===== apps/loops-min/README.md =====
1: # loops-min
2: 
3: `loops-min` is the transitional JSON process client for the headless `sdk`
4: package. It provides descriptor/read operations, verification, projection and
5: search maintenance, exact export, explicit restore-forward, and a mapped-only
6: Arrival writer surface. Empty-receiver import, admission, a generic replicate
7: command, and legacy writer retirement remain later work.
8: 
9: Writer commands require all of `--credential-root`, `--credential-namespace`,
10: and `--receipt-observer`. They never select locator-derived credentials or fall
11: back to a legacy writer or create keys. The founding binding must be
12: pre-provisioned for `init`; pre-provision every author and receipt binding used
13: by a signed workflow. Selecting the mapped provider does not make every domain
14: mandatory: an absent optional signer retains the SDK's unsigned behavior under
15: the captured declaration and signed-era rules. Callers should inspect each
16: result's `signed` and `witnessed` evidence. Create or import bindings explicitly
17: with the SDK's `MappedCredentialProvider`. For example,
18: `MappedCredentialProvider(root, namespace="tenant",
19: receipt_observer="alice").create_binding("alice", token="setup-alice")`
20: prepares the founding binding used by `init`.
21: 
22: `init` always requests an Arrival file target and never uses `init_vertex`'s
23: legacy default. A minimal lifecycle is:
24: 
25: ```text
26: loops-min init app.vertex --name app --location /data/app.arrival \
27:   --observer alice --credential-root /keys --credential-namespace tenant \
28:   --receipt-observer alice --strict
29: loops-min emit app.vertex item --payload-json '{"value":1}' --observer alice \
30:   --credential-root /keys --credential-namespace tenant --receipt-observer alice
31: loops-min emit-batch app.vertex --facts-json '[{"kind":"item","payload":{"value":2},"observer":"alice","id":"item-2"}]' \
32:   --credential-root /keys --credential-namespace tenant --receipt-observer alice
33: ```
34: 
35: `emit` requires a JSON object payload. `emit-batch` requires an array of JSON
36: objects and preserves each item's explicit observer, ID, timestamp, origin,
37: and admission choice. Transport JSON rejects duplicate keys and non-finite
38: numbers before credential resolution. The client does not retry unknown
39: outcomes; stable IDs and the SDK's returned evidence are the reconciliation
40: boundary.
41: 
42: `declaration target.vertex --proposed-file next.vertex --observer alice ...`
43: passes the file's text to the SDK's captured declaration-edit protocol. If an
44: edit reports an intent after a durable interruption,
45: `declaration-recover INTENT` resumes it without resolving credentials again.
46: Initialization recovery and credential creation are not CLI commands in this
47: slice.
48: 
49: `loops-min export target.vertex captured.jsonl` publishes a complete captured
50: wire prefix at a new pathname and returns the SDK manifest in its JSON result.
51: It never replaces an existing output. Export publication failures report
52: whether the complete artifact became visible before directory durability failed.
53: 
54: `loops-min restore-forward source.vertex receiver.vertex` restores an existing
55: exact copy through the witnessed source head. It preserves the receiver's
56: role and reports its before/after heads and commit receipt. Ordinary opens
57: continue to refuse older copies. Unknown or incomplete outcomes retain the
58: identity evidence needed to reconcile custody before repeating the operation.
59: 
60: Each successful invocation prints one `{"ok": true, "result": ...}` JSON
61: object. Failures print one JSON error object on stdout and a concise diagnostic
62: on stderr. Result objects are serialized with the SDK model's `as_dict()`;
63: continuation capabilities remain process-local and are reported without a
64: fake cursor token.
65: 
66: Exit status 2 covers argument, transport JSON, and local input-file errors; 3
67: means a recognized unsupported operation or target; 4 is a target, custody,
68: projection, publication, or contract refusal/outcome; 5 is admission or
69: ceremony refusal; and 6 means custody committed or may have committed. Status
70: 4 does not by itself prove zero derived or publication effects. Status 6 is
71: not permission to retry: the JSON error retains commit, IDs, intent, and
72: outcome evidence supplied by the SDK.
73: 
74: The executable is deliberately named `loops-min` while the legacy `loops`
75: application remains in the workspace. It has no presentation, storage, or

===== docs/scratch/arrival-break/consistency-c9-transition-2026-09-06.md =====
1: # C9: minimal-CLI writer transition and legacy-authority inventory
2: 
3: Status: first C9 writer slice implemented on `arrival/finish`, based on
4: `f45f1f03`. Native validation is complete; the frozen final Fable-low review is pending. No C9
5: commit or push yet; legacy retirement remains open.
6: 
7: ## Decision and first supported lifecycle
8: 
9: `loops-min` is the process boundary for the first writer slice.  It imports
10: only `sdk` and serializes SDK result/error objects; it does not open a store,
11: resolve a suffix, or construct a runtime.  The slice is deliberately
12: mapped-credential-only:
13: 
14: 1. Before mapped initialization, an operator uses the SDK's explicit
15:    `MappedCredentialProvider.create_binding`, import, existing-reference, or
16:    recovery operation to create the required founding binding. Binding mutation
17:    has its own durable result and is not a CLI subcommand in this slice.
18: 2. Each writer invocation supplies an exact `--credential-root`,
19:    `--credential-namespace`, and `--receipt-observer`.  The CLI constructs one
20:    `MappedCredentialProvider`; incomplete configuration is an argument error.
21:    Resolution is read-only and never creates a key or binding. A founding
22:    binding is mandatory for mapped init; an ordinary missing mapping may still
23:    produce an unsigned observation where the existing Arrival policy allows it.
24: 3. `init` calls `sdk.init_vertex(..., store_type="arrival", backend="file")`.
25:    It never selects SQLite or JSONL.  `emit` accepts one JSON object payload;
26:    `emit-batch` accepts a JSON array of object items and calls `sdk.emit_batch`.
27:    Both preserve the SDK's result, atomicity, Commit, and unknown-outcome
28:    evidence rather than retrying or synchronizing.
29: 4. `declaration TARGET --proposed-file FILE --observer OBSERVER` reads UTF-8
30:    proposal text and calls `sdk.edit_declaration`.  If its result/error carries
31:    a durable intent, `declaration-recover INTENT` calls
32:    `sdk.recover_declaration` without credentials: recovery must not re-sign or
33:    append a second declaration record.
34: 5. A separate existing `sync`, read, and `verify` invocation observes the
35:    outcome.  The writer commands do not add an implicit projection repair,
36:    source run, or retry.
37: 
38: This is an additive process-client workflow, not an authorization to remove
39: the old application or to claim feature parity.
40: 
41: ## Authority boundary and descriptor race
42: 
43: The public SDK generic writers still retain legacy compatibility:
44: `emit_fact` parses `_arrival_descriptor` and otherwise proceeds to the legacy
45: `open_vertex` path ([emit.py](../../../libs/sdk/src/sdk/emit.py#L363)).  The
46: same shape exists for `emit_batch` ([emit.py](../../../libs/sdk/src/sdk/emit.py#L596)).
47: Mapped credentials make a legacy downgrade fail closed:
48: `_refuse_legacy_mapped_credentials` rejects a mapped provider before that arm
49: ([emit.py](../../../libs/sdk/src/sdk/emit.py#L128)).  `edit_declaration` is
50: already Arrival-only and refuses a target without an explicit descriptor
51: ([declare.py](../../../libs/sdk/src/sdk/declare.py#L163)).
52: 
53: The CLI's `resolve_arrival_target` precheck is therefore a **classification
54: gate**, not a captured descriptor handle.  It parses the file once and the SDK
55: writer parses it again.  If the file is replaced with a legacy declaration
56: between those operations, mapped fail-closed behavior prevents a legacy write.
57: If it is replaced with a different valid Arrival descriptor, the second SDK
58: parse may choose that descriptor; the writer's own capture/CAS protects that
59: chosen descriptor, but the CLI has not promised identity continuity with the
60: first parse.
61: 
62: That is adequate for this first slice's no-legacy-authority claim.  It is not
63: a descriptor pinning contract.  A future process API that needs identity
64: continuity must receive a public resolved Arrival target/descriptor token or
65: perform resolve-and-write inside one SDK operation.  The CLI must not use
66: private SDK target helpers to simulate either design.
67: 
68: ## Existing authority inventory
69: 
70: | Surface | Evidence | C9 disposition |
71: | --- | --- | --- |

86: ## Acceptance and retirement gates
87: 
88: The real subprocess workflow uses isolated `XDG_STATE_HOME`,
89: `XDG_CONFIG_HOME`, and `LOOPS_HOME`. SDK setup provisions Alice and Bob; CLI
90: init → emit → declaration granting Bob → mixed-author atomic batch → complete
91: read → Full verify checks actual Commit predecessors, exact IDs/authors/bodies
92: and captured/projected heads. Refusal controls cover partial arguments,
93: malformed later batch items, a distinct unauthorized Alice key in another
94: namespace, absent founding credentials, and a legacy writer target. A separate
95: ordinary missing-slot case preserves unsigned behavior without creating keys.
96: 
97: Tests at the SDK call boundary exercise committed/unknown error serialization,
98: declaration recovery dispatch without credentials, strict JSON/finite timestamp
99: transport and a descriptor changed to legacy after the classification gate.
100: They are deterministic injected seams, not subprocess crash or concurrent
101: writer tests. The prior [declaration recovery SDK workload](sdk-conformance-declaration-recovery-2026-09-06.md)
102: provides the real interruption/recovery custody evidence; this slice does not
103: claim to repeat that interruption through an operating-system process crash.
104: 
105: A separate modular-wheel smoke installs the client and SDK dependency wheels
106: into a fresh environment, with neither legacy `loops` nor Painted installed.
107: Outside the repository it provisions mapped credentials via SDK and invokes
108: the installed console executable for init → emit → declaration → facts → verify.
109: Installed production source hashes match the worktree. The first smoke harness
110: attempt compared a resolved module path to an unresolved environment prefix;
111: fixing that assertion allowed the same product wheels to pass.
112: 
113: Do not delete a legacy command merely because this workflow passes.  Deletion
114: requires: a named SDK/CLI replacement or intentional retirement for every
115: legacy consumer; subprocess compatibility evidence for former callers; an
116: explicit migration decision for store/absorb/reanchor/import tools; and updated
117: packaging/help that identifies `loops-min` as additive until the old `loops`
118: entry point can be replaced.  `run_sources`, close/seal, population operations,
119: aggregate writing, empty-receiver import, and custody binding mutation are
120: outside this slice.

134: ## Narrow implementation note: absolute File residence spelling
135: 
136: During C9 smoke validation, a mapped initialization with an absolute store
137: path under a directory symlink wrote that alias spelling into the `.vertex`
138: file.  The subsequent edit re-parsed the descriptor with
139: `descriptor_for`, which leaves absolute File paths unchanged, but declaration
140: preparation separately called `Path.resolve()` before comparing residence.
141: The unchanged proposal therefore refused.
142: 
143: `_descriptor_location` now delegates to `canonical_store_path`, the same rule
144: used by `descriptor_for`.  This preserves an absolute declaration spelling and
145: still resolves a relative File store against its declaring vertex.  Non-File
146: locations remain opaque; no descriptor identity rule was broadened.  The SDK
147: regression initializes through a pre-provisioned mapped provider at a real
148: directory plus symlink alias, accepts an unchanged-location edit, and refuses
149: a proposal changing the location.  The current `InitVertexResult.store`
150: normalizes the initialization output to the resolved File path while the
151: declaration text retains its submitted absolute spelling; this patch leaves
152: that established output behavior untouched rather than redefining descriptor
153: serialization.

155: ## Narrow implementation note: batch input errors
156: 
157: Mapping-form batch payload and timestamp conversions previously raised raw
158: TypeError, ValueError, or OverflowError before SDK normalization. The client
159: would report those invalid inputs as internal failures. The SDK now raises
160: `InvalidEmissionRequest` at those conversion boundaries, preserving accepted
161: coercions and refusing before target resolution or any append. Six cases failed
162: before this correction and passed afterward; the CLI also exercises malformed
163: second items against an initialized store and checks unchanged ledger bytes.

49: def _tick_fields(tick: Any, change: Any) -> tuple[str | None, str | None]:
50:     """Resolve (tick_mark, tick_id) for a receipt whose write fired a boundary.
51: 
52:     The in-memory engine ``Tick`` carries no id — the store assigns one on the
53:     tick row, surfaced as ``TickEvent.tick_id`` in the post-write ``ChangeBatch``.
54:     Reading ``tick.id`` off the Tick object was an AttributeError on every
55:     boundary-firing emission.
56:     """
57:     if tick is None:
58:         return None, None
59:     tick_id: str | None = None
60:     if change is not None and change.ticks:
61:         matching = [ev for ev in change.ticks if ev.name == tick.name]
62:         if matching:
63:             tick_id = matching[-1].tick_id
64:     return tick.name, tick_id

67: def _fold_preview(

69: ) -> tuple[bool, str | None, bool, Any | None]:
70:     """Describe the existing SDK fold fields from one effective declaration."""

378: 
379:     Parameters:
380:         target: Path to the target .vertex file.
381:         kind_or_fact: Kind name string or complete `Fact` atom.
382:         payload: Fact payload dictionary (required if `kind_or_fact` is a string).

401:         actual_observer = fact.observer
402:     else:
403:         if observer is None:
404:             raise InvalidEmissionRequest("observer is required when emitting by kind name")
405:         if payload is None:
406:             raise InvalidEmissionRequest(
407:                 "payload dictionary is required when emitting by kind name"
408:             )

411:         actual_ts = ts if ts is not None else datetime.now(UTC).timestamp()

413:             kind=kind_or_fact,
414:             ts=actual_ts,
415:             payload=payload,
416:             observer=actual_observer,
417:             origin=origin,
418:         )
419: 
420:     if dry_run:
421:         preview = preview_emission(
422:             target,
423:             kind_or_fact=fact,
424:             observer=actual_observer,
425:             origin=origin,
426:             ts=ts,
427:             id_override=id_override,
428:             admit_undeclared=admit_undeclared,
429:             credentials=credentials,
430:             registry=registry,
431:         )
432:         if not preview.admitted:
433:             raise AdmissionFailed(

435:                 observer=preview.observer,
436:                 kind=preview.kind,
437:             )

439:             write_path=preview.read_path,
440:             store=preview.store,
441:             id="",
442:             stored=False,
443:             signed=None,
444:             observer=actual_observer,
445:             tick_mark=None,
446:             tick_id=None,
447:             state_change=False,
448:             affected_sections=[preview.kind] if preview.would_fold else [],
449:             delta_count=0,
450:             predicted_state_change=preview.would_fold,
451:             captured_head=preview.captured_head,
452:             witnessed=None,
453:             projection="not-requested" if arrival is not None else None,
454:         )

456:     if arrival is not None:
457:         from engine.arrival_maintenance import sync_projection
458:         from engine.runtime_write import (
459:             OrdinaryWritePlan,

217: def _cause_details(exc: BaseException) -> dict[str, Any] | None:
218:     """Two explicit causal nodes, never implicit context or record bodies."""
219:     seen = {id(exc)}
220:     result: dict[str, Any] | None = None
221:     parent: dict[str, Any] | None = None
222:     for _ in range(2):
223:         cause = _causal_exception(exc)
224:         if cause is None or id(cause) in seen:
225:             break
226:         seen.add(id(cause))
227:         try:
228:             message = str(cause)
229:         except Exception:
230:             message = "<message unavailable>"
231:         node: dict[str, Any] = {
232:             "type": type(cause).__name__,
233:             "message": message[:512],
234:             "details": _identity_details(cause),
235:         }

237:             node["truncated"] = True

239:             result = node

249:     evidence: dict[str, Any] = {}

257:             effect = effects.get(resource)

430: def normalize_exception(
431:     exc: BaseException, *, context: Mapping[str, Any] | None = None
432: ) -> BaseException:
433:     """Return a stable SDK exception for engine boundary failures.
434: 
435:     Existing SDK errors are returned unchanged.  Classification is by the
436:     engine's public exception types, never by message text.
437:     """
438:     if not isinstance(exc, Exception) or isinstance(exc, SdkError):
439:         return exc
440:     details = _identity_details(exc)
441:     context_fields = {
442:         "captured_head",
443:         "fact_id",
444:         "tick_id",
445:         "fact_ids",
446:         "tick_ids",
447:         "items",
448:         "item_index",
449:     }
450:     for name, value in (context or {}).items():
451:         if name in details or name not in context_fields:
452:             continue
453:         coordinate = _context_detail(name, value)
454:         if coordinate is not None or value is None:
455:             details[name] = coordinate

457:     credential = _credential_binding_details(exc)
458:     if credential is not None:
459:         details["credential_binding"] = credential
460:     evidence = _evidence_details(exc, details)
461:     if evidence is not None:
462:         details["evidence"] = evidence

466:         return CommittedOutcomeUnknown(str(exc), source_type=type(exc).__name__, details=details)
467:     if isinstance(exc, (DeclarationOutcomeUnknown, RestoreForwardUnknown)):
468:         return CommittedOutcomeUnknown(str(exc), source_type=type(exc).__name__, details=details)
469:     if isinstance(exc, InitializationUnwitnessed):
470:         return CommittedUnwitnessed(str(exc), source_type=type(exc).__name__, details=details)
471:     if isinstance(exc, DeclarationUnwitnessed):
472:         return CommittedUnwitnessed(str(exc), source_type=type(exc).__name__, details=details)
473:     if isinstance(exc, InitializationCommittedIncomplete):
474:         return CommittedIncomplete(str(exc), source_type=type(exc).__name__, details=details)
475:     if isinstance(exc, (DeclarationCommittedIncomplete, RestoreForwardIncomplete)):
476:         return CommittedIncomplete(str(exc), source_type=type(exc).__name__, details=details)
477:     if isinstance(exc, NotWitnessed):
478:         return CommittedUnwitnessed(str(exc), source_type=type(exc).__name__, details=details)
479:     if isinstance(exc, DeclarationStale):

509:             source_type=type(exc).__name__,
510:             details=details,
511:             observer=getattr(exc, "observer", None),

514:         )

518:         exc,

524:         ),

145:     def sign(
146:         self,
147:         credentials: WriteCredentials,
148:         request: CredentialRequest,
149:         digest: str,
150:         *,
151:         context: CapturedSigningContext,
152:         authorized_keys: tuple[str, ...],

154:     ) -> str | None:
155:         """Resolve, authorize and independently verify one mapped signature."""
156:         resolver = credentials.binding_resolver
157:         verifier = credentials.signature_verifier
158:         if not credentials.mapped or resolver is None or verifier is None:
159:             raise CredentialBindingRefused(
160:                 "mapped signing requires a complete credential configuration",
161:                 request=request,
162:                 captured_head=context.captured_head,
163:                 use_position=context.use_position,
164:             )
165:         try:
166:             resolved = resolver(request)
167:         except CredentialBindingRefused as exc:
168:             raise CredentialBindingRefused(

170:                 request=request,
171:                 captured_head=context.captured_head,
172:                 use_position=context.use_position,
173:                 evidence=exc.evidence,
174:             ) from exc
175:         except Exception as exc:
176:             raise CredentialBindingRefused(
177:                 "credential resolver failed",
178:                 request=request,
179:                 captured_head=context.captured_head,
180:                 use_position=context.use_position,
181:             ) from exc
182:         if resolved is None:
183:             if not required:
184:                 return None
185:             raise CredentialBindingRefused(
186:                 "missing-required",
187:                 request=request,
188:                 captured_head=context.captured_head,
189:                 use_position=context.use_position,
190:             )
191:         if not isinstance(resolved, ResolvedCredential):
192:             raise CredentialBindingRefused(
193:                 "resolver returned an invalid credential value",
194:                 request=request,
195:                 captured_head=context.captured_head,
196:                 use_position=context.use_position,
197:             )
198:         evidence = resolved.evidence
199:         if (
200:             not isinstance(evidence, CredentialBindingEvidence)
201:             or evidence.request != request
202:             or not all(

204:                 for value in (
205:                     evidence.key_ref,
206:                     evidence.algorithm,
207:                     evidence.public_key,
208:                     evidence.provenance,
209:                 )
210:             )
211:             or not callable(resolved.sign_digest)
212:         ):
213:             raise CredentialBindingRefused(
214:                 "resolver returned contradictory binding evidence",
215:                 request=request,
216:                 captured_head=context.captured_head,
217:                 use_position=context.use_position,
218:                 evidence=evidence
219:                 if isinstance(evidence, CredentialBindingEvidence)
220:                 else None,
221:             )
222:         if evidence.public_key not in authorized_keys:
223:             raise CredentialBindingRefused(
224:                 "resolved public key is not authorized at the captured position",
225:                 request=request,
226:                 captured_head=context.captured_head,
227:                 use_position=context.use_position,
228:                 evidence=evidence,
229:             )
230:         binding_key = (request.namespace, request.observer)
231:         binding_value = (evidence.key_ref, evidence.public_key)

247:                 captured_head=context.captured_head,

249:                 evidence=exc.evidence or evidence,
250:             ) from exc

252:             raise CredentialBindingRefused(
253:                 "credential signer failed",
254:                 request=request,
255:                 captured_head=context.captured_head,
256:                 use_position=context.use_position,
257:                 evidence=evidence,
258:             ) from exc

271:         except CredentialBindingRefused as exc:

273:                 exc.reason,
