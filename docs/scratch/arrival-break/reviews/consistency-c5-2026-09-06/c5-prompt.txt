18:
19: Resolution contract (SPEC §9.2 Lineage, §9.5):
20:
21: - **Genesis is identity, not fold state.** A store's lineage is opened exactly
22:   once; the genesis event carries the whole initial document set as its
23:   payload. Genesis is NOT resolved by Latest — its documents are the base the
24:   overlay is applied on top of. **Which genesis is self is recorded outside
25:   the fact stream**: the ``store_meta`` table's ``own_lineage`` row, stamped
26:   by ``absorb_genesis`` in the same transaction that mints the genesis. Merge
27:   copies facts, never meta — so foreign genesis rows arrive as inert citizens
28:   and can never hijack identity. Resolution selects the genesis row whose id
29:   equals the marker; a marker whose row is missing is corruption
30:   (:class:`DeclarationResolutionError`). An UNMARKED store holding any genesis
31:   rows refuses (:class:`UnadoptedLineage`) — identity is claimed only by the
32:   explicit adopt ceremony (``loops store adopt``), never inferred from facts.
33:

36:   physically present. Every overlay/tombstone row must carry

38:   with a foreign or absent lineage are **inert** — read, counted, never folded.

70:   position is A10-verified against this store before its ordinal is applied
