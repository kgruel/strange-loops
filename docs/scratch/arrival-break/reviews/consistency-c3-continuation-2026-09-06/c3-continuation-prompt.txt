1224:             truncated=more, order=request.order,
1225:         )
1461:     def open_snapshot(
1462:         self,
1463:         *,

1470:         No projection is created or repaired here. A missing index is an
1471:         explicit current-read refusal, or an empty allow-behind snapshot that
1472:         carries no represented watermark for diagnostics.
1473:         """

1475:             if requirement is ProjectionRequirement.CURRENT:
