===== libs/sdk/README.md =====
1: # sdk — Loops Apex Composition Library
2: 
3: `sdk` is the headless composition layer uniting `engine`, `custody`, `lang`, `store`, `atoms`, and `sign` into unified, typed operations. It serves as the single foundation for presentation layers (`apps/loops`, TUI, external agents, Python scripts) without leaking presentation logic into the core substrate.
4: 
5: ---
6: 
7: ## Architectural Guarantees
8: 
9: - **Zero Presentation Logic**: Returns pure typed dataclasses; never formats terminal escape codes or parses CLI flags.
10: - **Descriptor-First Arrival Reads**: An explicitly declared backend and instance role select the adapter; store locations remain opaque to the SDK.
11: - **Visible Legacy Boundary**: Bare `.jsonl`/SQLite inputs remain transitional and every read result labels its path as `legacy` with `basis=None`.
12: - **Witness-Axis Honesty**: Fact listing and pagination use append-order cursors (`WitnessPosition`) ensuring deterministic, non-lossy walks.
13: - **Declared Admission & Attestation**: Fact emission enforces declared observer and kind admission policies, signing with operation-fresh custody keys.
14: - **AST-Verified Ceremonies**: Declarative vertex modifications are verified against the language grammar and executed via transactional plan/apply ceremonies.
15: 
16: ---
17: 
18: ## API Reference
19: 
20: ### 1. Target Resolution & Discovery
21: 
22: ```python
23: from sdk import resolve_arrival_target, resolve_target, discover_targets, TargetInfo
24: 
25: # Supported Arrival target: the descriptor carries backend, opaque location,
26: # optional lineage pin, and mandatory instance role.
27: arrival = resolve_arrival_target("path/to/target.vertex")
28: # -> ArrivalTarget(store=StoreDescriptorInfo(backend='file', location='...', role='replica'))
29: 
30: # Single target probe
31: info = resolve_target("path/to/target.vertex")
32: # -> TargetInfo(target_type='vertex', canonical_mode='sqlite', canonical_path=..., index_path=..., exists=True, ...)
33: 
34: # Multi-target workspace discovery
35: targets = discover_targets(".", recursive=True)
36: ```
37: 
38: - **`resolve_target(target: Path | str) -> TargetInfo`**:
39:   Transitional filesystem probe for legacy targets. Raises `TargetNotFound` or `TargetUnsupported`.
40: - **`resolve_arrival_target(target: Path | str) -> ArrivalTarget`**:
41:   Parses an explicit vertex descriptor without probing or normalizing its backend-owned location. It refuses suffix inference and an omitted instance role.
42: - **`discover_targets(root_path=".", *, recursive=True, include_bare=True) -> list[TargetInfo]`**:
43:   Discovers all Loops vertices and bare stores in a directory tree.
44: 
45: ---
46: 
47: ### 2. Read Operations
48: 
49: ```python
50: from sdk import (
51:     read_summary,
52:     read_facts,
53:     read_state,
54:     read_ticks,
55:     read_fact_by_id,
56:     search_facts,
57:     resolve_entity,
58:     read_timeline,
59:     sync_target,
60: )
61: 
62: # Target statistical summary & kind inventory
63: summary = read_summary("target.vertex")
64: # -> ReadSummary(read_path='arrival', basis=ReadBasis(...), store=StoreDescriptorInfo(...), ...)
65: 
66: # Bounded, cursor-bearing fact pagination
67: page = read_facts("target.vertex", limit=10, order="newest")
68: # -> FactPageResult(items=[...], next_cursor=..., truncated=True, order='newest')
69: 
70: # Arrival continuations are process-local capabilities. Pass next_cursor back
71: # to read_facts() directly; as_dict() reports has_continuation=True and redacts
72: # the engine value instead of emitting an unprotected wire token.
73: 
74: # Folded vertex state
75: state = read_state("target.vertex", kind="note")
76: # -> FoldStateResult(vertex_name='target', sections={'note': {'count': 10, 'items': [...]}})
77: 
78: # Full-text search across observation payloads
79: search_res = search_facts("target.vertex", query="refactor auth", limit=10)
80: # -> SearchResult(query='refactor auth', matches=[...], total_matches=1)
81: 
82: # Domain entity fold-key resolution
83: fact_id = resolve_entity("target.vertex", kind="task", key="task_id", value="T-100")
84: 
85: # Interleaved chronological timeline (facts + ticks)
86: timeline = read_timeline("target.vertex", limit=50)
87: 
88: # Explicit projection synchronization. Arrival sync first attests custody and
89: # catches a missing or behind projection up through the captured head.
90: sync_res = sync_target("target.vertex")
91: # -> SyncResult(read_path='arrival', captured_head=..., target=...,
92: #               projected_before=..., projected_after=..., changed=True, ...)
93: 
94: # Tick records
95: ticks = read_ticks("target.vertex", name="default")
96: for tick in ticks.items:
97:     print(tick["name"])
98: 
99: # Fact lookup by full ID or prefix
100: lookup = read_fact_by_id("target.vertex", "01M01...")
101: fact = lookup.fact
102: ```
103: 
104: `read_summary`, `read_facts`, `read_state`, `read_ticks`, and
105: `read_fact_by_id` always return typed result models. Descriptor-first results
106: carry the custody head and represented projection prefix in `basis`; legacy
107: results carry `read_path="legacy"` and `basis=None`. Descriptor reads require a
108: current projection and never materialize, repair, or catch it up. Search,
109: entity resolution, and timelines carry the same captured basis. Aggregate
110: state, summary and timeline results retain per-occurrence member bases rather
111: than inventing one shared head. `sync_target` is the
112: explicit maintenance boundary: it may catch up a missing or behind Arrival
113: projection, while inconsistent existing state and rebuild requests refuse.
114: 
115: Arrival read operations, including `resolve_entity`, `read_timeline`, and
116: `inspect_declaration`, accept an optional keyword-only `registry=` for custom
117: `engine.arrival_registry.BackendRegistry` instances. Omission selects the
118: built-in backends. A supplied registry handles every supported root and member
119: Arrival open; unknown backends refuse without fallback, and non-file locations reach
120: the named adapter unchanged. Timeline reuses its captured root when the
121: effective declaration selects aggregation. Entity resolution and declaration
122: inspection retain their current Arrival aggregate restrictions.
123: Legacy targets keep their existing behavior and do not consult the registry.
124: 
125: `export_target("target.vertex", "snapshot.jsonl")` writes an exact captured
126: wire prefix and returns its manifest, selected/captured heads and byte count.
127: It refuses to replace an existing output. A late source failure publishes no
128: partial artifact; a directory-sync failure after publication raises
129: `ExportPublicationError` with `published=True` and the complete artifact's
130: identity. Export requires no current query projection. Import and replication
131: are still pending their explicit initialization/restoration boundary.

135: ### 3. Fact Emission
136: 
137: ```python
138: from sdk import BatchEmitResult, EmitReceipt, emit_batch, emit_fact, preview_emission
139: from atoms import Fact
140: 
141: # Emitting by kind and payload
142: receipt = emit_fact(
143:     "target.vertex",
144:     kind_or_fact="note",
145:     payload={"title": "Meeting Notes", "body": "Discussed SDK API"},
146:     observer="alice",
147: )
148: # Descriptor-first Arrival receipts carry the captured head, durable Commit,
149: # witness state, and post-commit projection status.
150: 
151: # Or preflight dry-run simulation
152: preview = preview_emission("target.vertex", "note", {"title": "Test"}, observer="alice")
153: 
154: # A descriptor-first batch is planned from one snapshot and uses one append.
155: batch = emit_batch(
156:     "target.vertex",
157:     [fact, ("note", {"title": "Batch item"})],
158:     observer="alice",
159: )
160: for receipt in batch.items:
161:     print(receipt.id, receipt.stored)
162: print(batch.commit, batch.atomicity, batch.projection)
163: ```
164: 
165: - **`emit_fact(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, id_override=None, credentials=None, admit_undeclared=False, dry_run=False, registry=None) -> EmitReceipt`**:
166:   Emits a fact (or `Fact` atom) under declared admission rules. Descriptor-first Arrival writes prepare from one CURRENT snapshot, append once against its captured full head, witness the commit, then explicitly synchronize the projection. Bypassing strict kind admission requires `admit_undeclared=True`. Deterministic IDs can be specified with `id_override`. `dry_run=True` simulates emission without storage.
167: - **`preview_emission(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, admit_undeclared=False, credentials=None, registry=None) -> EmitPreviewResult`**:
168:   Simulates emission against declared policies, checking fold key requirements without disk side effects. Arrival policy and fold metadata come from the same bounded effective declaration used for planning; a missing projection refuses without materializing it.
169: - **`emit_batch(target, facts, *, observer=None, origin="", credentials=None, admit_undeclared=False, registry=None) -> BatchEmitResult`**:
170:   Normalizes every item before resolving the target. A descriptor-first Arrival batch derives all per-item admission decisions from one current snapshot, appends the packed records under one head comparison, witnesses one shared commit, and explicitly synchronizes the projection. Each mapping item may set its own boolean `admit_undeclared`; duplicate receipts retain `stored=False`. Empty input is an explicit zero-write result. Legacy targets return the same wrapper with `atomic=False`, `atomicity="legacy-sequential"`, and no invented shared commit; `LegacyBatchPartialFailure` retains receipts if that sequential loop stops after an observable prefix.
171: 
172: `CustodyCredentialProvider()` and `CustodyCredentialProvider(key_dir=None)` use
173: the existing custody resolver. A non-`None` `key_dir` now raises
174: `SdkValueError` during construction because directory overrides were previously
175: accepted but ignored. This applies before either Arrival or legacy operations
176: can use the provider. Callers that need another credential source can continue
177: to supply a custom `CredentialProvider`; that interface does not itself create
178: an observer mapping or register public keys.
179: 
180: For an explicit persisted namespace, use `MappedCredentialProvider` with an
181: Arrival target. Prepare the binding separately from initializing the store:
182: 
183: ```python
184: from pathlib import Path
185: from sdk import MappedCredentialProvider, init_vertex, emit_fact
186: 
187: credentials = MappedCredentialProvider(
188:     Path("/absolute/path/to/private-custody"),
189:     namespace="personal",
190:     receipt_observer="alice",  # explicit local receipt-signing selection
191: )
192: binding = credentials.create_binding("alice", token="bootstrap-alice-1")
193: init_vertex(
194:     Path("observations.vertex"), store_type="arrival", observer="alice",
195:     credentials=credentials,
196: )
197: emit_fact(
198:     Path("observations.vertex"), "item", {"value": 1},
199:     observer="alice", credentials=credentials,
200: )
201: ```
202: 
203: Mapped selection uses the exact namespace and observer, independently of the
204: vertex filename or lineage. The engine checks author keys against verified
205: history through captured H, for use after H, and verifies each signature in its
206: own domain. Receipt signing uses the explicitly selected local observer and
207: the effective declaration's current receipt-key policy; the unsigned outer tick
208: still names the physical genesis custodian. Omitting `receipt_observer` permits
209: unsigned ticks before the signed-tick era, and refuses a required signed tick.
210: A missing author binding may remain unsigned where the existing policy allows;
211: a contradictory or unauthorized binding refuses before append.
212: 
213: Mapped initialization only loads a pre-created binding. For another observer,
214: prepare its binding and pass `key=binding.public_key` to `grant_observer` with
215: the existing author's credentials. Mapped `grant_observer(key=None)` refuses
216: before creating keys. Recovery of an existing Arrival initialization intent
217: signs nothing and does not require private custody to remain available.
218: Mapped providers are supported on Arrival targets; legacy writers explicitly
219: refuse them. The default `CustodyCredentialProvider` remains unchanged.
220: 
221: The runnable [two-observer mapped workload](tests/test_arrival_mapped_workload.py)
222: shows the complete public lifecycle: create Alice and Bob bindings under one
223: persisted provider root and exact namespace; initialize with Alice; grant Bob
224: using Bob's pre-created public key; then emit with both authors. For a locator
225: move that keeps the same physical file-backed store, initialize with an
226: **absolute** `location` and move only the `.vertex` file while retaining its
227: store clause, lineage, and role. Recreate `MappedCredentialProvider` with the
228: same provider root, namespace, and receipt observer before continuing work.
229: The absolute store location keeps the same store residence, while
230: mapped key selection comes only from the provider namespace and exact observer
231: label; neither the vertex filename nor its new directory chooses a key.
232: 
233: After relocation, `verify_target(relocated_vertex)` provides a `Full`
234: verification of the captured prefix's grammar, dense ordinals, lineage, and
235: record-hash chain. It does not establish projection agreement, signature
236: authorship, key trust, or the identity of an observer across lineages. The
237: mapped workload exercises public writes with captured authorization; the
238: [mapped signing tests](tests/test_arrival_mapped_credentials.py) separately
239: verify domain-specific signatures and key-history behavior.
240: 
241: `import_legacy(vertex_path, observer, token=...)` explicitly copies a verified
242: legacy key into managed storage without changing the original. It preserves
243: flat/nested ambiguity and alias refusals. After import, locator moves do not
244: change mapped selection. No read, preview, or signer load imports or creates a
245: binding. `bind_existing_ref(observer, key_ref, expected_public_key, token=...)`
246: permits deliberate reuse of a completed managed key in another namespace;
247: equal observer labels alone never select another namespace's key.
248: See [custody binding recovery](../custody/README.md#explicit-mapped-bindings)
249: for interruption handling and filesystem scope.
250: 
251: ### Recovering an interrupted mapped declaration edit
252: 
253: An edit can raise `CommittedIncomplete` after its declaration records are
254: durable but before projection synchronization or local cache publication
255: finishes. Its public `details["intent_path"]` identifies the retained recovery
256: intent. Use it before deciding whether to retry the proposal:
257: 
258: ```python
259: from sdk import CommittedIncomplete, edit_declaration, recover_declaration
260: 
261: try:
262:     edit_declaration(vertex, proposal, observer="alice", credentials=credentials)
263: except CommittedIncomplete as outcome:
264:     recovered = recover_declaration(outcome.details["intent_path"])
265: ```
266: 
267: Recovery reconciles the exact retained suffix, synchronizes the projection,
268: and publishes the retained declaration bytes without re-signing or appending
269: the proposal again. A recovery result has no original `Commit`; its basis is
270: the original captured edit basis. Follow it with `inspect_declaration(vertex)`
271: to obtain a fresh effective-declaration/read basis, and use
272: `verify_target(vertex)` when the bounded `Full` hash-chain claim is needed.
273: The [mapped declaration recovery workload](tests/test_arrival_declaration_recovery_workload.py)
274: uses a deterministic injected `after-append` interruption beneath the public
275: SDK edit call; it is not a process-kill or crash-survival test.
276: 
277: Supported Arrival execution reserves the vertex name from its loop names.
278: Every exact name collision refuses, including passive loops, reset/carry loops,
279: and count- or event-triggered boundaries. The runtime also adds an implicit
280: `cite` loop, so a vertex named `cite` cannot execute under this restriction.
281: Runtime capture checks the historized effective declaration and expanded
282: template loop names before hydration and planning; editing only the local cache
283: cannot bypass it. New and proposed declarations check their declared loops and
284: the implicit `cite` loop. The SDK initializer also refuses the name `item`,
285: because its scaffold declares an `item` loop, before creating custody keys.
286: External template sources are expanded and checked at runtime; declaration
287: editing does not load them solely to enforce this rule.
288: 
289: This is an Arrival execution compatibility restriction. Existing histories
290: remain available through evidence reads, declaration inspection and export.
291: A collision-free declaration can be appended to correct an ambiguous current
292: declaration; prior facts and ticks retain their original names and bytes.
293: This does not establish which role an already-recorded ambiguous tick had;
294: historical boundary continuity remains a separate limitation.
295: Legacy runtime behavior and the wire format retain their existing rules.

299: ### 4. Arrival Source Execution
300: 
301: ```python
302: from sdk import run_sources
303: 
304: result = await run_sources("target.vertex", observer="alice", force=False)
305: for tier in result.tiers:
306:     print(tier.outcome, tier.commit, tier.fact_ids, tier.tick_ids)
307: ```
308: 
309: - **`await run_sources(target, *, observer, force=False, credentials=None, registry=None, collector_factory=None, dispatcher=None, evaluated_at=None) -> SourceRunResult`**:
310:   Captures a CURRENT Arrival Authority before collection, fixes cadence and dependency tiers, and commits each collected tier with one exact-head batch append plus explicit projection synchronization. The lifecycle observer is always explicit. Existing custody keys are loaded when present; the operation never creates keys.
311: 
312:   A source error after yielding observations returns `status="error"` after its error lifecycle fact becomes durable. Interrupted results retain prior commits and distinguish `known_uncommitted` collection from an append whose durability is `unknown`; collectors are not rerun. When `dispatcher` is omitted, captured tick run intents remain visible with `dispatch_status="not-requested"` and `attempted=False`. This operation supports explicit single-store Arrival Authority descriptors only and never falls through to legacy source execution.
313: 
314:   Coordinator failures during ID allocation, lifecycle construction, or otherwise successful collector cleanup return an incomplete result with terminal category `collection-failed`. `terminal.details.collection` contains the current tier's basis, `custody="not-attempted"`, completed siblings, and paired partial observations from failed or cancelled siblings. Incomplete attempts have no lifecycle fact; prior tiers keep their commits. These partial observations live in terminal evidence, not `known_uncommitted`, which describes a fully collected tier. Owned iterators and distinct iterable owners receive `aclose()` when available; caller cancellation propagates after sibling cleanup. Closing a collector does not undo its external effects or guarantee subprocess termination.

394: ## Exception Taxonomy
395: 
396: ```mermaid
397: graph TD
398:     SdkError --> TargetError
399:     TargetError --> TargetNotFound
400:     TargetError --> TargetUnsupported
401:     TargetError --> TargetNotWritable
402:     SdkError --> AdmissionFailed
403:     SdkError --> EmissionFailed
404:     SdkError --> SdkValueError
405:     SdkValueError --> InvalidEmissionRequest
406:     EmissionFailed --> InvalidEmissionRequest
407:     EmissionFailed --> CommittedEmissionError
408:     SdkError --> CeremonyFailed
409: ```
410: 
411: - **`SdkError`**: Base class for all high-level SDK exceptions.
412: - **`SdkValueError`**: Base class for SDK parameter and validation errors (inherits from `ValueError`).
413: - **`TargetNotFound`**: Target path does not exist on disk.
414: - **`TargetUnsupported`**: Path exists but is not a recognized Loops artifact.
415: - **`TargetNotWritable`**: Target or derived index cannot be written to.
416: - **`AdmissionFailed`**: Declared admission policy (strict kinds or observer grants) refused the operation.
417: - **`EmissionFailed`**: Fact emission failed prior to committing.
418: - **`InvalidEmissionRequest`**: Invalid emission parameters (missing required observer or invalid shape).
419: - **`CommittedEmissionError`**: Fact was written to storage, but a post-commit task failed (carries `.fact_id`).
420: - **`CeremonyFailed`**: Declaration update AST generation or ceremony apply was refused.
421: 
422: Descriptor-first reads also surface engine contract refusals (for example, a
423: missing or behind projection or an invalid continuation) and declaration
424: resolution errors. These keep the adapter's evidence-bearing refusal intact.
425: 
426: Arrival `sync_target` and `sync_search_index` normalize maintenance failures as
427: `ProjectionOutcomeUnknown`. Their optional `details.evidence` object uses
428: `loops.sdk/evidence/v1`: it records the coordinator phase, resource effects,
429: available head/coverage coordinates, and up to two explicit causal exceptions.
430: Search failures before the build call report derived state as
431: `not-entered`/`not-attempted`; failures after entering build or projection
432: catch-up report `entered`/`unknown`. A nested refusal does not prove that an
433: adapter left derived state unchanged. Existing error outcomes, source types,
434: and operation-specific `details.phase` remain intact. Cause messages are capped
435: at 512 characters; record bodies and implicit exception context are excluded.
436: Declaration preparation refusals carry preparation evidence without claiming a
437: custody append. Cancellation and process-control exceptions propagate unchanged.

439: ## Restore an existing exact copy
440: 
441: ```python

443: 
444: restored = restore_forward("source.vertex", "replica.vertex")
445: print(restored.before, restored.after)
446: ```

451: declared role. `restored.commit` is an actual receipt, or `None` when the exact
452: selected head is already present. Projection catch-up remains explicit.

456: `CommittedIncomplete` retains the commit if later witnessing or comparison
457: failed. Empty receiver installation is a separate, pending import operation.

480: def _publish_cache(
481:     plan: DeclarationEditPlan,
482:     *,
483:     intent: Path,
484:     intent_data: dict[str, Any],
485:     failure_hook: Callable[[str], None] | None,
486: ) -> None:
487:     """Detach the verified old cache, then exclusively link a full new file."""
488:     target = plan.target_path
489:     temp = (
490:         Path(intent_data["cache_temp"])
491:         if intent_data.get("cache_temp")
492:         else _unique_sibling(target, "cache")
493:     )
494:     backup = (
495:         Path(intent_data["cache_backup"])
496:         if intent_data.get("cache_backup")
497:         else _unique_sibling(target, "backup")
498:     )
499:     intent_data["cache_temp"] = str(temp)
500:     intent_data["cache_backup"] = str(backup)
501:     _replace_json(intent, intent_data)
502:     try:
503:         proposed = plan.proposed_text.encode("utf-8")
504:         if temp.exists():
505:             _verify_cache_temp(temp, proposed)
506:         else:
507:             _create_cache_temp(temp, proposed)
508:             if failure_hook:
509:                 failure_hook("after-cache-temp")
510:         if target.exists():
511:             current = target.read_bytes()
512:             if current != plan.old_cache_bytes:
513:                 raise DeclarationStale(
514:                     "declaration cache changed after preparation; refusing publication"
515:                 )
516:             if backup.exists():
517:                 raise DeclarationApplyError(
518:                     "a prior cache publication left a backup beside the live declaration"
519:                 )
520:             target.rename(backup)
521:             _fsync_parent(target)
522:         elif not backup.exists():
523:             raise DeclarationApplyError(
524:                 "declaration cache is absent without the verified detached backup"
525:             )
526:         if failure_hook:
527:             failure_hook("after-cache-detach")
528:         if backup.read_bytes() != plan.old_cache_bytes:
529:             raise DeclarationApplyError(
530:                 "detached declaration cache bytes differ from prepared evidence"
531:             )
532:         os.link(temp, target)
533:         temp.unlink()
534:         _fsync_parent(target)
535:         if failure_hook:
536:             failure_hook("after-cache-link")
537:         with suppress(FileNotFoundError):
538:             backup.unlink()
539:         _fsync_parent(backup)
540:     except BaseException:
541:         raise

711: def _signed_with_existing_key(
712:     *,
713:     credentials: WriteCredentials,
714:     signer: Callable[[str, str], str | None] | None,
715:     verifier: Callable[[str, str, str], bool],
716:     registry: Any,
717:     author: str,
718:     head: Head,
719:     digest: str,
720:     label: str,
721:     domain: SigningDomain,
722:     purpose: CredentialPurpose,
723:     context: CapturedSigningContext,
724:     session: CredentialResolutionSession,
725: ) -> str:
726:     if credentials.mapped:
727:         request = CredentialRequest(
728:             namespace=credentials.binding_namespace,
729:             observer=author,
730:             domain=domain,
731:             purpose=purpose,
732:         )
733:         try:
734:             signature = session.sign(
735:                 credentials,
736:                 request,
737:                 digest,
738:                 context=context,
739:                 authorized_keys=context.keys_for_author(author),
740:                 required=True,
741:             )
742:         except CredentialBindingRefused as exc:
743:             raise _preparation_refused(
744:                 f"{label} mapped credential refused: {exc}",
745:                 captured_head=head,
746:             ) from exc
747:         if signature is None:  # required=True makes this unreachable
748:             raise _preparation_refused(f"missing {label} signature")
749:         return signature
750:     if not callable(signer):
751:         raise _preparation_refused(f"missing {label} signer")
752:     keys = _valid_author_keys(registry, author, head)
753:     if not keys:
754:         raise _preparation_refused(
755:             f"edit author {author!r} has no key valid at the captured Arrival head"
756:         )
757:     signature = signer(author, digest)
758:     if not signature:
759:         raise _preparation_refused(f"missing {label} signature")
760:     if not any(verifier(key, signature, digest) for key in keys):
761:         raise _preparation_refused(
762:             f"{label} signature does not verify under a key valid for edit author "
763:             f"{author!r} at the captured Arrival head"
764:         )
765:     return signature

858: def prepare_declaration_edit(
859:     registry: BackendRegistry,
860:     descriptor: StoreDescriptor,
861:     *,
862:     target: Path | str,
863:     proposed_text: str,
864:     observer: str,
865:     credentials: WriteCredentials | None,
866:     fact_verify: Callable[[str, str, str], bool],
867:     arrival_verify: Callable[[str, str, str], bool],
868:     source_cache_bytes: bytes | None = None,
869:     require_cache_basis: bool = False,
870: ) -> DeclarationEditPlan:
871:     """Prepare one exact declaration transition against an attested CURRENT head.
872: 
873:     This function only reads and signs in memory. It creates no intent, does
874:     not append, and does not touch the declaration cache. The registry opener
875:     is expected to return an attested custody handle; its ``scan`` is the
876:     structurally verified genesis-through-head sequence required by the
877:     iterable authorship seam.
878:     """
879:     target_path = Path(target).resolve()
880:     if not isinstance(proposed_text, str) or not proposed_text:
881:         raise _preparation_refused("proposed declaration text is empty")
882:     try:
883:         old_cache_bytes = target_path.read_bytes()
884:     except OSError as exc:
885:         raise _preparation_refused(
886:             f"cannot read declaration cache {target_path}: {exc}"
887:         ) from exc
888:     if source_cache_bytes is not None and old_cache_bytes != source_cache_bytes:
889:         raise _preparation_refused(
890:             "declaration cache changed while preparing the requested splice"
891:         )
892:     try:
893:         ast = parse_vertex(proposed_text, path=target_path)
894:         validate_vertex(ast)
895:     except Exception as exc:
896:         raise _preparation_refused(
897:             f"proposed declaration is not valid Vertex grammar/semantics: {exc}"
898:         ) from exc
899:     validate_arrival_runtime_identity(

1261: def _apply_declaration_edit(
1262:     registry: BackendRegistry,
1263:     plan: DeclarationEditPlan,
1264:     *,
1265:     failure_hook: Callable[[str], None] | None = None,
1266: ) -> DeclarationEditResult:
1267:     """Append one prepared declaration transition and publish its cache.
1268: 
1269:     The prepared drafts are submitted exactly once under the captured full
1270:     head. Contract refusals are zero-prefix stale refusals; transport and
1271:     witness failures retain the intent and their identity for recovery.
1272:     """
1273:     _validate_plan(plan)
1274:     if plan.status == "noop":
1275:         return _result(
1276:             plan, status="noop", head=plan.captured_head, commit=None, intent=None,
1277:             phase="noop", file_written=False, changes=plan.changes,
1278:         )
1279:     intent = declaration_intent_path(plan.target_path)
1280:     try:
1281:         if plan.target_path.read_bytes() != plan.old_cache_bytes:
1282:             raise DeclarationStale(
1283:                 "declaration cache changed after preparation; refusing append"
1284:             )
1285:     except OSError as exc:
1286:         raise DeclarationApplyError(
1287:             f"cannot recheck declaration cache before append: {exc}"
1288:         ) from exc
1289:     data = _intent_data(plan, phase="prepared")
1290:     append_drafts = _drafts_from_exact(
1291:         json.loads(plan.exact_drafts), plan.exact_drafts
1292:     )
1293:     try:
1294:         _write_exclusive_json(intent, data)
1295:     except FileExistsError as exc:
1296:         raise DeclarationApplyError(
1297:             f"unfinished declaration intent already exists: {intent}"
1298:         ) from exc
1299:     if failure_hook:
1300:         try:
1301:             failure_hook("after-intent")
1302:         except Exception as exc:
1303:             raise DeclarationApplyError(
1304:                 "declaration intent was durable but append did not start"
1305:             ) from exc
1306: 
1307:     ledger: Any | None = None
1308:     query: Any | None = None
1309:     commit: Any | None = None
1310:     head: Head | None = None
1311:     append_entered = False
1312:     try:
1313:         ledger, query = registry.open(plan.descriptor)
1314:         try:
1315:             append_entered = True
1316:             commit = ledger.append(plan.captured_head, append_drafts)
1317:         except Exception as exc:
1318:             from .arrival_contract import ContractRefusal
1319:             from .arrival_head_seam import NotWitnessed
1320: 
1321:             if isinstance(exc, ContractRefusal):
1322:                 _remove_intent(intent)
1323:                 raise DeclarationStale(
1324:                     f"declaration append refused before mutation: {exc}"
1325:                 ) from exc
1326:             if isinstance(exc, NotWitnessed):
1327:                 head = exc.head
1328:                 data["phase"] = "append-unwitnessed"
1329:                 with suppress(Exception):
1330:                     _replace_json(intent, data)
1331:                 raise DeclarationUnwitnessed(
1332:                     "declaration records committed but their witness is unknown",
1333:                     head=exc.head, commit=exc.commit, intent_path=intent,
1334:                     fact_ids=plan.fact_ids, cause=exc,
1335:                 ) from exc
1336:             data["phase"] = "append-unknown"
1337:             with suppress(Exception):
1338:                 _replace_json(intent, data)
1339:             raise DeclarationOutcomeUnknown(
1340:                 "declaration append outcome is unknown; recover the intent",
1341:                 head=None, intent_path=intent, fact_ids=plan.fact_ids, cause=exc,
1342:             ) from exc
1343:         head = commit.after
1344:         try:
1345:             data["phase"] = "appended"
1346:             _replace_json(intent, data)
1347:             if failure_hook:
1348:                 failure_hook("after-append")
1349:         except Exception as exc:
1350:             raise DeclarationCommittedIncomplete(
1351:                 "declaration append committed but append phase recording failed",
1352:                 phase="appended", head=head, commit=commit, intent_path=intent,
1353:                 fact_ids=plan.fact_ids, cause=exc,
1354:             ) from exc
1355:     except (DeclarationStale, DeclarationUnwitnessed, DeclarationOutcomeUnknown,
1356:             DeclarationCommittedIncomplete):
1357:         raise
1358:     except Exception as exc:
1359:         if not append_entered:
1360:             raise DeclarationApplyError(
1361:                 "declaration append was refused before entering the append call; "
1362:                 "prepared intent retained for inspection",
1363:             ) from exc
1364:         raise DeclarationOutcomeUnknown(
1365:             "declaration append path failed; recover the intent",
1366:             head=head, intent_path=intent, fact_ids=plan.fact_ids, cause=exc,
1367:         ) from exc
1368:     finally:
1369:         _close_quietly(query)
1370:         _close_quietly(ledger)
1371: 
1372:     try:
1373:         from .arrival_maintenance import sync_projection
1374: 
1375:         sync_projection(registry, plan.descriptor, through=head)
1376:         data["phase"] = "synced"
1377:         _replace_json(intent, data)
1378:         if failure_hook:
1379:             failure_hook("after-sync")
1380:         data["phase"] = "publishing"
1381:         _publish_cache(
1382:             plan, intent=intent, intent_data=data, failure_hook=failure_hook
1383:         )
1384:         data["phase"] = "published"
1385:         _replace_json(intent, data)
1386:         if failure_hook:
1387:             failure_hook("before-intent-remove")
1388:         _remove_intent(intent)
1389:     except Exception as exc:
1390:         raise DeclarationCommittedIncomplete(
1391:             "declaration append committed but a later phase failed; recover the intent",
1392:             phase=str(data.get("phase", "appended")), head=head,
1393:             commit=commit, intent_path=intent, fact_ids=plan.fact_ids, cause=exc,
1394:         ) from exc
1395:     return _result(
1396:         plan, status="applied", head=head, commit=commit, intent=None,
1397:         phase="published", file_written=True, changes=plan.changes,
1398:     )

1415: def _recover_declaration_edit(
1416:     registry: BackendRegistry,
1417:     intent: Path | str,
1418:     *,
1419:     failure_hook: Callable[[str], None] | None = None,
1420: ) -> DeclarationEditResult:
1421:     """Reconcile an edit intent by exact suffix membership, then finish cache."""
1422:     intent_path = Path(intent).resolve()
1423:     data = _read_intent(intent_path)
1424:     drafts = _drafts_from_intent(data)
1425:     plan = _plan_from_intent(data, drafts)
1426:     captured = plan.captured_head
1427:     ledger: Any | None = None
1428:     query: Any | None = None
1429:     try:
1430:         ledger, query = registry.open(plan.descriptor)
1431:         captured_at_ledger = ledger.head_at(
1432:             Watermark(lineage=captured.lineage, ordinal=captured.ordinal)
1433:         )
1434:         if captured_at_ledger != captured:
1435:             raise DeclarationStale(
1436:                 "declaration intent predecessor head hash no longer matches"
1437:             )
1438:         actual = ledger.head()
1439:         if actual == captured:
1440:             if data.get("cache_temp") or data.get("cache_backup"):
1441:                 raise DeclarationApplyError(
1442:                     "unapplied declaration intent has cache publication artifacts"
1443:                 )
1444:             if plan.target_path.read_bytes() != plan.old_cache_bytes:
1445:                 raise DeclarationStale(
1446:                     "unapplied declaration intent has competing cache bytes"
1447:                 )
1448:             _remove_intent(intent_path)
1449:             return _result(
1450:                 plan, status="not-applied", head=actual, commit=None, intent=None,
1451:                 phase="not-applied", file_written=False, changes=None,
1452:             )
1453:         first = captured.ordinal + 1
1454:         for index, draft in enumerate(drafts):
1455:             ordinal = first + index
1456:             if actual.ordinal < ordinal or not _record_matches_draft(
1457:                 ledger.read(ordinal), draft
1458:             ):
1459:                 raise DeclarationStale(
1460:                     "declaration intent does not occupy its exact expected suffix"
1461:                 )
1462:     except DeclarationStale:
1463:         raise
1464:     except Exception as exc:
1465:         raise DeclarationApplyError(
1466:             f"cannot reconcile declaration intent against Arrival custody: {exc}"
1467:         ) from exc
1468:     finally:
1469:         _close_quietly(query)
1470:         _close_quietly(ledger)
1471: 
1472:     file_written = False
1473:     try:
1474:         from .arrival_maintenance import sync_projection
1475: 
1476:         sync_projection(registry, plan.descriptor, through=actual)
1477:         data["phase"] = "synced"
1478:         _replace_json(intent_path, data)
1479:         if failure_hook:
1480:             failure_hook("after-sync")
1481:         if plan.target_path.exists():
1482:             current = plan.target_path.read_bytes()
1483:             if current == plan.proposed_text.encode("utf-8"):
1484:                 _cleanup_cache_artifacts(plan, data)
1485:                 data["phase"] = "published"
1486:                 _replace_json(intent_path, data)
1487:             elif current == plan.old_cache_bytes:
1488:                 data["phase"] = "publishing"
1489:                 _publish_cache(
1490:                     plan, intent=intent_path, intent_data=data,
1491:                     failure_hook=failure_hook,
1492:                 )
1493:                 file_written = True
1494:                 data["phase"] = "published"
1495:                 _replace_json(intent_path, data)
1496:             else:
1497:                 raise DeclarationStale(
1498:                     "competing declaration cache bytes are present; refusing overwrite"
1499:                 )
1500:         elif data.get("cache_backup"):
1501:             data["phase"] = "publishing"
1502:             _publish_cache(
1503:                 plan, intent=intent_path, intent_data=data,
1504:                 failure_hook=failure_hook,
1505:             )
1506:             file_written = True
1507:             data["phase"] = "published"
1508:             _replace_json(intent_path, data)
1509:         else:
1510:             raise DeclarationApplyError(
1511:                 "declaration cache is missing and has no detached recovery backup"
1512:             )
1513:         _remove_intent(intent_path)
1514:     except Exception as exc:
1515:         raise DeclarationCommittedIncomplete(
1516:             "declaration custody is committed but cache recovery remains incomplete",
1517:             phase=str(data.get("phase", "synced")), head=actual, commit=None,
1518:             intent_path=intent_path, fact_ids=plan.fact_ids, cause=exc,
1519:         ) from exc
1520:     return _result(
1521:         plan, status="recovered", head=actual, commit=None, intent=None,
1522:         phase="published", file_written=file_written, changes=None,
1523:     )

478:         # Refuse these collisions before the default custody path creates keys.
479:         validate_arrival_runtime_identity(v_name, ("item",), refusal=SdkValueError)

484:     elif chosen_backend == "file":

492:     # Verification is independent of where signing callables came from.  A
493:     # caller-supplied pair still has to prove both protocol domains against
494:     # the supplied public key before an intent or mint is attempted.
495:     from custody.signing import ARRIVAL_DOMAIN, FACT_DOMAIN
496:     from sign import ed25519

498:     def _verify(domain: str, key: str, signature: str, digest: str) -> bool:
499:         try:
500:             public = ed25519.public_key_from_b64(key)
501:         except ValueError:
502:             return False

506:         return _verify(FACT_DOMAIN, key, signature, digest)

508:     def _arrival_verify(key: str, signature: str, digest: str) -> bool:
509:         return _verify(ARRIVAL_DOMAIN, key, signature, digest)

511:     fact_verify = _fact_verify
512:     arrival_verify = _arrival_verify
513:     if not recover:
514:         # The SDK is the custody owner. An injected signer/key pair is useful
515:         # to headless deployments; absent one, key creation/loading is the
516:         # same explicit custody operation used by the existing init command.
517:         from custody import arrival_signer_for, ensure_signing_key, fact_signer_for
518:         from engine.credentials import (

530:                 )

550:                 arrival_credential = write_credentials.binding_resolver(arrival_request)
551:             except Exception as exc:
552:                 normalized = normalize_exception(exc)
553:                 if normalized is not exc:
554:                     raise normalized from exc
555:                 raise SdkValueError(
556:                     "Arrival initialization could not resolve its pre-created mapped binding"
557:                 ) from exc
558:             if fact_credential is None or arrival_credential is None:
559:                 raise SdkValueError(
560:                     "mapped Arrival initialization requires a pre-created founding binding"
561:                 )
562:             def valid_bootstrap_credential(value: object, request: CredentialRequest) -> bool:
563:                 if not isinstance(value, ResolvedCredential):
564:                     return False
565:                 evidence = value.evidence
566:                 return (
567:                     isinstance(evidence, CredentialBindingEvidence)
568:                     and evidence.request == request
569:                     and all(
570:                         isinstance(item, str) and bool(item)
571:                         for item in (
572:                             evidence.key_ref,
573:                             evidence.algorithm,
574:                             evidence.public_key,
575:                             evidence.provenance,
576:                         )
577:                     )
578:                     and callable(value.sign_digest)
579:                 )

582:             arrival_valid = valid_bootstrap_credential(arrival_credential, arrival_request)
583:             if not fact_valid or not arrival_valid:
584:                 raise SdkValueError(
585:                     "mapped Arrival initialization resolver returned contradictory binding evidence"
586:                 )
587:             if (
588:                 fact_credential.evidence.public_key != arrival_credential.evidence.public_key
589:                 or fact_credential.evidence.key_ref != arrival_credential.evidence.key_ref
590:             ):
591:                 raise SdkValueError(
592:                     "mapped Arrival initialization requires FACT and ARRIVAL bindings with one key"
593:                 )
594:             if public_key is not None and public_key != fact_credential.evidence.public_key:
595:                 raise SdkValueError(
596:                     "mapped Arrival initialization public_key disagrees with its binding"
597:                 )
598:             public_key = fact_credential.evidence.public_key
599: 
600:             def mapped_arrival_signer(author: str, digest: str) -> str | None:
601:                 return arrival_credential.sign_digest(digest) if author == observer else None
602:

+### Recovering an interrupted mapped declaration edit
+
+An edit can raise `CommittedIncomplete` after its declaration records are
+durable but before projection synchronization or local cache publication
+finishes. Its public `details["intent_path"]` identifies the retained recovery
+intent. Use it before deciding whether to retry the proposal:
+
+```python
+from sdk import CommittedIncomplete, edit_declaration, recover_declaration
+
+try:
+    edit_declaration(vertex, proposal, observer="alice", credentials=credentials)
+except CommittedIncomplete as outcome:
+    recovered = recover_declaration(outcome.details["intent_path"])
+```
+
+Recovery reconciles the exact retained suffix, synchronizes the projection,
+and publishes the retained declaration bytes without re-signing or appending
+the proposal again. A recovery result has no original `Commit`; its basis is
+the original captured edit basis. Follow it with `inspect_declaration(vertex)`
+to obtain a fresh effective-declaration/read basis, and use
+`verify_target(vertex)` when the bounded `Full` hash-chain claim is needed.
+The [mapped declaration recovery workload](tests/test_arrival_declaration_recovery_workload.py)
+uses a deterministic injected `after-append` interruption beneath the public
+SDK edit call; it is not a process-kill or crash-survival test.
