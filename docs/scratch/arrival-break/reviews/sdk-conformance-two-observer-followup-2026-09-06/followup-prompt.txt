===== libs/sdk/README.md =====
1: # sdk — Loops Apex Composition Library
2: 
3: `sdk` is the headless composition layer uniting `engine`, `custody`, `lang`, `store`, `atoms`, and `sign` into unified, typed operations. It serves as the single foundation for presentation layers (`apps/loops`, TUI, external agents, Python scripts) without leaking presentation logic into the core substrate.
4: 
5: ---
6: 
7: ## Architectural Guarantees
8: 
9: - **Zero Presentation Logic**: Returns pure typed dataclasses; never formats terminal escape codes or parses CLI flags.
10: - **Descriptor-First Arrival Reads**: An explicitly declared backend and instance role select the adapter; store locations remain opaque to the SDK.
11: - **Visible Legacy Boundary**: Bare `.jsonl`/SQLite inputs remain transitional and every read result labels its path as `legacy` with `basis=None`.
12: - **Witness-Axis Honesty**: Fact listing and pagination use append-order cursors (`WitnessPosition`) ensuring deterministic, non-lossy walks.
13: - **Declared Admission & Attestation**: Fact emission enforces declared observer and kind admission policies, signing with operation-fresh custody keys.
14: - **AST-Verified Ceremonies**: Declarative vertex modifications are verified against the language grammar and executed via transactional plan/apply ceremonies.
15: 
16: ---

18: ## API Reference
19: 
20: ### 1. Target Resolution & Discovery
21: 
22: ```python
23: from sdk import resolve_arrival_target, resolve_target, discover_targets, TargetInfo
24: 
25: # Supported Arrival target: the descriptor carries backend, opaque location,
26: # optional lineage pin, and mandatory instance role.
27: arrival = resolve_arrival_target("path/to/target.vertex")
28: # -> ArrivalTarget(store=StoreDescriptorInfo(backend='file', location='...', role='replica'))
29: 
30: # Single target probe
31: info = resolve_target("path/to/target.vertex")
32: # -> TargetInfo(target_type='vertex', canonical_mode='sqlite', canonical_path=..., index_path=..., exists=True, ...)
33: 
34: # Multi-target workspace discovery
35: targets = discover_targets(".", recursive=True)
36: ```
37: 
38: - **`resolve_target(target: Path | str) -> TargetInfo`**:
39:   Transitional filesystem probe for legacy targets. Raises `TargetNotFound` or `TargetUnsupported`.
40: - **`resolve_arrival_target(target: Path | str) -> ArrivalTarget`**:
41:   Parses an explicit vertex descriptor without probing or normalizing its backend-owned location. It refuses suffix inference and an omitted instance role.
42: - **`discover_targets(root_path=".", *, recursive=True, include_bare=True) -> list[TargetInfo]`**:
43:   Discovers all Loops vertices and bare stores in a directory tree.

104: `read_summary`, `read_facts`, `read_state`, `read_ticks`, and

108: current projection and never materialize, repair, or catch it up. Search,
109: entity resolution, and timelines carry the same captured basis. Aggregate
110: state, summary and timeline results retain per-occurrence member bases rather
111: than inventing one shared head. `sync_target` is the
112: explicit maintenance boundary: it may catch up a missing or behind Arrival

122: inspection retain their current Arrival aggregate restrictions.
123: Legacy targets keep their existing behavior and do not consult the registry.

129: `ExportPublicationError` with `published=True` and the complete artifact's
130: identity. Export requires no current query projection. Import and replication
131: are still pending their explicit initialization/restoration boundary.

135: ### 3. Fact Emission
136: 
137: ```python
138: from sdk import BatchEmitResult, EmitReceipt, emit_batch, emit_fact, preview_emission
139: from atoms import Fact
140: 
141: # Emitting by kind and payload
142: receipt = emit_fact(
143:     "target.vertex",
144:     kind_or_fact="note",
145:     payload={"title": "Meeting Notes", "body": "Discussed SDK API"},
146:     observer="alice",
147: )
148: # Descriptor-first Arrival receipts carry the captured head, durable Commit,
149: # witness state, and post-commit projection status.
150: 
151: # Or preflight dry-run simulation
152: preview = preview_emission("target.vertex", "note", {"title": "Test"}, observer="alice")
153: 
154: # A descriptor-first batch is planned from one snapshot and uses one append.
155: batch = emit_batch(
156:     "target.vertex",
157:     [fact, ("note", {"title": "Batch item"})],
158:     observer="alice",
159: )
160: for receipt in batch.items:
161:     print(receipt.id, receipt.stored)
162: print(batch.commit, batch.atomicity, batch.projection)
163: ```
164: 
165: - **`emit_fact(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, id_override=None, credentials=None, admit_undeclared=False, dry_run=False, registry=None) -> EmitReceipt`**:
166:   Emits a fact (or `Fact` atom) under declared admission rules. Descriptor-first Arrival writes prepare from one CURRENT snapshot, append once against its captured full head, witness the commit, then explicitly synchronize the projection. Bypassing strict kind admission requires `admit_undeclared=True`. Deterministic IDs can be specified with `id_override`. `dry_run=True` simulates emission without storage.
167: - **`preview_emission(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, admit_undeclared=False, credentials=None, registry=None) -> EmitPreviewResult`**:
168:   Simulates emission against declared policies, checking fold key requirements without disk side effects. Arrival policy and fold metadata come from the same bounded effective declaration used for planning; a missing projection refuses without materializing it.
169: - **`emit_batch(target, facts, *, observer=None, origin="", credentials=None, admit_undeclared=False, registry=None) -> BatchEmitResult`**:
170:   Normalizes every item before resolving the target. A descriptor-first Arrival batch derives all per-item admission decisions from one current snapshot, appends the packed records under one head comparison, witnesses one shared commit, and explicitly synchronizes the projection. Each mapping item may set its own boolean `admit_undeclared`; duplicate receipts retain `stored=False`. Empty input is an explicit zero-write result. Legacy targets return the same wrapper with `atomic=False`, `atomicity="legacy-sequential"`, and no invented shared commit; `LegacyBatchPartialFailure` retains receipts if that sequential loop stops after an observable prefix.
171: 
172: `CustodyCredentialProvider()` and `CustodyCredentialProvider(key_dir=None)` use
173: the existing custody resolver. A non-`None` `key_dir` now raises
174: `SdkValueError` during construction because directory overrides were previously
175: accepted but ignored. This applies before either Arrival or legacy operations
176: can use the provider. Callers that need another credential source can continue
177: to supply a custom `CredentialProvider`; that interface does not itself create
178: an observer mapping or register public keys.
179: 
180: For an explicit persisted namespace, use `MappedCredentialProvider` with an
181: Arrival target. Prepare the binding separately from initializing the store:
182: 
183: ```python
184: from pathlib import Path
185: from sdk import MappedCredentialProvider, init_vertex, emit_fact
186: 
187: credentials = MappedCredentialProvider(
188:     Path("/absolute/path/to/private-custody"),
189:     namespace="personal",
190:     receipt_observer="alice",  # explicit local receipt-signing selection
191: )
192: binding = credentials.create_binding("alice", token="bootstrap-alice-1")
193: init_vertex(
194:     Path("observations.vertex"), store_type="arrival", observer="alice",
195:     credentials=credentials,
196: )
197: emit_fact(
198:     Path("observations.vertex"), "item", {"value": 1},
199:     observer="alice", credentials=credentials,
200: )
201: ```
202: 
203: Mapped selection uses the exact namespace and observer, independently of the
204: vertex filename or lineage. The engine checks author keys against verified
205: history through captured H, for use after H, and verifies each signature in its
206: own domain. Receipt signing uses the explicitly selected local observer and
207: the effective declaration's current receipt-key policy; the unsigned outer tick
208: still names the physical genesis custodian. Omitting `receipt_observer` permits
209: unsigned ticks before the signed-tick era, and refuses a required signed tick.
210: A missing author binding may remain unsigned where the existing policy allows;
211: a contradictory or unauthorized binding refuses before append.
212: 
213: Mapped initialization only loads a pre-created binding. For another observer,
214: prepare its binding and pass `key=binding.public_key` to `grant_observer` with
215: the existing author's credentials. Mapped `grant_observer(key=None)` refuses
216: before creating keys. Recovery of an existing Arrival initialization intent
217: signs nothing and does not require private custody to remain available.
218: Mapped providers are supported on Arrival targets; legacy writers explicitly
219: refuse them. The default `CustodyCredentialProvider` remains unchanged.
220: 
221: The runnable [two-observer mapped workload](tests/test_arrival_mapped_workload.py)
222: shows the complete public lifecycle: create Alice and Bob bindings under one
223: persisted provider root and exact namespace; initialize with Alice; grant Bob
224: using Bob's pre-created public key; then emit with both authors. For a locator
225: move that keeps the same physical file-backed store, initialize with an
226: **absolute** `location` and move only the `.vertex` file while retaining its
227: store clause, lineage, and role. Recreate `MappedCredentialProvider` with the
228: same provider root, namespace, and receipt observer before continuing work.
229: The absolute store location keeps the same store residence, while
230: mapped key selection comes only from the provider namespace and exact observer
231: label; neither the vertex filename nor its new directory chooses a key.
232: 
233: After relocation, `verify_target(relocated_vertex)` provides a `Full`
234: verification of the captured prefix's grammar, dense ordinals, lineage, and
235: record-hash chain. It does not establish projection agreement, signature
236: authorship, key trust, or the identity of an observer across lineages. The
237: mapped workload exercises public writes with captured authorization; the
238: [mapped signing tests](tests/test_arrival_mapped_credentials.py) separately
239: verify domain-specific signatures and key-history behavior.
240: 
241: `import_legacy(vertex_path, observer, token=...)` explicitly copies a verified
242: legacy key into managed storage without changing the original. It preserves
243: flat/nested ambiguity and alias refusals. After import, locator moves do not
244: change mapped selection. No read, preview, or signer load imports or creates a
245: binding. `bind_existing_ref(observer, key_ref, expected_public_key, token=...)`
246: permits deliberate reuse of a completed managed key in another namespace;
247: equal observer labels alone never select another namespace's key.
248: See [custody binding recovery](../custody/README.md#explicit-mapped-bindings)
249: for interruption handling and filesystem scope.
250: 
251: Supported Arrival execution reserves the vertex name from its loop names.
252: Every exact name collision refuses, including passive loops, reset/carry loops,
253: and count- or event-triggered boundaries. The runtime also adds an implicit
254: `cite` loop, so a vertex named `cite` cannot execute under this restriction.
255: Runtime capture checks the historized effective declaration and expanded
256: template loop names before hydration and planning; editing only the local cache
257: cannot bypass it. New and proposed declarations check their declared loops and
258: the implicit `cite` loop. The SDK initializer also refuses the name `item`,
259: because its scaffold declares an `item` loop, before creating custody keys.
260: External template sources are expanded and checked at runtime; declaration
261: editing does not load them solely to enforce this rule.
262: 
263: This is an Arrival execution compatibility restriction. Existing histories
264: remain available through evidence reads, declaration inspection and export.
265: A collision-free declaration can be appended to correct an ambiguous current
266: declaration; prior facts and ticks retain their original names and bytes.
267: This does not establish which role an already-recorded ambiguous tick had;
268: historical boundary continuity remains a separate limitation.
269: Legacy runtime behavior and the wire format retain their existing rules.

273: ### 4. Arrival Source Execution
274: 
275: ```python
276: from sdk import run_sources
277: 
278: result = await run_sources("target.vertex", observer="alice", force=False)
279: for tier in result.tiers:
280:     print(tier.outcome, tier.commit, tier.fact_ids, tier.tick_ids)
281: ```
282: 
283: - **`await run_sources(target, *, observer, force=False, credentials=None, registry=None, collector_factory=None, dispatcher=None, evaluated_at=None) -> SourceRunResult`**:
284:   Captures a CURRENT Arrival Authority before collection, fixes cadence and dependency tiers, and commits each collected tier with one exact-head batch append plus explicit projection synchronization. The lifecycle observer is always explicit. Existing custody keys are loaded when present; the operation never creates keys.
285: 
286:   A source error after yielding observations returns `status="error"` after its error lifecycle fact becomes durable. Interrupted results retain prior commits and distinguish `known_uncommitted` collection from an append whose durability is `unknown`; collectors are not rerun. When `dispatcher` is omitted, captured tick run intents remain visible with `dispatch_status="not-requested"` and `attempted=False`. This operation supports explicit single-store Arrival Authority descriptors only and never falls through to legacy source execution.
287: 
288:   Coordinator failures during ID allocation, lifecycle construction, or otherwise successful collector cleanup return an incomplete result with terminal category `collection-failed`. `terminal.details.collection` contains the current tier's basis, `custody="not-attempted"`, completed siblings, and paired partial observations from failed or cancelled siblings. Incomplete attempts have no lifecycle fact; prior tiers keep their commits. These partial observations live in terminal evidence, not `known_uncommitted`, which describes a fully collected tier. Owned iterators and distinct iterable owners receive `aclose()` when available; caller cancellation propagates after sibling cleanup. Closing a collector does not undo its external effects or guarantee subprocess termination.

368: ## Exception Taxonomy
369: 
370: ```mermaid
371: graph TD
372:     SdkError --> TargetError
373:     TargetError --> TargetNotFound
374:     TargetError --> TargetUnsupported
375:     TargetError --> TargetNotWritable
376:     SdkError --> AdmissionFailed
377:     SdkError --> EmissionFailed
378:     SdkError --> SdkValueError
379:     SdkValueError --> InvalidEmissionRequest
380:     EmissionFailed --> InvalidEmissionRequest
381:     EmissionFailed --> CommittedEmissionError
382:     SdkError --> CeremonyFailed
383: ```
384: 
385: - **`SdkError`**: Base class for all high-level SDK exceptions.
386: - **`SdkValueError`**: Base class for SDK parameter and validation errors (inherits from `ValueError`).
387: - **`TargetNotFound`**: Target path does not exist on disk.
388: - **`TargetUnsupported`**: Path exists but is not a recognized Loops artifact.
389: - **`TargetNotWritable`**: Target or derived index cannot be written to.
390: - **`AdmissionFailed`**: Declared admission policy (strict kinds or observer grants) refused the operation.
391: - **`EmissionFailed`**: Fact emission failed prior to committing.
392: - **`InvalidEmissionRequest`**: Invalid emission parameters (missing required observer or invalid shape).
393: - **`CommittedEmissionError`**: Fact was written to storage, but a post-commit task failed (carries `.fact_id`).
394: - **`CeremonyFailed`**: Declaration update AST generation or ceremony apply was refused.
395: 
396: Descriptor-first reads also surface engine contract refusals (for example, a
397: missing or behind projection or an invalid continuation) and declaration
398: resolution errors. These keep the adapter's evidence-bearing refusal intact.
399: 
400: Arrival `sync_target` and `sync_search_index` normalize maintenance failures as
401: `ProjectionOutcomeUnknown`. Their optional `details.evidence` object uses
402: `loops.sdk/evidence/v1`: it records the coordinator phase, resource effects,
403: available head/coverage coordinates, and up to two explicit causal exceptions.
404: Search failures before the build call report derived state as
405: `not-entered`/`not-attempted`; failures after entering build or projection
406: catch-up report `entered`/`unknown`. A nested refusal does not prove that an
407: adapter left derived state unchanged. Existing error outcomes, source types,
408: and operation-specific `details.phase` remain intact. Cause messages are capped
409: at 512 characters; record bodies and implicit exception context are excluded.
410: Declaration preparation refusals carry preparation evidence without claiming a
411: custody append. Cancellation and process-control exceptions propagate unchanged.

217: def _cause_details(exc: BaseException) -> dict[str, Any] | None:
218:     """Two explicit causal nodes, never implicit context or record bodies."""
219:     seen = {id(exc)}
220:     result: dict[str, Any] | None = None
221:     parent: dict[str, Any] | None = None
222:     for _ in range(2):
223:         cause = _causal_exception(exc)
224:         if cause is None or id(cause) in seen:
225:             break
226:         seen.add(id(cause))

+    verify_target,
+)

+@pytest.fixture(autouse=True)
+def _isolated_process_roots(tmp_path: Path, monkeypatch: pytest.MonkeyPatch) -> None:
+    monkeypatch.setenv("XDG_STATE_HOME", str(tmp_path / "state"))
+    monkeypatch.setenv("XDG_CONFIG_HOME", str(tmp_path / "config"))
+    monkeypatch.setenv("LOOPS_HOME", str(tmp_path / "loops-home"))
+
+
+def test_mapped_two_observer_workload_survives_descriptor_relocation(
+    tmp_path: Path,
+) -> None:
+    custody_root = tmp_path / "custody"
+    namespace = "workload-tenant"
+    provider = MappedCredentialProvider(
+        custody_root,
+        namespace=namespace,
+        receipt_observer="alice",
+    )
+    alice = provider.create_binding("alice", token="create-alice")
+    bob = provider.create_binding("bob", token="create-bob")
+    alice_case_alias = provider.create_binding("Alice", token="create-uppercase-alice")
+    assert alice_case_alias.key_ref != alice.key_ref
+    assert alice_case_alias.public_key != alice.public_key
+
+    vertex = tmp_path / "original" / "workload.vertex"
+    store = (tmp_path / "data" / "workload.arrival").resolve()
+    initialized = init_vertex(
+        vertex,
+        name="workload",
+        store_type="arrival",
+        location=store,
+        observer="alice",
+        credentials=provider,
+    )
+    assert initialized.lineage is not None
+    assert initialized.store is not None
+    assert initialized.store.location == str(store)
+
+    before_grant = verify_target(vertex).verified_through
+    assert before_grant is not None
+    assert initialized.head == {
+        "lineage": before_grant.lineage,
+        "ordinal": before_grant.ordinal,
+        "record_hash": before_grant.record_hash,
+    }
+    with pytest.raises(AdmissionFailed) as ungranted:
+        emit_fact(
+            vertex,
+            "item",
+            {"owner": "bob", "phase": "before-grant"},
+            observer="bob",
+            origin="workload-test",
+            ts=9.0,
+            id_override="bob-before-grant",
+            credentials=provider,
+        )
+    assert ungranted.value.observer == "bob"
+    assert ungranted.value.kind == "item"
+    assert verify_target(vertex).verified_through == before_grant
+
+    granted = grant_observer(
+        vertex,
+        "bob",
+        grants=["item"],
+        key=bob.public_key,
+        observer="alice",
+        credentials=provider,
+    )
+    assert granted.status == "applied"
+    assert granted.commit is not None
+    assert granted.commit.before == before_grant
+    assert granted.commit.after.lineage == granted.commit.before.lineage
+    assert granted.commit.after.ordinal > granted.commit.before.ordinal
+
+    batch = emit_batch(
+        vertex,
+        [
+            {
+                "id": "alice-item",
+                "kind": "item",
+                "payload": {"owner": "alice"},
+                "observer": "alice",
+                "origin": "workload-test",
+                "ts": 10.0,
+            },
+            {
+                "id": "bob-item",
+                "kind": "item",
+                "payload": {"owner": "bob"},
+                "observer": "bob",
+                "origin": "workload-test",
+                "ts": 11.0,
+            },
+        ],
+        credentials=provider,
+    )
+    assert batch.atomic is True
+    assert batch.atomicity == "single-append"
+    assert batch.commit is not None
+    assert batch.commit.before == granted.commit.after
+    assert batch.commit.after.lineage == batch.commit.before.lineage
+    assert batch.commit.after.ordinal > batch.commit.before.ordinal
+    assert batch.captured_head == batch.commit.before
+    assert batch.witnessed is True
+    assert batch.projection == "synced"
+    assert [(item.id, item.observer, item.stored, item.signed) for item in batch.items] == [
+        ("alice-item", "alice", True, True),
+        ("bob-item", "bob", True, True),
+    ]
+    assert all(item.captured_head == batch.captured_head for item in batch.items)
+    assert all(item.commit is None for item in batch.items)
+    assert all(item.witnessed is True for item in batch.items)
+    assert all(item.projection == "synced" for item in batch.items)
+
+    first_read = read_facts(vertex, limit=20, order="oldest")
+    assert first_read.basis is not None
+    assert first_read.basis.lineage == initialized.lineage
+    assert first_read.basis.captured_head == batch.commit.after
+    assert first_read.basis.projected_through == first_read.basis.captured_head
+    assert [
+        (item["id"], item["observer"], item["payload"])
+        for item in first_read.items
+    ] == [
+        ("alice-item", "alice", {"owner": "alice"}),
+        ("bob-item", "bob", {"owner": "bob"}),
+    ]
+    first_verified = verify_target(vertex)
+    assert first_verified.captured_head == batch.commit.after
+    assert first_verified.verified_through == first_read.basis.captured_head
+    assert first_verified.claims == ("grammar", "density", "lineage", "hash-chain")
+    assert "signature-authorship" in first_verified.excludes
+
+    relocated = tmp_path / "relocated" / "renamed.vertex"
+    relocated.parent.mkdir()
+    original_declaration = vertex.read_bytes()
+    vertex.rename(relocated)
+    assert relocated.read_bytes() == original_declaration
+
+    reopened = MappedCredentialProvider(
+        custody_root,
+        namespace=namespace,
+        receipt_observer="alice",
+    )
+    for observer, created in (("alice", alice), ("bob", bob)):
+        resolved = reopened.resolve(
+            CredentialRequest(
+                namespace,
+                observer,
+                SigningDomain.FACT,
+                CredentialPurpose.AUTHORSHIP,
+            )
+        )
+        assert resolved is not None
+        assert resolved.evidence.key_ref == created.key_ref
+        assert resolved.evidence.public_key == created.public_key
+    resolved_case_alias = reopened.resolve(
+        CredentialRequest(
+            namespace,
+            "Alice",
+            SigningDomain.FACT,
+            CredentialPurpose.AUTHORSHIP,
+        )
+    )
+    assert resolved_case_alias is not None
+    assert resolved_case_alias.evidence.key_ref == alice_case_alias.key_ref
+    assert resolved_case_alias.evidence.public_key == alice_case_alias.public_key
+    assert resolved_case_alias.evidence.key_ref != alice.key_ref
+
+    relocated_verified = verify_target(relocated)
+    assert relocated_verified.verified_through == first_verified.verified_through
+    relocated_read = read_facts(relocated, limit=20, order="oldest")
+    assert relocated_read.basis == first_read.basis
+    assert relocated_read.items == first_read.items
+    assert relocated_read.store is not None
+    assert relocated_read.store.location == str(store)
+
+    other_namespace = MappedCredentialProvider(
+        custody_root,
+        namespace="other-tenant",
+        receipt_observer="alice",
+    )
+    other_alice = other_namespace.create_binding(
+        "alice", token="create-other-tenant-alice"
+    )
+    assert other_alice.public_key != alice.public_key
+    other_resolved = other_namespace.resolve(
+        CredentialRequest(
+            "other-tenant",
+            "alice",
+            SigningDomain.FACT,
+            CredentialPurpose.AUTHORSHIP,
+        )
+    )
+    assert other_resolved is not None
+    assert other_resolved.evidence.key_ref == other_alice.key_ref
+    assert other_resolved.evidence.public_key == other_alice.public_key
+    with pytest.raises(ArrivalRefusal) as wrong_namespace:
+        emit_fact(
+            relocated,
+            "item",
+            {"owner": "alice", "phase": "wrong-namespace"},
+            observer="alice",
+            origin="workload-test",
+            ts=11.5,
+            id_override="alice-wrong-namespace",
+            credentials=other_namespace,
+        )
+    assert wrong_namespace.value.source_type == "CredentialBindingRefused"
+    credential_refusal = wrong_namespace.value.details["credential_binding"]
+    assert credential_refusal["reason"] == (
+        "resolved public key is not authorized at the captured position"
+    )
+    assert credential_refusal["request"] == {
+        "namespace": "other-tenant",
+        "observer": "alice",
+        "domain": "fact",
+        "purpose": "authorship",
+    }
+    assert credential_refusal["use_position"] == (
+        first_verified.verified_through.ordinal + 1
+    )
+    assert credential_refusal["binding"]["key_ref"] == other_alice.key_ref
+    assert credential_refusal["binding"]["public_key"] == other_alice.public_key
+    assert wrong_namespace.value.details["captured_head"] == {
+        "lineage": first_verified.verified_through.lineage,
+        "ordinal": first_verified.verified_through.ordinal,
+        "record_hash": first_verified.verified_through.record_hash,
+    }
+    assert verify_target(relocated).verified_through == first_verified.verified_through
+
+    with pytest.raises(AdmissionFailed) as wrong_case:
+        emit_fact(
+            relocated,
+            "item",
+            {"owner": "Alice", "phase": "case-alias"},
+            observer="Alice",
+            origin="workload-test",
+            ts=11.75,
+            id_override="uppercase-alice",
+            credentials=reopened,
+        )
+    assert wrong_case.value.observer == "Alice"
+    assert wrong_case.value.kind == "item"
+    assert verify_target(relocated).verified_through == first_verified.verified_through
+
+    continued = emit_fact(
+        relocated,
+        "item",
+        {"owner": "bob", "phase": "relocated"},
+        observer="bob",
+        origin="workload-test",
+        ts=12.0,
+        id_override="bob-after-relocation",
+        credentials=reopened,
+    )
+    assert continued.stored is True
+    assert continued.signed is True
+    assert continued.commit is not None
+    assert continued.commit.before == first_verified.verified_through
+    assert continued.commit.after.lineage == continued.commit.before.lineage
+    assert continued.commit.after.ordinal > continued.commit.before.ordinal
+    assert continued.witnessed is True
+    assert continued.projection == "synced"
+
+    final_read = read_facts(relocated, limit=20, order="oldest")
+    assert final_read.basis is not None
+    assert final_read.basis.lineage == initialized.lineage
+    assert final_read.basis.captured_head == continued.commit.after
+    assert final_read.basis.projected_through == final_read.basis.captured_head
+    assert [
+        (item["id"], item["observer"], item["payload"])
+        for item in final_read.items
+    ] == [
+        ("alice-item", "alice", {"owner": "alice"}),
+        ("bob-item", "bob", {"owner": "bob"}),
+        (
+            "bob-after-relocation",
+            "bob",
+            {"owner": "bob", "phase": "relocated"},
+        ),
+    ]
+    final_verified = verify_target(relocated)
+    assert final_verified.captured_head == continued.commit.after
+    assert final_verified.verified_through == final_read.basis.captured_head
