3: Status: design only. This specifies the evidence required before public SDK
4: normalization is widened; it neither changes wire records nor declares a common

7: 
8: ## What exists now

12: `NotWitnessed` retains its resulting head and an actual `Commit` where the
13: underlying operation supplies one; post-commit projection failures retain their
14: commit. Initialization, declaration recovery, and restore have
15: operation-specific unknown/incomplete wrappers. Source invocation instead
16: returns structured per-tier results, preserving an earlier durable tier while a
17: later tier is uncommitted or unknown.
18: 
19: There are two material gaps. `sync_target` calls `sync_projection` directly and
20: therefore bypasses the existing `ProjectionSyncError ->

23: in-process maintenance caller can inspect the causal exception while an SDK
24: caller cannot identify its stable type or its evidence. The same concern applies
25: to search-index synchronization. Declaration preparation catches a

28: cause today, but public normalization must not erase it.
29:

31: `sync_projection` enters its catch-up attempt, it wraps an ordinary
32: `Exception` as
33: `ProjectionSyncError(target, projected_before, observed_after, cause)`.

35: prove that for every implementation. `SearchIndexSyncError` has the analogous

50: operation exposes only fields it can prove, under its existing names where
51: possible. The new engine attribute is named `coordinator_phase`; only the SDK

61: | `identities` | Planned fact/tick IDs, item or tier index, observer/kind, and a real `Commit` before/after when known. No invented Commit for a no-op or recovery. |
62: | `cause` | A bounded recursive diagnostic: causal type name, message, and the same safe identity coordinates available on that cause. Its exact source and bound are specified below. |

```
74:

77: `not-attempted`, `known-none`, `committed`, `unknown`, `completed`, or

79: resource's mutation boundary. `known-none` is a distinct proof: an entered

93: characters with `truncated=true` when shortened. Never follow `__context__`,
94: call `repr`, or serialize payload/record bodies.
95:
```

```
351:             return AdmissionRefusal(
352:                 str(exc),
353:                 source_type=type(exc).__name__,
354:                 details=details,
355:                 observer=fact.observer,
356:                 kind=fact.kind,
357:                 vertex=exc.effective_declaration.name,
358:             )
359:         return ArrivalRefusal(str(exc), source_type=type(exc).__name__, details=details)
360:     if isinstance(exc, AdmissionError):
361:         return AdmissionRefusal(
362:             str(exc),
363:             source_type=type(exc).__name__,
364:             details=details,
365:             observer=getattr(exc, "observer", None),
366:             kind=getattr(exc, "kind", None),
367:             vertex=getattr(exc, "vertex", None),
368:         )
369:     if isinstance(
370:         exc,
371:         (
372:             AttestationRefusal,
373:             ContractRefusal,
374:             ArrivalError,
375:             ProjectionSyncError,
376:             RuntimeWriteRefused,
377:         ),
378:     ):
379:         return ArrivalRefusal(str(exc), source_type=type(exc).__name__, details=details)
380:     return exc
```

```
178: def sync_projection(
179:     registry: BackendRegistry,
180:     descriptor: StoreDescriptor,
181:     *,
182:     through: Head | None = None,
183:     rebuild: bool = False,
184: ) -> ProjectionSyncResult:
185:     """Advance one projection after normal registry attestation.
186: 
187:     Catch-up is the only supported operation.  Existing inconsistent state is
188:     refused; this coordinator has no path that discards rows or identity
189:     markers.  A projection already at or beyond the target is validated and
190:     reported at its actual prefix without moving backward.
191:     """
192:     if descriptor.role not in (Profile.AUTHORITY, Profile.REPLICA):
193:         raise NotAuthority(
194:             "projection maintenance requires an explicit Authority or Replica role"
195:         )
196: 
197:     ledger, query = registry.open(descriptor)
198:     maintenance: ProjectionMaintenance | None = None
199:     try:
200:         if not isinstance(ledger, AttestedLedger):
201:             raise TypeError("BackendRegistry.open must return an AttestedLedger")
202:         captured = _captured_head(ledger)
203:         target = _verify_target(
204:             ledger, captured, captured if through is None else through
205:         )
206: 
207:         maintenance = registry._maintenance_for(descriptor)
208:         capabilities = maintenance.capabilities()
209:         if rebuild or not capabilities.catch_up:
210:             raise NotSupported(
211:                 "projection rebuild is not supported"
212:                 if rebuild
213:                 else f"backend {descriptor.backend!r} does not support projection catch-up"
214:             )
215:         if capabilities.rebuild:
216:             raise TypeError(
217:                 "first-stage maintenance providers must advertise rebuild=False"
218:             )
219: 
220:         projected_before, before_generation = _snapshot_state(
221:             query, ledger, bound=captured
222:         )
223:         if (
224:             projected_before is not None
225:             and projected_before.lineage == target.lineage
226:             and projected_before.ordinal >= target.ordinal
227:         ):
228:             generation = (
229:                 None
230:                 if projected_before.ordinal > captured.ordinal
231:                 else before_generation
232:             )
233:             return ProjectionSyncResult(
234:                 captured_head=captured,
235:                 target=target,
236:                 projected_before=projected_before,
237:                 projected_after=projected_before,
238:                 view_generation=generation,
239:                 changed=False,
240:             )
241: 
242:         try:
243:             advance = maintenance.catch_up(target)
244:             projected_after = _resolve_head(ledger, advance.after)
245:             if projected_after is None:  # the adapter contract requires one
246:                 raise TypeError("maintenance returned no resulting watermark")
247:             if projected_after.lineage != target.lineage:
248:                 raise NotAuthority("maintenance returned a foreign projection lineage")
249:             if projected_after.ordinal < target.ordinal:
250:                 raise HeadMismatch("maintenance returned a prefix behind its target")
251:             if projected_after.ordinal == target.ordinal and projected_after != target:
252:                 raise HeadMismatch(
253:                     "maintenance returned a same-height head different from its target"
254:                 )
255:             projected_before = _resolve_head(ledger, advance.before)
256:             observed_after, generation = _snapshot_state(
257:                 query, ledger, bound=projected_after
258:             )
259:             if (
260:                 observed_after is None
261:                 or observed_after.lineage != projected_after.lineage
262:                 or observed_after.ordinal < projected_after.ordinal
263:             ):
264:                 raise HeadMismatch(
265:                     "query projection does not reach the prefix maintenance returned"
266:                 )
267:             if observed_after != projected_after:
268:                 # Another serialized maintainer advanced after this handle
269:                 # committed. The first snapshot's generation is bounded at
270:                 # our returned prefix, so it cannot identify the newer view.
271:                 # Report the attested actual prefix and leave generation
272:                 # unknown rather than mislabel it or report success as loss.
273:                 projected_after = observed_after
274:                 generation = None
275:             return ProjectionSyncResult(
276:                 captured_head=captured,
277:                 target=target,
278:                 projected_before=projected_before,
279:                 projected_after=projected_after,
280:                 view_generation=generation,
281:                 changed=advance.changed,
282:             )
283:         except Exception as cause:
284:             observed_after = None
285:             with suppress(Exception):
286:                 observed_after, _ = _snapshot_state(query, ledger, bound=captured)
287:             raise ProjectionSyncError(
288:                 f"projection maintenance through ordinal {target.ordinal} failed; "
289:                 "inspect observed_after before retrying",
290:                 target=target,
291:                 projected_before=projected_before,
292:                 observed_after=observed_after,
293:                 cause=cause,
294:             ) from cause
295:     finally:
296:         if maintenance is not None:
297:             _close_quietly(maintenance)
298:         _close_quietly(query)
299:         _close_quietly(ledger)
```
