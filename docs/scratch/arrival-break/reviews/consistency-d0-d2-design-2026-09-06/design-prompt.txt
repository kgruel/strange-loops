===== docs/scratch/arrival-break/consistency-d0-d2-design-2026-09-06.md =====
1: # D0/D2 explicit credential binding design
2: 
3: Status: proposed design for Fable-low review. No implementation, key, store, or
4: wire-format change has been made by this document.
5: 
6: ## Decision
7: 
8: A signing request has three independent identity inputs:
9: 
10: 1. an exact, explicitly configured local custody namespace;
11: 2. an exact protocol observer label; and
12: 3. an explicit signing domain.
13: 
14: The local binding key is `(namespace, observer)`. All currently supported
15: domains select the same opaque local key reference for that binding. The domain
16: is still present on every request and determines the signature prefix; a FACT
17: signature can never substitute for ARRIVAL or TICK. Domain-specific private-key
18: bindings are a future design, not an implicit option in v1.
19: 
20: The captured verification context is separate. For an existing lineage it
21: contains the captured full Head, successor position, and the keys authorized by
22: that lineage or effective declaration. It is constructed by the engine after
23: the registry has attested the target. It is never an input that lets the local
24: provider infer a namespace or choose another observer.
25: 
26: Equal observer strings in different namespaces do not share a binding.
27: Applications may deliberately bind an existing managed key reference into
28: another namespace, but that is an explicit mutation. Namespace, observer, and
29: public wire strings are compared byte-for-byte as Python strings: no casefold,
30: Unicode normalization, path splitting, or filename derivation.
31: 
32: ## Why the current interface is insufficient
33: 
34: `CredentialProvider.for_write(vertex: Path)` selects only from a mutable
35: locator. `CustodyCredentialProvider.for_write` eagerly constructs three
36: path-based callbacks, and custody derives the flat self observer from the file
37: stem. The callbacks expose neither the chosen key reference nor public-key
38: evidence. SDK preview, ordinary emit, batch emit, and sources all call this
39: interface before the engine captures H. Declaration edit does the same through
40: `_arrival_credentials`.
41: 
42: The runtime then calls those callbacks while planning FACT, ARRIVAL, and TICK
43: commitments. Ordinary runtime does not currently compare the selected local
44: author key with captured lineage key history. Declaration preparation does
45: perform such a check by scanning through captured H and consulting
46: `keys_valid_at(observer, H.ordinal + 1)`.
47: 
48: Initialization and observer grant bypass the provider entirely:
49: `init_vertex` and `grant_observer(key=None)` call
50: `ensure_signing_key`. This must not remain as a hidden legacy-key mutation
51: when a mapped provider is selected.
52: 
53: Relevant source seams:
54: 
55: - `engine.credentials:WriteCredentials, CredentialProvider`;
56: - `sdk.emit:CustodyCredentialProvider` and the preview/ordinary/batch calls;
57: - `sdk.sources:run_sources`;
58: - `sdk.declare:_arrival_credentials, _init_arrival`;
59: - `sdk.kind:grant_observer`;
60: - `engine.runtime_write:capture_runtime, plan_ordinary_write,
61:   plan_batch_from_capture`;
62: - `engine.arrival_sources:prepare_source_invocation,
63:   execute_source_invocation`;
64: - `engine.arrival_declarations:prepare_declaration_edit`; and
65: - `engine.arrival_initialization:initialize_arrival`.

67: ## Neutral engine API
68: 
69: The proposed values live beside `WriteCredentials` in
70: `engine.credentials`. They contain no filesystem or Ed25519 dependency.
71: 
72: ```python
73: class SigningDomain(StrEnum):
74:     FACT = "fact"
75:     ARRIVAL = "arrival"
76:     TICK = "tick"
77: 
78: class CredentialPurpose(StrEnum):
79:     AUTHORSHIP = "authorship"
80:     KEY_INTRODUCTION = "key-introduction"
81:     RECEIPT = "receipt"
82:     INITIALIZATION = "initialization"
83: 
84: @dataclass(frozen=True)
85: class CredentialRequest:
86:     namespace: str
87:     observer: str
88:     domain: SigningDomain
89:     purpose: CredentialPurpose
90: 
91: @dataclass(frozen=True)
92: class CredentialBindingEvidence:
93:     request: CredentialRequest
94:     key_ref: str
95:     algorithm: str
96:     public_key: str
97:     provenance: str
98: 
99: @dataclass(frozen=True)
100: class ResolvedCredential:
101:     evidence: CredentialBindingEvidence
102:     sign_digest: Callable[[str], str]
103: 
104: BindingResolver = Callable[[CredentialRequest], ResolvedCredential | None]
105: SignatureVerifier = Callable[[SigningDomain, str, str, str], bool]
106: ```
107: 
108: The request validates non-empty namespace and observer strings but does not
109: normalize them. `key_ref` is opaque outside the provider. Public outcomes may
110: serialize `CredentialBindingEvidence`; they never serialize the signer,
111: private-key location, or provider root.
112: 
113: `WriteCredentials` gains trailing, constructor-compatible optional fields:
114: 
115: ```python
116: binding_namespace: str | None = None
117: receipt_observer: str | None = None
118: binding_resolver: BindingResolver | None = None
119: signature_verifier: SignatureVerifier | None = None
120: ```
121: 
122: The four mapped fields are an all-or-none coherent mode except that
123: `receipt_observer` is required only when a TICK signature is requested.
124: Existing `tick_signer`, `fact_signer`, and `arrival_signer` remain the
125: legacy mode. If mapped mode is configured, the engine never falls back to a
126: legacy callback for a missing, corrupt, or unauthorized mapped binding.
127: 
128: A mapped SDK provider may still implement `for_write(Path)` for source
129: compatibility, but that method only returns this lazy configuration. It must
130: not load, create, or choose a key. The explicit namespace comes from provider
131: configuration, not from the Path argument.
132: 
133: An internal frozen `CapturedSigningContext` records:
134: 
135: - `captured_head`;
136: - `use_position = captured_head.ordinal + 1`;
137: - verified author-key introductions through H; and
138: - the effective declaration's current receipt-key set.
139: 
140: It remains separate from `CredentialRequest` and is not sent to the provider.
141: 
142: ## Engine resolution and verification rule
143: 
144: The engine signs in this order:
145: 
146: 1. Open and attest the descriptor, capture full H, effective declaration, and
147:    any required projection evidence.
148: 2. Only for mapped credentials, scan the structurally verified custody prefix
149:    through H and build selective key history using the injected signature
150:    verifier. Legacy and unsigned paths do not gain this new prerequisite.
151: 3. Construct the exact request for the commitment being planned.
152: 4. Resolve the binding. Verify that the returned request exactly equals the
153:    offered request and that its key reference, algorithm, and public key are
154:    well formed.
155: 5. Check the public key against the captured authorization policy below.
156: 6. Sign the digest, independently verify the signature using
157:    `signature_verifier(domain, public_key, signature, digest)`, then retain
158:    serializable binding evidence on the plan.
159: 7. Any mismatch refuses before append. It never downgrades a contradictory
160:    binding to unsigned output.
161: 
162: A missing binding is distinct from corruption. Where the existing protocol
163: allows an unsigned ordinary fact/envelope, `None` may retain that behavior
164: and the plan records an unbound/unsigned decision. Declaration edits,
165: initialization, and a TICK in an established signed tick era require a usable
166: binding. Alias, conflict, public-key mismatch, malformed state, or resolver
167: failure always refuses.
168: 
169: ### Authorization table
170: 
171: | Commitment | Request observer/domain | Captured authorization |
172: | --- | --- | --- |
173: | Inner fact, including each batch row | Exact fact author / FACT | That observer's verified lineage keys valid at H+1 |
174: | Outer fact or packed batch | Exact envelope author / ARRIVAL | That observer's verified lineage keys valid at H+1 |
175: | Declaration fact and envelope | Explicit edit author / FACT and ARRIVAL | Edit author's verified lineage keys valid at H+1 |
176: | Key introduction | Explicit introducing author / ARRIVAL | Introducing author's verified lineage keys valid at H+1; the introduced subject is not the signer |
177: | Inner boundary tick | Explicit configured receipt observer / TICK | Returned public key is in the effective declaration's current declared receipt-key set, preserving the existing any-declared-key policy |
178: | Outer tick envelope | No signing request | Observer remains the verified physical genesis custodian and the envelope remains unsigned |
179: | Initialization declaration | Exact founding observer / FACT and ARRIVAL | Planned bootstrap context; both bindings must expose the same public key and verify independently |
180: | Physical genesis | Exact founding observer / ARRIVAL | Planned bootstrap context and requested founding public key |
181: 
182: For authored records, H+1 is sufficient even when a prepared batch expands to
183: several physical records: only keys introduced through H may authorize the
184: operation. A key-introduction draft in the same append cannot authorize a
185: sibling draft. The tick check uses keys declared in the same captured effective
186: declaration, not every key ever introduced into the physical lineage. The
187: request's receipt observer names local selection evidence; it does not change
188: the wire's existing any-declared-key receipt policy or add a signer identity to
189: the tick row.
190: 
191: ## Runtime integration
192: 
193: `capture_runtime` accepts the mapped verifier configuration and conditionally
194: retains immutable key-history evidence on `RuntimeCapture`. New fields are
195: trailing/defaulted so existing direct test construction and legacy callers
196: remain compatible.
197: 
198: `prepare_ordinary_write` captures before resolving either author domain.
199: The low-level `plan_ordinary_write` may continue accepting legacy callbacks,
200: but mapped credentials without a captured signing context refuse rather than
201: sign without authorization evidence.
202: 
203: `prepare_batch_write` captures once. `plan_batch_from_capture` resolves
204: FACT and ARRIVAL for each exact author and TICK for the explicit receipt
205: observer. Repeated requests may be cached only within that one captured
206: planning operation and only by the complete request value.
207: 
208: Source invocation resolves nothing before initial capture. Preflight uses the
209: initial context. Later dependency tiers recapture H, rebuild key evidence, and
210: resolve again before planning that tier. A binding change after collection
211: therefore causes a retained known-uncommitted tier refusal; collectors are not
212: rerun. One credential resolution must not be cached across tier captures.
213: 
214: Declaration preparation keeps its existing full-prefix selective registry.
215: Its signer helper changes to the mapped request path when configured, retaining
216: the current H+1 author check and independent FACT/ARRIVAL signature
217: verification. A no-change declaration plan need not resolve a signer.
218: 
219: Preview performs the same captured checks and may compute signatures in memory,
220: but provider resolution is read-only: it cannot create a key, binding, intent,
221: directory, or convenience public-key file.
222: 
223: Public plans/results should add ordered binding decision evidence for signatures
224: they actually attempted. This is additive evidence, not a new identity claim.
225: 
226: ## Explicit mapped filesystem provider
227: 
228: The v1 mapped provider is separately configured with:
229: 
230: - a provider root;
231: - one exact custody namespace; and
232: - an optional exact receipt observer.
233: 
234: It does not accept a vertex-derived default namespace. `CustodyCredentialProvider`
235: remains the explicitly documented legacy adapter; C4's rejection of non-None
236: `key_dir` remains in force.
237: 
238: ### Storage
239: 
240: Filesystem slot names are hashes of length-framed UTF-8 bytes, never encodings
241: that are later treated as identity:
242: 
243: ```text
244: <provider-root>/
245:   bindings-v1/<sha256(frame(namespace, observer))>.json
246:   keys-v1/<opaque-key-ref>/ed25519.key
247:   keys-v1/<opaque-key-ref>/ed25519.pub
248:   intents-v1/<operation-token>.json
249: ```
250: 
251: A binding record contains at least:
252: 
253: ```json
254: {
255:   "schema": "loops.custody/binding/v1",
256:   "namespace": "<exact string>",
257:   "observer": "<exact string>",
258:   "key_ref": "<opaque provider ref>",
259:   "algorithm": "ed25519",
260:   "public_key": "<raw-32-byte base64>",
261:   "provenance": "created|legacy-import|existing-ref"
262: }
263: ```
264: 
265: The loader recomputes the slot hash from the exact stored strings, confines the
266: key reference beneath the provider root, refuses symlinks and non-regular
267: files, loads the private key, derives its public key, and compares it with the
268: binding. If `ed25519.pub` exists it must also match. A missing convenience
269: public file is not created during resolution. This avoids
270: `ed25519.load_or_generate` silently repairing a mismatched public file before
271: the binding can be checked.
272: 
273: A binding is domain-independent in v1. Every domain request for the same
274: namespace/observer returns the same key ref and public key while constructing a
275: domain-specific signer. A provider returning different refs across domains is
276: corrupt.
277: 
278: ### Atomic creation and concurrency
279: 
280: Creation requires an explicit operation token and follows a recoverable state
281: machine:
282: 
283: 1. Publish a complete, fsynced creation-intent file using a temp file plus
284:    no-clobber hard link, then fsync the parent. The intent fixes namespace,
285:    observer, candidate key ref, and creation/import source. A repeated token
286:    must match exactly.
287: 2. Create the candidate key object under its unique ref. Publish complete key
288:    files before any binding can name them and fsync the key directory.
289: 3. Build and fsync the complete binding JSON in a temporary file.
290: 4. Publish the binding slot with a no-clobber hard link and fsync its parent.
291:    Never create the final slot and then write into it.
292: 5. If this candidate won, mark the intent complete atomically. If another
293:    creator won, load and validate that winner, mark this intent lost, and
294:    remove this candidate only after proving no binding references it.
295: 
296: A crash before the intent has no durable effect. A crash after intent but
297: before binding is resumed with the same candidate key ref; another call for the
298: same namespace/observer discovers the pending intent and must resume or
299: explicitly reconcile it rather than minting a fresh candidate. A crash after
300: binding publication is reconciled by comparing the slot with the intent.
301: Unreferenced candidates with durable intents are recoverable; anonymous temp
302: files are removable. Garbage collection is an explicit maintenance operation,
303: never part of signer loading.
304: 
305: Two creators with different tokens may prepare candidates, but exactly one
306: complete binding slot wins. Losers return the validated winning binding; they
307: never overwrite it. A pre-existing binding with different requested public
308: material is a conflict, not a rotation. Rotation and revocation remain outside
309: D2.
310: 
311: `bind_existing_ref(namespace, observer, key_ref, expected_public_key, token)`
312: supports deliberate reuse of one already-managed key across namespaces. It
313: performs the same validation and exclusive publication and never infers reuse
314: from equal observer labels.
315: 
316: ### Explicit legacy onboarding
317: 
318: Mapped resolution never scans `<vertex>/keys`. A separate explicit import
319: ceremony receives the legacy vertex path, exact observer, destination
320: namespace, and operation token. It:
321: 
322: 1. invokes the current flat/nested resolver without minting;
323: 2. preserves its missing-versus-alias/ambiguity distinction;
324: 3. derives public material from the private key and refuses a malformed or
325:    mismatched existing `.pub`;
326: 4. copies the private material into a new managed key object with restrictive
327:    permissions, leaving the legacy files untouched; and
328: 5. publishes one mapped binding through the creation state machine.
329: 
330: The copy is an explicit custody mutation and must be reported. It is not run by
331: reads, preview, signer loading, write fallback, locator move, or declaration
332: inspection. Existing labels that the path layout cannot represent cannot be
333: auto-imported; they can receive a new mapped binding through explicit creation.
334: After import, moving the vertex locator does not change the mapped selection.
335: 
336: ## Initialization and observer grant
337: 
338: Initialization has no captured existing H. A mapped provider creates or loads
339: the founding binding using a planned bootstrap context containing the target,
340: pending lineage, founding observer, and operation token. This happens before
341: the engine's durable initialization intent, so documentation and results must
342: call it planned, not reserved.
343: 
344: FACT and ARRIVAL requests must resolve the same public key. The existing engine
345: then verifies both domain signatures against that key before it reserves the
346: initialization intent. Recovery continues to use the exact signatures already
347: stored in that intent and signs nothing.
348: 
349: The first D2 slice should not change the v1 initialization-intent schema merely
350: to duplicate the custody receipt. Existing intents lack such a field and the
351: current observer, public key, and exact signatures already suffice for engine
352: recovery. The binding slot and its own creation intent are the durable local
353: receipt. Recovery must remain possible without re-resolving private custody;
354: a later mismatched binding affects future writes, not completion of an already
355: reserved bootstrap. Adding optional cross-links to both intents is a later
356: versioned evidence improvement.
357: 
358: For `grant_observer(key=None)`, a mapped provider must invoke explicit mapped
359: creation and use its returned public key in the proposed declaration. It must
360: never call legacy `ensure_signing_key`. If the SDK cannot carry a mapped
361: creation request and receipt in the first implementation slice, it must refuse
362: before touching either key layout. Supplying an explicit public key continues
363: not to imply possession of its private key or create a local binding.
364: 
365: A created binding may survive a later declaration or initialization refusal.
366: That is an honest, separately reported custody effect, not a reason to delete a
367: potentially reused key.
368: 
369: ## Legacy compatibility and migration boundary
370: 
371: The following remain transitional behavior:
372: 
373: - `CustodyCredentialProvider()` and explicit `None` use current path/stem,
374:   flat-self, and exact nested-observer lookup;
375: - missing legacy material may yield unsigned output where currently legal;
376: - filesystem aliases, symlinks, unsafe components, and conflicting flat/nested
377:   self keys keep refusing;
378: - legacy `engine.handle` and `engine.ceremony` retain
379:   `CredentialProvider.for_write(Path)`; and
380: - directly supplied legacy `WriteCredentials` retain callback semantics.
381: 
382: These paths do not claim stable D0 namespace binding. They receive no automatic
383: migration and no new key-history scan prerequisite. Documentation must say a
384: locator move is stable only for an explicitly mapped provider after onboarding.
385: 
386: Mapped mode is opt-in. Once selected for an operation, there is no fallback to
387: legacy directories or callbacks. This prevents a corrupt binding from being
388: laundered into an unsigned or differently keyed write.
389: 
390: ## Failure and result evidence
391: 
392: Introduce a typed precommit `CredentialBindingRefused` carrying the exact
393: request, captured Head/use position when present, reason code, and safe binding
394: evidence when available. It must not expose private paths. Suggested reasons
395: are `missing-required`, `corrupt-binding`, `request-mismatch`,
396: `unauthorized-public-key`, `signature-invalid`, `receipt-key-undeclared`,
397: and `recovery-required`.
398: 
399: Provider corruption and authorization disagreement refuse before signing or
400: append. Provider `BaseException` identity is preserved. Ordinary absence that
401: legally produces unsigned output is an explicit decision rather than an error.
402: Postcommit failure taxonomy is unchanged because credential work finishes
403: before append.
404: 
405: Creation/import results separately report operation token, winning key ref and
406: public key, whether a key object or binding was created, and whether another
407: creator won. Outcome-unknown errors retain the intent path/token and candidate
408: ref so callers reconcile instead of retrying with a new key.
409: 
410: ## Implementation order and acceptance
411: 
412: A bounded implementation should proceed in four reviewed slices:
413: 
414: 1. Add neutral request/evidence types and lazy mapped fields while preserving
415:    constructors and all legacy behavior.
416: 2. Add the mapped filesystem provider and creation/import recovery tests,
417:    without routing SDK defaults to it.
418: 3. Integrate conditional captured verification into ordinary, batch, source,
419:    and declaration preparation; expose an explicit SDK mapped provider.
420: 4. Integrate initialization and observer grant through explicit mapped creation,
421:    retaining old initialization recovery.
422: 
423: Required tests include:
424: 
425: - exact case- and Unicode-distinct namespaces/observers without path semantics;
426: - FACT/ARRIVAL/TICK domain separation and same-key-ref v1 policy;
427: - captured H+1 authorization, unauthorized replacement refusal, and no
428:   within-batch introduction authorization;
429: - current-declaration any-key receipt validation distinct from author history;
430: - provider resolution only after H, and source re-resolution per later tier;
431: - preview/read/load causing zero persistence;
432: - missing unsigned versus corrupt refusal;
433: - complete-temp/no-clobber binding publication, concurrent winner, every crash
434:   phase, same-intent recovery, loser cleanup, and explicit orphan maintenance;
435: - malformed/mismatched `.pub`, private/public mismatch, symlink and slot-payload
436:   mismatch refusal;
437: - explicit legacy flat/nested import preserving current ambiguity rules;
438: - deliberate existing-ref reuse across namespaces;
439: - locator move after mapped onboarding;
440: - initialization FACT/ARRIVAL same-public requirement and recovery with old
441:   intents; and
442: - mapped `grant_observer` creation or pre-effect refusal, never hidden legacy
443:   key generation.
444: 
445: ## Judgment issues for review
446: 
447: 1. **Receipt observer configuration.** The design requires an explicit provider
448:    `receipt_observer`. It deliberately does not infer one from vertex name,
449:    boundary name/origin, fact author, or physical custodian. A product surface
450:    must decide where users configure it.
451: 2. **Legacy onboarding copies private material.** Copying into managed storage
452:    makes locator moves stable and leaves the original untouched, but duplicates
453:    a secret. An external-reference key ref avoids duplication but does not
454:    survive moving the old key directory. This design chooses explicit secure
455:    copy and requires the operation to report it.
456: 3. **Initialization intent cross-link.** The first slice keeps its proven v1
457:    recovery format unchanged. A later schema may cross-link the custody intent
458:    for richer provenance, but recovery must remain compatible with old intents.
459: 4. **Unsigned mapped absence.** Existing ordinary unsigned behavior is retained.
460:    If the product wants selecting mapped mode to require signatures for every
461:    author, that is a separate policy flag; it must not be smuggled into D0.
462: 5. **Cost.** Verified key-history scanning is conditional on mapped signing and
463:    may be O(N). A backend-neutral authenticated key-history query can optimize
464:    it later without changing the request or authorization rule.

11: The guiding decision is to keep identity, evidence about identity, and local
12: ways of finding that evidence separate. An observer can interpret several
13: stores together without those stores acquiring one clock, one authority, or
14: one shared authentication namespace.
15: 
16: ## Existing distinctions to retain
17: 
18: | Concept | Existing evidence / scope | What it does not establish |
19: | --- | --- | --- |
20: | Physical lineage | Genesis opens one ordered history; the Arrival declaration anchor must name that same lineage. | A filesystem location, a global observer, or the identity of every vertex that reads it. |
21: | Full head | `(lineage, ordinal, record_hash)` identifies a custody prefix. | The meanings of its observations or the correctness of projected rows merely claiming its ordinal. |
22: | Projection watermark and generation | The watermark is resolved through custody; generation detects changes to a derived view. | A watermark alone is not history proof; generation is not a durable semantic vertex ID. |
23: | Observer label | Exact string in the fact/envelope under its record-kind profile. | A globally authenticated person, a key fingerprint, or a local pathname. |
24: | Key history | One lineage's verified introductions authorize named keys for named observers at later ordinals. | Global equivalence between equal labels, or automatic revocation of older keys. |
25: | Origin | Opaque provenance label; current local runtime also uses exact nonempty vertex name equality to recognize its ticks. | A globally unique vertex ID or an authentication claim. |
26: | Descriptor binding | Backend-owned location interpretation and witness binding evidence. | Identity inferred from filename suffix, or permission to mutate merely because bytes are writable. |
27: | Aggregate member occurrence | A position in one captured composition with its own read basis. | A new physical lineage, a globally stable occurrence ID, or a single instant shared by members. |

37: ## D0 — Name the credential-binding scope before designing its storage
38: 
39: **Working recommendation:** a local binding is selected by a provider-owned
40: custody namespace and exact observer label, with explicit signing-domain
41: selection. Its value is an opaque key reference and enough public evidence to
42: check the requested signing claim. The custody namespace is explicit local
43: configuration; it is not silently derived from the vertex filename, declaration
44: name, or physical lineage. A provider may deliberately reuse a key reference
45: across namespaces/lineages, but equal observer labels do not authorize that reuse.
46: 
47: Separate this local selection from the verification context: an existing
48: lineage's captured H and the intended record position determine which historical
49: keys can substantiate a claim. In particular, a key introduced at H is available
50: for a successor at H+1, not retroactively valid for the record at H. Existing
51: declaration preparation uses `keys_valid_at(observer, H.ordinal + 1)`.
52: 
53: | Request | Identity input and evidence |
54: | --- | --- |
55: | Fact / batch authorship and author envelope | Exact input author; verification context belongs to the relevant captured lineage. Do not substitute vertex name or founding observer. |
56: | Declaration edit | Explicit edit author and key introduced through H, valid for the proposed successor. This is not a new administrative-grant rule. |
57: | Inner tick receipt signing | An explicitly selected receipt-signing capability under its established verification policy. Do not infer the signer from boundary `name` or `origin`. |
58: | Outer tick custodian label | Physical genesis observer under the existing wire profile; envelope remains unsigned. This label does not make every author or inner tick signer the genesis observer. |
59: | Initialization | Explicit requested founding observer, pending lineage and reserved bootstrap intent; no fabricated pre-genesis H. Founding observer and vertex name need not be equal. |
60: 
61: Today `CredentialProvider.for_write(vertex: Path)` cannot express this request;
62: the returned callbacks expose no general public-key binding evidence. Designing
63: the request and a compatibility adapter is a prerequisite to the persisted
64: mapping in D2. Keep location available for ingress/legacy discovery, but do not
65: use it as the new identity input. The new request type and persistence schema
66: remain unimplemented; this decision defines their separation, not a wire change.
67: 
68: ## D1 — Observer identity survives changes of key and location
69: 
70: **Recommendation:** keep the exact observer label as the protocol's named
71: identity within its explicit verification context. Resolve local signing
72: material through an explicit binding for that observer and signing domain.
73: A key rotation, key relocation, vertex-file move, or display-name change must
74: not implicitly change that binding.
75: 
76: Cross-store authentication needs the source key history and the position at
77: which a claim is checked. Equal `observer="alice"` strings in two lineages
78: alone do not prove the same author. A vertex may group them for its own
79: purposes, but that interpretation should not be reported as cryptographic
80: identity. An application can append an explicit association with provenance
81: when it wants to preserve that conclusion.
82: Such an association remains application evidence; it is not, by itself,
83: cryptographic proof of cross-lineage identity.
84: 
85: This does not require replacing strings with global UUIDs or equating an
86: observer with one public key. The existing protocol supports additional keys
87: under the same observer. Its introduction rule is additive: old keys remain
88: valid under that rule. Selecting a new local signing key and revoking an old
89: key are separate operations; this pass does not invent revocation semantics.
90: 
91: **Bounded next implementation:** specify a provider request containing the
92: explicit observer/domain and the relevant declared identity context. Resolve
93: an opaque key reference internally. Keep FACT, ARRIVAL and tick commitments
94: separate. Preserve operation-fresh credential acquisition and forbid key
95: creation during reads, previews, and signer loading.
96: The provider must expose enough public-key evidence for a path claiming
97: authorized signing to check the binding against captured key history. An
98: arbitrary signer callback or a replacement local key alone does not establish
99: a valid rotation. Ordinary unsigned observations remain legal where the
100: operation's policy permits them.
101: 
102: ## D2 — Preserve existing custody bindings explicitly
103: 
104: **Recommendation:** evolve the filesystem provider toward a persisted mapping
105: from exact observer identity to opaque key references. Keep filenames private
106: to that provider. This removes the need for every legal protocol label to be
107: representable as an exact directory spelling.
108: 
109: The current flat/nested resolver is a compatibility implementation, with
110: deliberate refusal of ambiguous keys and filesystem aliases. Do not weaken
111: those refusals to make a migration convenient. The next provider design must
112: specify:
113: 
114: 1. How an existing flat key is bound to its existing self observer before a
115:    file rename can change the lookup convention.
116: 2. How exact nested identities retain their keys, including distinct labels
117:    that a filesystem would otherwise alias.
118: 3. How conflicting mappings or mismatched public material refuse without
119:    minting, overwriting, or silently choosing a winner.
120: 4. How explicit creation publishes one binding and one winning private key
121:    under concurrent creators, and how interruptions are reconciled.
122: 
123: An encoded filename without a recorded/verifiable binding is not a complete
124: migration plan. No key files or live stores are moved in this pass. Arbitrary
125: label portability on a normalizing filesystem remains unimplemented.
126: 
127: An immediate, smaller correction precedes that design: the SDK currently
128: accepts `CustodyCredentialProvider(key_dir=...)` but ignores the value.
129: Recommend an explicit configuration refusal for non-`None` values until a
130: consistent override is supported, rather than continuing to select default
131: keys silently. This is an API compatibility change to document and test; it
132: does not require a key migration. Repository call sites currently use the
133: default constructor; external callers are unknown, so release notes must still
134: describe this compatibility change.
135: 
136: ## D3 — Vertex continuity is distinct from residence and declaration version
137: 
138: **Recommendation:** a vertex's continued identity should survive moving its
139: locator and editing its interpretation. Its declaration revision describes
140: how that vertex interprets captured facts. Here “revision” means the bounded
141: declaration documents/anchor and H, not an existing public revision-ID type.
142: Neither physical lineage nor the
143: hash of that revision should automatically serve as the vertex's identity:
144: storeless and multi-store vertices make both substitutions inadequate.
145: 
146: Current support is narrower. Historized documents supply the effective name;
147: runtime ticks use that name as origin. `lang.document.diff_documents` already
148: refuses post-genesis vertex renames as routine edits, and Arrival declaration
149: preparation uses that function. Retain that restriction. Local custody still
150: derives self from the locator stem, so moving a file can change credential
151: selection even when its declared identity stays fixed. Any future semantic
152: rename also has to account for tick ownership by origin; present support is
153: not a durable identity/alias mechanism.
154: 
155: For the next bounded pass, preserve the existing semantic name and make
156: credential binding independent of the locator. Treat runtime identity rename
157: as an explicit continuity operation requiring a separate design. Do not
158: silently translate historical origins or reinterpret a new name as an alias.
159: A future durable vertex identifier needs a recorded association to existing
160: names and a policy for storeless vertices; it is not a prerequisite for fixing
161: the current credential configuration and boundary ambiguity.
162: 
163: ## D4 — Boundary identity must be unambiguous within a runtime identity
164: 
165: **Recommendation for the current wire profile:** initially reserve the vertex
166: name from the loop-name namespace: refuse any loop whose name equals its
167: vertex name on supported Arrival runtime execution and proposed declarations.
168: This is an explicit compatibility restriction, not a new protocol label rule.
169: It covers both production and interpretation of indistinguishable local ticks,
170: including passive/reset loops and loop ticks mistaken for a vertex period edge.
171: Validate the effective declaration before planning; validating only
172: the mutable local file would leave adopted history able to bypass the rule.
173: Apply the same validation to new/proposed declarations. Do not silently
174: rename a loop or edit historical ticks.
175: 
176: Conceptually a boundary needs `(vertex identity, boundary role, boundary name)`.
177: The existing tick profile supplies `origin` and `name`, and cannot always
178: distinguish the role. Refusal is a bounded way to make the supported subset
179: unambiguous. Adding a role or a new boundary ID to the wire profile would need
180: an explicit compatibility decision, including old histories that contain
181: collisions. Existing ambiguous histories should remain available for evidence
182: inspection even if runtime execution refuses them.
183: 
184: The refusal predicate must cover both tick production and hydration: current
185: `hydrate_snapshot` looks up every owned tick by loop name, even if that loop
186: has no independent boundary trigger. Test same-named passive, count-triggered,
187: and other boundary forms. Any later relaxation of the initial name reservation
188: needs evidence that those configurations cannot be interpreted ambiguously. Share
189: the semantic validator across supported Arrival construction/capture and
190: declaration preparation; do not make it a guard only in one SDK command.
191: 
192: The recent origin guard is retained: foreign and originless ticks are visible
193: evidence but do not consume a local boundary. Event timestamp and receipt
194: position retain their distinct roles; a tick's fact cursor is not a global
195: consumption cutoff.
196: 
197: ## D5 — Declaration edits preserve history; reset must be explicit
198: 
199: **Recommendation:** editing a fold or its presentation appends a new
200: interpretation. It does not rewrite prior facts/ticks or automatically mint a
201: new observer, lineage, or boundary. Capture records the effective declaration
202: used for that operation; a later read may apply a later declaration and reach
203: a different conclusion honestly.
204: 
205: The accepted [C6 boundary design](consistency-c6-boundary-design-2026-09-06.md)
206: defines that continuity policy; the [implementation](consistency-c6-2026-09-06.md)
207: is complete and accepted after Fable-low review. An ordinary
208: in-place trigger/count/mode, fold, parse, route, or presentation edit inherits
209: the existing boundary's recorded consumption. Current replay folds facts under
210: the new interpretation; it does not deserialize old tick payloads as state.
211: An old tick can therefore exhaust a newly selected `after` mode, while a changed
212: repeating count resumes from that recorded edge and subsequent routed facts.
213: The C6 conformance table states these behaviors without inventing a restart.
214: 
215: A runtime name removed and later recreated cannot silently consume ticks from
216: its former membership interval. History analysis includes intermediate
217: self-lineage declaration revisions, implicit `cite`, and generated names whose
218: membership can be established from recorded literals or verified pinned
219: parameter bytes. Environment-derived historical names remain unproven.
220: A historical loop/vertex collision refuses when the target consumes its
221: ambiguous vertex-period stream. A corrected target without that consumer can
222: run; reintroducing the consumer does not recover the missing role evidence.
223: Evidence reads remain available.
224: 
225: Explicit restart, state carry, same-name incarnation cutover, and semantic
226: vertex rename still need a separately recorded transition design. A fresh loop
227: name establishes a distinct future tick identity but no cutoff for old facts.
228: Do not substitute a declaration hash as boundary identity: unrelated or cosmetic
229: edits must not reopen consumed observations. The existing post-genesis vertex
230: rename refusal remains. Credential-request and persisted-binding work in D0/D2
231: is separate from this boundary implementation.
232: 
233: ## D6 — Result identity describes evidence and actions separately
234: 
235: **Recommendation:** keep one outcome vocabulary across public operations, with
236: operation-specific evidence. A known actual Commit is retained; an unknown
237: append outcome is not a refusal or a successful retry. A recovered operation
238: may be complete without the recovering invocation possessing its original
239: Commit. It may also find an already-published cache without writing it.
240: 
241: Read bases, projection observations, durable append receipts, witness state,
242: and artifact-publication state answer different questions. They should be
243: consistently named and serialized, not flattened into a universal success
244: boolean. The matrix defines the intended comparison points and proposed
245: cross-operation checks.
246: 
247: Normalization must preserve evidence of a known pre-mutation refusal when it
248: exists, including the underlying cause and the operation phase. An exception
249: type alone cannot prove no write: the same refusal type might follow a
250: maintainer invocation or a post-write check. Unknown derived effects remain
251: unknown until adapter/coordinator evidence resolves them. Align that evidence
252: before mechanically routing more public calls through a normalizer that may
253: discard the cause.
254: 
255: ## Order of work
256: 
257: First align captured-basis validation, including same-height hash disagreement,
258: and unchanged exception propagation; registry injection can proceed independently.
259: Specify maintenance failure phase/cause evidence before broadening normalization.
260: Then make ambiguous boundary execution refuse with useful evidence and design
261: the D0 credential request before the explicit custody-binding provider and its
262: compatibility path. Stabilize these with public SDK
263: conformance before retiring the competing legacy entrypoints. Durable vertex
264: IDs, boundary incarnations, revocation, and cross-lineage identity association
265: remain separately reviewable designs, not hidden additions to this pass.

1: # D0/D2 code audit: credential requests and local binding persistence
2: 
3: ## Current seams
4: 
5: The neutral engine contract is deliberately callback-only:
6: `engine.credentials.WriteCredentials` has independent tick, inner-fact, and
7: outer-Arrival signer callables; `CredentialProvider.for_write(vertex: Path)`
8: has only a mutable locator input
9: ([credentials.py:18-36](../../../libs/engine/src/engine/credentials.py)). It carries
10: no provider namespace, requested observer, opaque reference, public key, or
11: captured lineage/position. That cannot represent D0's binding selection or
12: supply public evidence for checking it.
13: 
14: SDK `CustodyCredentialProvider.for_write` selects from the vertex path and
15: builds all three callbacks at once
16: ([emit.py:92-107](../../../libs/sdk/src/sdk/emit.py)). It correctly keeps domains
17: separate. It still lets the callback select an author only after receipt
18: planning. The currently refused `key_dir` override is correctly not a
19: namespace substitute (C4).
20: 
21: Arrival call sites that must migrate as one coherent contract are:
22: 
23: | Entrypoint | Current credential seam |
24: | --- | --- |
25: | preview, ordinary emit, batch | `sdk.emit` calls `for_write(target_path)` before the engine prepare call (emit.py:183, 425, 682). |
26: | source invocation | `sdk.sources` calls it once before source planning (sources.py:456-63). |
27: | declaration/kind/grant/revoke edits | `sdk.declare._arrival_credentials` accepts either a raw `WriteCredentials` or `for_write(vertex)`; `sdk.kind` routes edits through it. |
28: | legacy held writer/ceremony | `engine.handle.receive` calls it per write (handle.py:1500); ceremony reads only `.fact_signer` (ceremony.py:562). These are compatibility consumers. |
29: | initialization and observer keygen | SDK directly calls `ensure_signing_key` and signer factories (declare.py:510-19; kind.py:506-15), bypassing the provider. |
30: 
31: Runtime uses the supplied fact signer for inner rows, Arrival signer for fact
32: and packed-batch envelopes, and tick signer for generated ticks
33: ([runtime_write.py:669-75, 973-88, 1011-20, 1284-92](../../../libs/engine/src/engine/runtime_write.py)).
34: The tick envelope's custodian remains a separate physical-genesis wire field;
35: the provider must not infer an inner tick signer from it.
36: 
37: ## Current custody compatibility behavior
38: 
39: `custody.signing` maps a vertex path to `<parent>/keys`. The flat key is
40: only the exact locator stem's self key; other observers use exact nested path
41: components. `_observer_key_dir` rejects invalid/reserved components, case
42: aliases, symlinks, and regular-file components; `_self_key_dir` refuses
43: different flat/nested public keys but permits identical copies
44: ([signing.py:39-183](../../../libs/custody/src/custody/signing.py)). Missing key
45: material is an honest unsigned result; ambiguous/aliased material raises.
46: A new provider must preserve that distinction rather than minting or borrowing
47: a key on an unresolved mapping.
48: 
49: This layout is a compatibility resolver, not a D0 identity model: it derives
50: self identity from the vertex filename and selects nested references by a
51: filesystem spelling. In particular, initialization before its vertex exists
52: uses the future filename stem. If founding observer differs, its nested
53: fact/Arrival key can exist while `tick_signer_for` selects no self key.
54: That is current permitted unsigned-tick behavior, but it proves why tick
55: selection needs an explicit request rather than a filename rule.
56: 
57: D2 also cannot treat `ed25519.pub` as trusted mapping evidence today:
58: `sign.ed25519.load` reads only `ed25519.key`, and
59: `load_or_generate` then rewrites the convenience `.pub` file
60: ([ed25519.py:146-69](../../../libs/sign/src/sign/ed25519.py)). A migration/binding
61: validator must derive public material from the private key and refuse a
62: present mismatching or malformed `.pub` before it invokes that convenience
63: repair path.
64: 
65: ## Recommended bounded implementation split
66: 
67: 1. **Engine-neutral request context.** Add a frozen request/evidence value
68:    beside `WriteCredentials`, not a custody import. It needs provider
69:    namespace, exact observer, requested domain/purpose, optional transitional
70:    locator, and the operation's lineage/captured head/proposed position where
71:    available. The response exposes opaque key reference plus public-key
72:    material and domain signer; engine code checks history at its existing
73:    capture/successor point. A compatibility adapter may still implement
74:    `for_write(vertex)`, but it must be explicit and must not claim mapped
75:    evidence.
76: 2. **Move selection to the captured operation boundary.** Ordinary/batch
77:    preparation knows the fact observer; declaration preparation knows its
78:    author and successor rule; runtime knows a generated tick and physical
79:    genesis. The engine coordinator should request those capabilities after
80:    it has the relevant capture, while SDK passes the provider rather than
81:    preselected location-only callbacks. Do not retrofit legacy handle/ceremony
82:    beyond an adapter in this slice.
83: 3. **Separate mapped filesystem provider.** Keep
84:    `CustodyCredentialProvider` as the location-scoped compatibility provider;
85:    a new mapped provider takes explicit namespace configuration.
86:    Persist exact-label -> opaque-reference plus derived public material in a
87:    provider-owned mapping; private filename layout remains private. Creation
88:    must publish one key and one mapping atomically enough that concurrent
89:    losers load the winner. A mapping that points to a missing key refuses.
90:    A private key without a mapping after interruption is not automatically
91:    adopted; recovery is explicit.
92: 4. **Compatibility onboarding, no automatic migration.** A caller can
93:    explicitly bind an unambiguous legacy flat/nested key with its exact
94:    observer label and self-label evidence, after validating private-derived
95:    public material and existing `.pub`. Do not scan and guess bindings,
96:    infer a namespace, lower alias/ambiguity refusals, move live keys, or
97:    overload `key_dir`.
98: 
99: ## Acceptance
100: 
101: Use subprocess/process-level temporary `XDG_STATE_HOME`,
102: `XDG_CONFIG_HOME`, and `LOOPS_HOME` for every custody fixture. Prove
103: exact-label namespace separation, all three domains, no key mint on a missing
104: read binding, and refusal on mapping/key/public mismatch. Exercise declaration
105: successor validation, ordinary/batch author selection, explicit tick selection,
106: and initialization bootstrap separately. Add interruption/concurrent-create
107: tests for private-key publication and mapping publication; no test may use
108: real user keys or stores.
109: 
110: Unresolved policy decisions: persistent mapping format/location and recovery
111: UX; whether one response can carry all operation capabilities or requests are
112: per domain; and the explicit bootstrap authority for a namespace. None require
113: an Arrival wire change.

===== docs/scratch/arrival-break/consistency-d0-d2-validation-2026-09-06.md =====
1: # D0→D2 identity validation plan — 2026-09-06
2: 
3: This is an independent validation plan for the next credential-binding slice.
4: It does not ratify a wire migration or a filesystem layout. The authoritative
5: constraints are [identity decisions](identity-decisions-2026-09-06.md), the
6: [identity audit](consistency-audit-identity-2026-09-06.md), and the Arrival
7: wire/backend contracts.
8: 
9: ## Contract under test
10: 
11: D0 separates four values that must not be inferred from one another:
12: 
13: 1. the exact protocol observer label;
14: 2. the provider's explicit custody namespace and opaque key reference;
15: 3. the signing domain (FACT, ARRIVAL, or tick); and
16: 4. the verification context, including lineage and the captured successor
17:    coordinate at which a key was valid.
18: 
19: D2 persists the provider's mapping from exact observer identity to opaque key
20: references. It keeps the existing flat self-key and nested observer behavior
21: as compatibility inputs, while refusing ambiguous aliases, conflicting
22: public material, unsafe path components, and silent winner selection. A
23: filename, vertex stem, descriptor location, lineage, or equal observer label
24: across lineages is not a key-history proof.
25: 
26: ## Adversarial matrix
27: 
28: ### Request and domain separation (D0)
29: 
30: - A fact, batch, and declaration edit request credentials with explicit
31:   observer/domain context. A provider must never substitute the vertex name,
32:   boundary name, founding observer, or location for the requested observer.
33:   An inner tick commitment uses the TICK domain and has no author label; its
34:   receipt-signing capability follows the established any-key policy. The
35:   outer Arrival envelope is unsigned and carries the physical log custodian.
36: - `WriteCredentials` must preserve independent FACT, ARRIVAL, and tick
37:   callbacks. Missing one callback remains the operation's existing unsigned
38:   posture where allowed; another callback must not be used as a fallback.
39:   Verify each signature under its own domain and assert cross-domain
40:   verification fails.
41: - A provider is queried fresh per operation. Reads, previews, verification,
42:   signer loading, and failed preflight must not generate a private key or
43:   publish a binding. A failed signer/public-key relationship must refuse
44:   before intent, mint, or append.
45: - A key introduced at captured H is valid for a successor record at H+1, not
46:   retroactively for H. Test valid and invalid introduction coordinates,
47:   unknown observer, wrong lineage, and a signer whose bytes do not match the
48:   presented public evidence. Preserve the actual captured H and cause in the
49:   typed refusal.
50: - A tick's inner TICK signer and outer Arrival custodian label remain
51:   distinct. Test a tick signed by a non-genesis key and confirm the outer
52:   envelope still follows the established custodian rule. For facts, test an
53:   author different from the physical genesis observer. Equal labels in
54:   separate lineages must not be reported as globally authenticated identity.
55: 
56: ### Mapping and compatibility (D2)
57: 
58: - Existing flat `keys/ed25519.key` remains the self-observer compatibility
59:   key. Existing exact nested `keys/<observer>/` keys remain usable. Moving or
60:   renaming the `.vertex` file must not silently select a new key for the same
61:   explicit observer when a persisted binding exists.
62: - Exact nested labels, slash namespaces, case variants, Unicode, empty
63:   components, dot/parent components, reserved key filenames, symlinks, and
64:   regular-file path components must be tested. Preserve the current refusal
65:   policy; never borrow a case-folded or traversal-equivalent key.
66: - A mapping whose observer/namespace/reference is malformed, whose public
67:   material disagrees with the key, or whose target key is missing must refuse
68:   without overwriting existing bytes, minting a replacement, or choosing a
69:   newer arbitrary row. A mapping for one lineage is not silently reused as
70:   proof for another lineage unless the provider explicitly declares that
71:   namespace reuse and the operation still verifies lineage key history.
72: - Concurrent creators for the same exact binding must converge on one
73:   complete winner or return a typed conflict. They must not publish a partial
74:   mapping, two private keys, or a mapping pointing at the losing key. Inject
75:   interruption after key creation, after mapping temp write, and after rename;
76:   recovery must retain enough evidence to reconcile without generating a new
77:   identity.
78: - A provider configured with an unsupported key root must fail explicitly
79:   before signer lookup. The current `CustodyCredentialProvider(key_dir=...)`
80:   refusal is the compatibility baseline until an explicit provider/key-locator
81:   design is implemented; callers must not believe the argument was honored.
82: 
83: ### Operation and error compatibility
84: 
85: - Existing unsigned/pre-signature behavior remains legal where the operation
86:   permits it. A missing local key on a read or signer load must not mint one.
87: - Precommit input/configuration errors retain zero-mutation evidence. An
88:   append after credentials are acquired retains stable fact/tick IDs, captured
89:   head, and the proper committed, unwitnessed, projection-failed, or unknown
90:   outcome. Credential lookup failure must not be mislabeled append-unknown.
91: - Public error/outcome serialization must expose enough namespace, observer,
92:   domain, key-reference/public-evidence status, captured verification
93:   coordinate, and mutation phase to explain a refusal or uncertain result,
94:   without leaking private key bytes or reducing a committed outcome to a
95:   generic refusal. Success DTOs need only expose the identity evidence their
96:   operation contract promises; this plan does not require every result to
97:   repeat provider-internal references.
98: - Registration and custom-provider paths must preserve opaque backend
99:   locations and the caller's registry. Credential configuration must not
100:   derive identity from an adapter DSN or fall back to the built-in provider.
101: 
102: ## Existing evidence to extend
103: 
104: The current baseline already covers domain-separated custody signers and
105: flat/nested compatibility in `libs/custody/tests/test_signing.py`, including
106: alias, symlink, traversal, ambiguity, missing-load, and cross-domain cases.
107: `libs/sdk/tests/test_emit.py` covers operation-fresh `WriteCredentials`,
108: unsigned behavior, and the explicit refusal of the ineffective `key_dir`
109: override. `libs/sdk/tests/test_arrival_init.py` covers injected separate
110: fact/Arrival signers, wrong-domain and key mismatch preflight, partial custom
111: credentials, and recovery without generating a replacement key. These tests
112: are the compatibility floor; D0/D2 additions should prove persisted binding
113: selection and concurrency rather than mirror helper internals.
114: 
115: ## Proposed focused test split (pending API freeze)
116: 
117: Do not add these files until the provider request and binding result types are
118: settled. The likely ownership split is:
119: 
120: - `libs/custody/tests/test_binding.py`: persisted observer-to-opaque-reference
121:   selection, flat/nested compatibility, exact case/slash/Unicode labels,
122:   traversal/symlink/regular-file rejection, mismatched public material,
123:   concurrent creators, and interruption at key or mapping publication. Each
124:   case should assert prior bytes survive and that a loser cannot replace a
125:   complete winner.
126: - `libs/engine/tests/test_arrival_credentials.py`: engine-facing request
127:   context and verification only. Cover separate FACT/ARRIVAL/TICK domains,
128:   TICK's authorless inner commitment plus unsigned outer custodian envelope,
129:   key validity at H versus H+1, wrong lineage/unknown author, and the
130:   distinction between credential/preflight refusal and append-unknown. Use
131:   injected callbacks or signed temporary records; do not import custody
132:   layout helpers into the engine package.
133: - `libs/sdk/tests/test_arrival_mapped_credentials.py` (with compatibility
134:   assertions remaining in `test_emit.py` and `test_arrival_init.py`): public
135:   provider registration,
136:   moved vertex residence, opaque backend namespace collision refusal, fresh
137:   provider calls, no key generation on reads/previews, unsupported key-root
138:   override, and JSON-safe refusal/uncertain-result evidence. A success DTO
139:   should assert only the identity fields promised by its operation contract.
140: 
141: Sol's provisional neutral seam gives these cases concrete request points:
142: `SigningDomain`, `CredentialRequest(namespace, observer, domain)`, and
143: `CredentialBinding(request, key_ref, public_key, sign_digest)`, plus provider
144: namespace/receipt-observer/resolve/verifier operations. The tests should use
145: that seam when frozen rather than reach into custody filenames. For a TICK
146: request, the inner signature is TICK-domain evidence without an author label;
147: the outer receipt remains unsigned physical-custodian evidence. The request
148: shape must not turn either into a FACT-author assertion.
149: 
150: The minimum cross-operation acceptance sequence is: create an isolated real
151: lineage; bind two exact observers; introduce one observer at a known H; sign a
152: fact and a TICK-domain inner record with their required callbacks; verify the
153: unsigned outer envelope's custodian; then move the vertex residence and repeat
154: the lookup. Separate negative cases must prove that a FACT callback cannot
155: stand in for ARRIVAL or TICK, H is not retroactively authorized, an opaque
156: provider key is not interpreted as a local path, and a failed preflight creates
157: no key, mapping, intent, or append. These are contract tests, not requirements
158: to expose provider-internal references on every successful result.
159: 
160: The strongest conformance fixture should create a real temporary lineage,
161: introduce one or more observer keys at known ordinals, and perform a signed
162: fact, signed declaration/tick inner record, and Arrival envelope. It should
163: verify every signature against the historical registry and then repeat after
164: moving the vertex residence or changing the provider's local path. A separate
165: fake provider should prove opaque namespaces and collision refusal without
166: filesystem interpretation.
167: 
168: ## Validation protocol and limits
169: 
170: Every test process must set isolated `XDG_STATE_HOME`, `XDG_CONFIG_HOME`, and
171: `LOOPS_HOME` beneath a disposable task directory. Test setup must assert those

===== libs/sign/src/sign/ed25519.py =====
1: """Ed25519 detached signatures over digests, with domain separation.
2: 
3: The provenance-arc signing primitive (loops delta 2: tick signing). A distinct
4: surface from sign.keys/sign.jwt — those mint RSA JWTs over claims documents;
5: this signs already-computed digests with deterministic Ed25519 (RFC 8032).
6: Determinism is the load-bearing property for tamper-evidence: the same
7: commitment always yields the same signature, so re-signing never produces
8: spurious diffs and signature equality is meaningful.
9: 
10: Domain separation is mandatory: every signature binds a caller-supplied domain
11: prefix (e.g. ``myapp-tick-v1``) so a signature minted for one surface can
12: never be replayed as a commitment on another. The prefix constant belongs to
13: the COMPOSING layer (apps/loops), not here — this library stays loops-agnostic.
14: 
15: Public-key wire format is raw-32-byte base64 (~44 chars) — small enough to
16: inline in a declaration file. ``load_or_generate`` writes the same string to
17: ``ed25519.pub``, so the registry value is copy-identical to the file on disk.
18: 
19: Designed for namespaced import (``from sign import ed25519``): function names
20: deliberately mirror ``sign.keys`` (``load_or_generate``) and are therefore not
21: re-exported flat from the package root.
22: """
23: 
24: from __future__ import annotations
25: 
26: import base64
27: import binascii
28: import logging
29: import os
30: import tempfile
31: from contextlib import suppress
32: from dataclasses import dataclass
33: from pathlib import Path
34: 
35: from cryptography.exceptions import InvalidSignature
36: from cryptography.hazmat.primitives import serialization
37: from cryptography.hazmat.primitives.asymmetric.ed25519 import (
38:     Ed25519PrivateKey,
39:     Ed25519PublicKey,
40: )
41: 
42: __all__ = [
43:     "Keypair",
44:     "load",
45:     "load_or_generate",
46:     "public_key_b64",
47:     "public_key_from_b64",
48:     "sign",
49:     "verify",
50: ]
51: 
52: log = logging.getLogger(__name__)
53: 
54: _KEY_FILE = "ed25519.key"
55: _PUB_FILE = "ed25519.pub"
56: 
57: 
58: @dataclass(frozen=True)
59: class Keypair:
60:     """An Ed25519 signing keypair loaded from (or generated into) a key dir."""
61: 
62:     private: Ed25519PrivateKey
63:     public: Ed25519PublicKey
64: 
65:     @property
66:     def public_b64(self) -> str:
67:         """Raw-32-byte base64 of the public key — the registry/wire format."""
68:         return public_key_b64(self.public)

72:     if not domain:
73:         raise ValueError("domain separation prefix must be non-empty")
74:     return domain.encode() + b":" + digest

78:     """Encode a public key as raw-32-byte base64 (the inline registry format)."""
79:     raw = public.public_bytes(
80:         serialization.Encoding.Raw, serialization.PublicFormat.Raw
81:     )

83: 
84: 
85: def public_key_from_b64(data: str) -> Ed25519PublicKey:
86:     """Decode the inline registry format back to a public key.
87: 
88:     Raises ValueError on malformed base64 or wrong key length.
89:     """
90:     try:
91:         raw = base64.b64decode(data, validate=True)
92:     except binascii.Error as exc:
93:         raise ValueError(f"malformed base64 public key: {exc}") from exc
94:     if len(raw) != 32:
95:         raise ValueError(f"expected 32-byte Ed25519 public key, got {len(raw)} bytes")
96:     return Ed25519PublicKey.from_public_bytes(raw)
97: 
98: 
99: def _generate(key_dir: Path) -> None:
100:     log.info("generating Ed25519 signing key in %s", key_dir)
101:     key_dir.mkdir(parents=True, exist_ok=True)
102:     private = Ed25519PrivateKey.generate()
103:     key_pem = private.private_bytes(
104:         serialization.Encoding.PEM,
105:         serialization.PrivateFormat.PKCS8,
106:         serialization.NoEncryption(),
107:     )
108:     key_path = key_dir / _KEY_FILE
109:     fd, raw = tempfile.mkstemp(prefix=f".{_KEY_FILE}.", dir=key_dir)
110:     temporary = Path(raw)
111:     try:
112:         with os.fdopen(fd, "wb") as stream:
113:             stream.write(key_pem)
114:             stream.flush()
115:             os.fsync(stream.fileno())
116:         temporary.chmod(0o600)
117:         with suppress(FileExistsError):
118:             # Publish a complete private key once.  A concurrent loser loads
119:             # this winning file below; it never replaces it with its draft.
120:             os.link(temporary, key_path)
121:     finally:
122:         temporary.unlink(missing_ok=True)
123: 
124: 
125: def _publish_public(key_dir: Path, keypair: Keypair) -> None:
126:     """Atomically make the convenience public-key file agree with the private key."""
127:     public_path = key_dir / _PUB_FILE
128:     expected = public_key_b64(keypair.public) + "\n"
129:     try:
130:         if public_path.read_text() == expected:
131:             return
132:     except FileNotFoundError:
133:         pass
134:     fd, raw = tempfile.mkstemp(prefix=f".{_PUB_FILE}.", dir=key_dir)
135:     temporary = Path(raw)
136:     try:
137:         with os.fdopen(fd, "w") as stream:
138:             stream.write(expected)
139:             stream.flush()
140:             os.fsync(stream.fileno())
141:         temporary.replace(public_path)
142:     finally:
143:         temporary.unlink(missing_ok=True)
144: 
145: 
146: def load(key_dir: str | Path) -> Keypair:
147:     """Load an existing Ed25519 keypair without creating any filesystem state.
148: 
149:     ``FileNotFoundError`` is deliberate: read-side callers can distinguish the
150:     pre-signature era from a request to mint a new key.
151:     """
152:     key_path = Path(key_dir) / _KEY_FILE
153:     private = serialization.load_pem_private_key(key_path.read_bytes(), password=None)
154:     if not isinstance(private, Ed25519PrivateKey):
155:         kind = type(private).__name__
156:         raise ValueError(f"expected Ed25519 private key in {key_path}, got {kind}")
157:     return Keypair(private=private, public=private.public_key())
158: 
159: 
160: def load_or_generate(key_dir: str | Path) -> Keypair:
161:     """Ensure an Ed25519 keypair exists in ``key_dir``, then load and return it."""
162:     key_dir = Path(key_dir)
163:     try:
164:         keypair = load(key_dir)
165:     except FileNotFoundError:
166:         _generate(key_dir)
167:         keypair = load(key_dir)
168:     _publish_public(key_dir, keypair)
169:     return keypair
170: 
171: 
172: def sign(keypair: Keypair, digest: bytes, *, domain: str) -> str:
173:     """Sign a digest under a domain prefix; returns the signature as base64.
174: 
175:     Deterministic (RFC 8032): the same (key, domain, digest) always yields
176:     the same signature.
177:     """
178:     return base64.b64encode(keypair.private.sign(_message(domain, digest))).decode()
179: 
180: 
181: def verify(
182:     public: Ed25519PublicKey, signature_b64: str, digest: bytes, *, domain: str
183: ) -> bool:
184:     """Check a base64 signature over a digest under a domain prefix.
185: 
186:     Returns False for any failure mode short of caller error — bad base64,
187:     wrong key, tampered digest, wrong domain. An empty domain still raises
188:     ValueError (that is a composition bug, not a verification outcome).
189:     """
190:     message = _message(domain, digest)
191:     try:
192:         raw = base64.b64decode(signature_b64, validate=True)
193:         public.verify(raw, message)
194:     except (InvalidSignature, binascii.Error, ValueError):
195:         return False
196:     return True

582: def _window_hash(
583:     facts: tuple[SnapshotFact, ...],
584:     *,
585:     start: str,
586:     appended: tuple[object, ...] | None = None,
587: ) -> str:
588:     """The live tick window hash over exact snapshot rows plus this fact."""
589:     import hashlib
590: 
591:     digest = hashlib.sha256()
592:     if appended is not None and start == appended[0]:
593:         return digest.hexdigest()
594:     start_at = -1
595:     if start:
596:         for index, fact in enumerate(facts):
597:             if fact.id == start:
598:                 start_at = index
599:                 break
600:         else:
601:             raise RuntimeWriteRefused(f"tick window start {start!r} is absent from the snapshot")
602:     for fact in facts[start_at + 1 :]:
603:         if fact.payload_text is None:
604:             raise RuntimeWriteRefused("snapshot omitted exact fact payload text")
605:         digest.update(
606:             fact_row_hash(
607:                 (
608:                     fact.id,
609:                     fact.kind,
610:                     fact.ts,
611:                     fact.observer,
612:                     fact.origin,
613:                     fact.payload_text,
614:                     fact.signature,
615:                 )
616:             ).encode()
617:         )
618:     if appended is not None:
619:         digest.update(fact_row_hash(appended).encode())
620:     return digest.hexdigest()

623: def _current_tick_context(
624:     ticks: tuple[SnapshotTick, ...], *, current_fact_id: str
625: ) -> tuple[str | None, str]:
626:     """Return the predecessor identity and next tick's window start."""
627:     if not ticks:
628:         return None, ""
629:     previous = max(ticks, key=lambda tick: (tick.arrival_ordinal, tick.arrival_seq))
630:     if previous.payload_text is None:
631:         raise RuntimeWriteRefused("snapshot omitted exact tick payload text")
632:     previous_hash = tick_row_hash(
633:         (
634:             previous.id,
635:             previous.name,
636:             previous.ts,
637:             previous.since,
638:             previous.origin,
639:             previous.payload_text,
640:             previous.prev_hash,
641:             previous.window_start,
642:             previous.fact_cursor,
643:             previous.window_hash,
644:             previous.signature,
645:         )
646:     )
647:     if previous.window_hash is None:
648:         # The live store starts a new chain epoch at its current fact edge,
649:         # which is this just-planned fact; its first window is empty.
650:         return previous_hash, current_fact_id
651:     if previous.fact_cursor is None:
652:         raise RuntimeWriteRefused("chained tick has no fact cursor")
653:     return previous_hash, previous.fact_cursor

894: def plan_ordinary_write(
895:     snapshot: QuerySnapshot,
896:     basis: ReadBasis,
897:     vertex: Vertex,

904:     admit_undeclared: bool = False,
905:     _mutate_candidate: bool = False,

907:     """Internal, caller-responsible planner for one local fact and tick.
908: 
909:     ``vertex`` must be a detached reconstruction of this exact snapshot.
910:     Supported consumers use :func:`prepare_ordinary_write`, which creates it
911:     through :func:`hydrate_arrival_candidate`; this lower-level seam exists
912:     for focused engine composition and must not be offered as a coherent

918:     if getattr(vertex, "_has_children", False):

920:     from .declaration import validate_arrival_runtime_identity
921: 
922:     validate_arrival_runtime_identity(
923:         vertex.name,
924:         vertex.kinds,
925:         refusal=RuntimeWriteRefused,
926:     )
927:     anchor = snapshot.declaration_anchor
928:     if anchor.own_lineage is None or anchor.genesis is None:
929:         raise RuntimeWriteRefused("ordinary emission requires a declaration anchor")
930:     from .declaration import validate_arrival_declaration_anchor
931: 
932:     validate_arrival_declaration_anchor(anchor, basis.captured_head)
933: 
934:     existing_plan = _existing_fact_plan(snapshot, basis, fact, credentials, fact_id)
935:     if existing_plan is not None:
936:         return existing_plan
937:     facts = snapshot.facts(FactRequest(limit=None, include_internal=True, order="oldest")).items
938:     # The neutral request is receipt-ordered, but keep this safety boundary at
939:     # the chain calculation: window membership is coordinates, never a
940:     # backend's event-time or identifier presentation order.
941:     facts = tuple(sorted(facts, key=lambda row: (row.arrival_ordinal, row.arrival_seq)))
942:     ticks = snapshot.ticks(TickRequest())
943:     chosen_id = fact_id if fact_id is not None else str(ULID())
944:     payload_text = _payload_text(fact.payload)
945:     inner_signature = (
946:         credentials.fact_signer(
947:             fact.observer,
948:             fact_commitment_hash(fact.kind, fact.ts, fact.observer, fact.origin, payload_text),
949:         )
950:         if credentials.fact_signer is not None
951:         else None

954:         chosen_id,
955:         fact.kind,
956:         fact.ts,
957:         fact.observer,
958:         fact.origin,
959:         payload_text,
960:         inner_signature,

970:         raise _AdmissionPlanRefused("admission rejected the fact before append")

973:         credentials.arrival_signer(
974:             fact.observer,
975:             content_commitment("fact", fact.ts, fact.observer, fact.origin, fact_body),
976:         )
977:         if credentials.arrival_signer is not None
978:         else None
979:     )

981:         RecordDraft(
982:             kind="fact",
983:             authored_at=fact.ts,
984:             observer=fact.observer,
985:             origin=fact.origin,
986:             body=fact_body,
987:             signature=outer_signature,
988:         )

1122: def prepare_ordinary_write(
1123:     registry: BackendRegistry,
1124:     descriptor: StoreDescriptor,
1125:     locator: VertexFile,

1137:     detached plan; execution later compares the same complete head under the

1194:     """Append a previously prepared plan once against its exact full head.
1195:

1198:     operation.  ``after_commit`` is the optional injected maintenance seam:
1199:     it receives the durable ``Commit.after`` and cannot change the append

220: def _reserved_genesis_signer(
221:     plan: Mapping[str, Any],
222: ) -> Callable[[str, str], str | None]:
223:     """Return the exact signature reserved before the durable mint."""
224:     genesis = plan["genesis"]
225:     digest = content_commitment(
226:         genesis["kind"], genesis["at"], genesis["observer"],
227:         genesis["origin"], genesis["body"],

230:     def sign(observer: str, offered_digest: str) -> str | None:
231:         if observer == genesis["observer"] and offered_digest == digest:

273: def _draft(
274:     *,
275:     lineage: str,
276:     authored_at: float,
277:     observer: str,
278:     documents: Sequence[Mapping[str, Any]],
279:     fact_signer: Callable[[str, str], str | None],
280:     arrival_signer: Callable[[str, str], str | None],
281:     public_key: str,
282:     fact_verify: Callable[[str, str, str], bool] | None = None,
283:     arrival_verify: Callable[[str, str, str], bool] | None = None,
284: ) -> RecordDraft:
285:     payload = json.dumps(
286:         {"protocol": 1, "documents": [dict(document) for document in documents]},
287:         ensure_ascii=False,
288:         separators=(",", ":"),
289:     )
290:     inner_digest = fact_commitment_hash(
291:         "_decl.genesis", authored_at, observer, "", payload
292:     )
293:     inner_signature = fact_signer(observer, inner_digest)
294:     if not inner_signature:
295:         raise ArrivalInitializationError(
296:             f"founding observer {observer!r} has no fact signer"
297:         )
298:     if fact_verify is not None and not fact_verify(
299:         public_key, inner_signature, inner_digest
300:     ):
301:         raise ArrivalInitializationError("founding fact signer does not match the public key")
302:     body = body_of_fact_row(
303:         (lineage, "_decl.genesis", authored_at, observer, "", payload, inner_signature)
304:     )
305:     outer_digest = content_commitment("fact", authored_at, observer, "", body)
306:     outer_signature = arrival_signer(observer, outer_digest)
307:     if not outer_signature:
308:         raise ArrivalInitializationError(
309:             f"founding observer {observer!r} has no Arrival signer"
310:         )
311:     if arrival_verify is not None and not arrival_verify(
312:         public_key, outer_signature, outer_digest
313:     ):
314:         raise ArrivalInitializationError("founding Arrival signer does not match the public key")
315:     return RecordDraft(
316:         kind="fact",
317:         authored_at=authored_at,
318:         observer=observer,
319:         origin="",
320:         body=body,
321:         signature=outer_signature,
322:     )

325: def _same_record(record: Mapping[str, Any], draft: RecordDraft) -> bool:
326:     return (
327:         record.get("k") == draft.kind
328:         and record.get("at") == draft.authored_at
329:         and record.get("observer") == draft.observer
330:         and record.get("origin") == draft.origin
331:         and record.get("body") == dict(draft.body)

336: def _declared_key_drafts(
337:     documents: Sequence[Mapping[str, Any]],
338:     *,
339:     observer: str,
340:     public_key: str,
341:     at: float,
342:     signer: Callable[[str, str], str | None],
343:     verify: Callable[[str, str, str], bool] | None,
344: ) -> tuple[RecordDraft, ...]:
345:     """Introduce declared observer keys using the valid founding key."""
346:     keys: dict[str, str] = {}
347:     for document in documents:
348:         if document["kind"] != "_decl.observer-defined":
349:             continue
350:         key = document["payload"].get("key")
351:         if key is None:
352:             continue
353:         subject = document["subject"]
354:         try:
355:             if not isinstance(key, str) or len(base64.b64decode(key, validate=True)) != 32:
356:                 raise ValueError
357:         except (ValueError, TypeError):
358:             raise InitializationConflict(
359:                 f"observer {subject!r} has a malformed public key"
360:             ) from None
361:         if subject == observer:
362:             if key != public_key:
363:                 raise InitializationConflict(
364:                     "declared founding key differs from genesis public key"
365:                 )
366:             continue
367:         if subject in keys and keys[subject] != key:
368:             raise InitializationConflict(f"observer {subject!r} has conflicting declared keys")
369:         keys[subject] = key
370:     drafts: list[RecordDraft] = []
371:     for subject, key in keys.items():
372:         body = {"observer": subject, "key": key}
373:         digest = content_commitment("key", at, observer, "", body)
374:         signature = signer(observer, digest)
375:         if not signature or (
376:             verify is not None and not verify(public_key, signature, digest)
377:         ):
378:             raise InitializationConflict("founding signer cannot authenticate key introduction")
379:         drafts.append(RecordDraft("key", at, observer, "", body, signature))
380:     return tuple(drafts)

405: def _check_preconditions(
406:     target: Path,
407:     descriptor: StoreDescriptor,
408:     documents: Sequence[Mapping[str, Any]],
409:     declaration_text: str,
410:     observer: str,
411:     public_key: str,
412:     signer: Callable[[str, str], str | None],
413:     fact_signer: Callable[[str, str], str | None],
414:     arrival_signer: Callable[[str, str], str | None],
415: ) -> None:
416:     if descriptor.role is not Profile.AUTHORITY:
417:         raise InitializationConflict("fresh initialization requires an Authority descriptor")
418:     if not observer or not isinstance(observer, str):
419:         raise InitializationConflict("fresh initialization requires a non-empty observer")
420:     if not isinstance(public_key, str) or not public_key:
421:         raise InitializationConflict("fresh initialization requires a founding public key")
422:     try:
423:         if len(base64.b64decode(public_key, validate=True)) != 32:
424:             raise ValueError
425:     except (ValueError, TypeError):
426:         raise InitializationConflict(
427:             "founding public key must be raw-32-byte base64"
428:         ) from None
429:     if not isinstance(declaration_text, str) or not declaration_text.strip():
430:         raise InitializationConflict("declaration text must be non-empty UTF-8 text")
431:     if not callable(signer) or not callable(fact_signer) or not callable(arrival_signer):
432:         raise InitializationConflict("fresh initialization requires signer callables")
433:     if not isinstance(documents, Sequence) or isinstance(documents, (str, bytes)):
434:         raise InitializationConflict("declaration documents must be a sequence")
435:     try:
436:         json.dumps([dict(document) for document in documents], ensure_ascii=False)
437:     except (TypeError, ValueError) as exc:
438:         raise InitializationConflict(f"declaration documents are not JSON-safe: {exc}") from exc
439:     if target.exists():
440:         raise InitializationConflict(f"vertex file already exists: {target}")

443: def _validate_declaration(
444:     target: Path,
445:     descriptor: StoreDescriptor,
446:     documents: Sequence[Mapping[str, Any]],
447:     declaration_text: str,
448:     lineage: str,
449: ) -> None:
450:     """Check the signed declaration inputs before reserving or minting.
451: 
452:     The declaration text is the human ingress form and the document sequence
453:     is what gets committed into ``_decl.genesis``.  They must describe the
454:     same residence and identity, otherwise recovery could faithfully preserve
455:     a plan that never represented the requested target.
456:     """
457:     try:
458:         from lang import parse_vertex, validate_vertex, vertex_to_documents
459: 
460:         ast = parse_vertex(declaration_text, path=target)
461:         validate_vertex(ast)
462:     except Exception as exc:
463:         raise InitializationConflict(
464:             f"declaration text is not valid Vertex grammar: {exc}"
465:         ) from exc
466:     from .declaration import validate_arrival_runtime_identity
467: 
468:     validate_arrival_runtime_identity(
469:         ast.name,
470:         ast.loops,
471:         refusal=InitializationConflict,
472:     )
473:     parsed_documents = [document.as_json() for document in vertex_to_documents(ast)]
474:     if [dict(document) for document in documents] != parsed_documents:
475:         raise InitializationConflict(
476:             "declaration text and declaration documents disagree"
477:         )
478:     backend = ast.store_backend
479:     if (
480:         backend is None
481:         or backend.name != descriptor.backend
482:         or backend.lineage != lineage
483:         or backend.role != Profile.AUTHORITY.value
484:     ):
485:         raise InitializationConflict(
486:             "declaration residence must match the requested backend, lineage and authority role"
487:         )
488:     location = ast.store_location
489:     if descriptor.backend == "file" and ast.store is not None:
490:         location = str(ast.store)
491:     if location is None:
492:         raise InitializationConflict("declaration residence must include a store location")
493:     if descriptor.backend == "file":
494:         parsed_location = (target.parent / location).resolve()
495:         requested_location = Path(descriptor.location).resolve()
496:         locations_match = parsed_location == requested_location
497:     else:
498:         # DSNs are adapter-owned and must survive the engine untouched.
499:         locations_match = location == descriptor.location
500:     if not locations_match:
501:         raise InitializationConflict(
502:             "declaration residence location does not match the requested descriptor"
503:         )

506: def initialize_arrival(
507:     registry: BackendRegistry,
508:     descriptor: StoreDescriptor,
509:     *,
510:     target: Path | str,
511:     documents: Sequence[Mapping[str, Any]],
512:     declaration_text: str,
513:     observer: str,
514:     public_key: str,
515:     signer: Callable[[str, str], str | None],
516:     fact_signer: Callable[[str, str], str | None],
517:     arrival_signer: Callable[[str, str], str | None],
518:     fact_verify: Callable[[str, str, str], bool] | None = None,
519:     arrival_verify: Callable[[str, str, str], bool] | None = None,
520:     lineage: str | None = None,
521:     authored_at: float | None = None,
522:     failure_hook: Callable[[str], None] | None = None,
523: ) -> ArrivalInitializationResult:
524:     """Mint and publish a fresh Arrival declaration with recoverable intent."""
525:     target_path = Path(target).resolve()
526:     intent = arrival_intent_path(target_path)
527:     _check_preconditions(
528:         target_path, descriptor, documents, declaration_text, observer, public_key,
529:         signer, fact_signer, arrival_signer,
530:     )
531:     if intent.exists():
532:         raise InitializationRecoveryRequired(
533:             f"unfinished initialization intent exists: {intent}; recover explicitly"
534:         )
535:     chosen_lineage = lineage or descriptor.lineage or new_lineage()
536:     if descriptor.lineage is not None and descriptor.lineage != chosen_lineage:
537:         raise InitializationConflict("descriptor lineage does not match reserved lineage")
538:     _validate_declaration(
539:         target_path, descriptor, documents, declaration_text, chosen_lineage
540:     )
541:     at = time.time() if authored_at is None else authored_at
542:     genesis_body = {
543:         "protocol": 1,
544:         "lineage": chosen_lineage,
545:         "key": public_key,
546:     }
547:     genesis_digest = content_commitment(
548:         "genesis", at, observer, "", genesis_body
549:     )
550:     genesis_signature = signer(observer, genesis_digest)
551:     if not genesis_signature:
552:         raise InitializationConflict("founding signer produced no genesis signature")
553:     if arrival_verify is not None and not arrival_verify(
554:         public_key, genesis_signature, genesis_digest
555:     ):
556:         raise InitializationConflict("founding genesis signer does not match the public key")
557:     draft = _draft(
558:         lineage=chosen_lineage,
559:         authored_at=at,
560:         observer=observer,
561:         documents=documents,
562:         fact_signer=fact_signer,
563:         arrival_signer=arrival_signer,
564:         public_key=public_key,
565:         fact_verify=fact_verify,
566:         arrival_verify=arrival_verify,
567:     )
568:     key_drafts = _declared_key_drafts(
569:         documents, observer=observer, public_key=public_key, at=at,
570:         signer=arrival_signer, verify=arrival_verify,
571:     )
572:     if key_drafts:
573:         # The minimum backend contract supports one record. Additional keys
574:         # and declaration genesis form one larger atomic unit; refuse its
575:         # unsupported size before reserving an intent or minting a lineage.
576:         ledger, query = registry.open(descriptor)
577:         try:
578:             limit = ledger.capabilities().max_atomic_records
579:             if limit is not None and len(key_drafts) + 1 > limit:
580:                 raise AtomicLimitExceeded(
581:                     f"initialization needs {len(key_drafts) + 1} records; atomic limit is {limit}"
582:                 )
583:         finally:
584:             for resource in (query, ledger):
585:                 close = getattr(resource, "close", None)
586:                 if callable(close):
587:                     close()
588:     planned = {
589:         "schema": _INTENT_SCHEMA,
590:         "phase": "reserved",
591:         "target": str(target_path),
592:         "descriptor": _descriptor_dict(
593:             StoreDescriptor(
594:                 descriptor.backend, descriptor.location, chosen_lineage,
595:                 descriptor.role, descriptor.query, descriptor.witness,
596:             )
597:         ),
598:         "lineage": chosen_lineage,
599:         "observer": observer,
600:         "public_key": public_key,
601:         "at": at,
602:         "genesis": {
603:             "kind": "genesis",
604:             "at": at,
605:             "observer": observer,
606:             "origin": "",
607:             "body": genesis_body,
608:             "signature": genesis_signature,
609:         },
610:         "documents": [dict(document) for document in documents],
611:         "declaration_text": declaration_text,
612:         "draft": _draft_dict(draft),
613:         "key_drafts": [_draft_dict(key_draft) for key_draft in key_drafts],
614:     }
615:     _reserve(intent, planned)
616:     try:
617:         return _continue(
618:             registry, intent, planned, failure_hook=failure_hook,
619:         )
620:     except BaseException:
621:         # The sidecar is the recovery record.  It is removed only once the
622:         # declaration bytes have been atomically published.
623:         raise
624: 
625: 
626: def _continue(
627:     registry: BackendRegistry,
628:     intent: Path,
629:     plan: dict[str, Any],
630:     *,
631:     failure_hook: Callable[[str], None] | None,
632: ) -> ArrivalInitializationResult:
633:     descriptor = _descriptor_from(plan["descriptor"])
634:     target = Path(plan["target"])
635:     draft_data = plan["draft"]
636:     draft = RecordDraft(
637:         kind=draft_data["kind"], authored_at=draft_data["authored_at"],
638:         observer=draft_data["observer"], origin=draft_data["origin"],
639:         body=draft_data["body"], signature=draft_data["signature"],
640:     )
641:     drafts = tuple(RecordDraft(**data) for data in plan.get("key_drafts", ())) + (draft,)
642:     ledger = query = None
643:     head: Head | None = None
644:     commit = None
645:     try:
646:         if plan["phase"] == "reserved":
647:             ledger, query = registry.open(descriptor)
648:             # PreGenesis carries no absence claim.  The adapter's exclusive
649:             # mint is the authority for an absent, existing, or corrupt
650:             # location and refuses safely in the latter two cases.
651:             try:
652:                 head = ledger.mint({
653:                     "observer": plan["observer"],
654:                     "signer": _reserved_genesis_signer(plan),
655:                     "key": plan["public_key"], "lineage": plan["lineage"],
656:                     "origin": "", "at": plan["at"],
657:                 })
658:             except Exception as mint_error:
659:                 from .arrival import GenesisRefused
660:                 from .arrival_contract import ContractRefusal
661:                 from .arrival_head_seam import NotWitnessed
662: 
663:                 if isinstance(mint_error, NotWitnessed):
664:                     raise InitializationUnwitnessed(
665:                         "genesis committed but its witness is unknown; recover "
666:                         "the initialization intent before retrying",
667:                         phase="reserved", lineage=plan["lineage"],
668:                         fact_id=plan["lineage"], head=mint_error.head,
669:                         commit=mint_error.commit, intent_path=intent,
670:                         cause=mint_error,
671:                     ) from mint_error
672:                 # A prior mint may have committed while its witness was
673:                 # unknown.  The failed exclusive mint is the proof that this
674:                 # is not a fresh location; only an exact custody comparison
675:                 # can turn that case into recoverable progress.
676:                 try:
677:                     head = _head_and_check_genesis(registry, descriptor, plan)
678:                 except Exception:
679:                     if isinstance(mint_error, (ContractRefusal, GenesisRefused)):
680:                         raise mint_error from None
681:                     raise InitializationOutcomeUnknown(
682:                         "genesis mint outcome is unknown; recover the durable "
683:                         "initialization intent before retrying",
684:                         phase="reserved", lineage=plan["lineage"],
685:                         fact_id=plan["lineage"], captured_head=None,
686:                         intent_path=intent, cause=mint_error,
687:                     ) from mint_error
688:                 if head.ordinal != 0:
689:                     raise mint_error from None
690:             _phase(plan, "minted")
691:             _save_intent(intent, plan)
692:             if failure_hook:
693:                 failure_hook("after-mint")
694:         else:
695:             head = _head_and_check_genesis(registry, descriptor, plan)
696:         if plan["phase"] == "minted":
697:             if ledger is None:
698:                 ledger, query = registry.open(descriptor)
699:             current = ledger.head()
700:             if current.ordinal == 0:
701:                 try:
702:                     commit = ledger.append(current, drafts)
703:                 except Exception as exc:
704:                     # Contract/grammar refusals are precommit diagnostics;
705:                     # an adapter exception outside those public families did
706:                     # not establish whether its append landed.
707:                     from .arrival_contract import ContractRefusal
708: 
709:                     if isinstance(exc, ContractRefusal):
710:                         raise
711:                     from .arrival import GenesisRefused
712: 
713:                     if isinstance(exc, GenesisRefused):
714:                         raise
715:                     from .arrival_head_seam import NotWitnessed
716: 
717:                     if isinstance(exc, NotWitnessed):
718:                         raise InitializationUnwitnessed(
719:                             "declaration committed but its witness is unknown; "
720:                             "recover the initialization intent before retrying",
721:                             phase="minted", lineage=plan["lineage"],
722:                             fact_id=str(draft.body["id"]), head=exc.head,
723:                             commit=exc.commit, intent_path=intent, cause=exc,
724:                         ) from exc
725:                     raise InitializationOutcomeUnknown(
726:                         "declaration append outcome is unknown; recover the "
727:                         "initialization intent before retrying",
728:                         phase="minted", lineage=plan["lineage"],
729:                         fact_id=str(draft.body["id"]), captured_head=current,
730:                         intent_path=intent, cause=exc,
731:                     ) from exc
732:                 head = commit.after
733:             elif _bootstrap_matches(ledger, current, drafts):
734:                 head = current
735:             else:
736:                 raise InitializationConflict("ledger contains a conflicting post-genesis record")
737:             _phase(plan, "declared")
738:             _save_intent(intent, plan)
739:             if failure_hook:
740:                 failure_hook("after-declaration")
741:         if plan["phase"] == "declared":
742:             if ledger is None:
743:                 ledger, query = registry.open(descriptor)
744:             current = ledger.head()
745:             # The declaration append is already durable at this point.  Keep
746:             # its observed head while projection sync runs so a sync failure
747:             # is reported as committed-incomplete with concrete identity.
748:             head = current
749:             if not _bootstrap_matches(ledger, current, drafts):
750:                 raise InitializationConflict(
751:                     "ledger no longer contains the planned declaration genesis"
752:                 )
753:             result = sync_projection(registry, descriptor)
754:             head = result.captured_head
755:             _phase(plan, "synced")
756:             _save_intent(intent, plan)
757:             if failure_hook:
758:                 failure_hook("after-sync")
759:         elif plan["phase"] in {"synced", "published"}:
760:             if ledger is None:
761:                 ledger, query = registry.open(descriptor)
762:             current = ledger.head()
763:             # Recovery has an observed committed head before attempting
764:             # publication or intent cleanup.
765:             head = current
766:             if not _bootstrap_matches(ledger, current, drafts):
767:                 raise InitializationConflict(
768:                     "ledger no longer contains the planned declaration genesis"
769:                 )
770:         else:
771:             head = ledger.head() if ledger is not None else _head_and_check_genesis(
772:                 registry, descriptor, plan
773:             )
774:         if plan["phase"] == "synced":
775:             if target.exists():
776:                 existing = target.read_text(encoding="utf-8")
777:                 if existing != plan["declaration_text"]:
778:                     raise InitializationConflict(
779:                         "existing declaration differs from initialization intent"
780:                     )
781:             else:
782:                 try:
783:                     _publish_exclusive(target, plan["declaration_text"])
784:                 except FileExistsError:
785:                     existing = target.read_text(encoding="utf-8")
786:                     if existing != plan["declaration_text"]:
787:                         raise InitializationConflict(
788:                             "a concurrent declaration differs from initialization intent"
789:                         ) from None
790:             _phase(plan, "published")
791:             _save_intent(intent, plan)
792:             if failure_hook:
793:                 failure_hook("after-publication")
794:         if plan["phase"] == "published":
795:             with suppress(FileNotFoundError):
796:                 intent.unlink()
797:                 _fsync_parent(intent)
798:         return ArrivalInitializationResult(
799:             target_path=str(target), location=descriptor.location,
800:             lineage=plan["lineage"], head=head,
801:             phase=plan["phase"], file_written=target.exists(),
802:         )
803:     except Exception as exc:
804:         if isinstance(
805:             exc,
806:             (
807:                 InitializationOutcomeUnknown,
808:                 InitializationUnwitnessed,
809:                 InitializationCommittedIncomplete,
810:             ),
811:         ):
812:             raise
813:         if head is not None and plan["phase"] in {"minted", "declared", "synced", "published"}:
814:             raise InitializationCommittedIncomplete(
815:                 "initialization committed but a later phase failed; recover "
816:                 "the durable intent",
817:                 phase=plan["phase"], lineage=plan["lineage"],
818:                 fact_id=str(draft.body["id"]), captured_head=head,
819:                 commit=commit, intent_path=intent, cause=exc,
820:             ) from exc
821:         raise
822:     finally:
823:         close = getattr(query, "close", None)
824:         if callable(close):
825:             close()
826:         close = getattr(ledger, "close", None)
827:         if callable(close):
828:             close()

831: def _head_and_check_genesis(
832:     registry: BackendRegistry,
833:     descriptor: StoreDescriptor,
834:     plan: Mapping[str, Any],
835: ) -> Head:
836:     ledger, query = registry.open(descriptor)
837:     try:
838:         head = ledger.head()
839:         record = ledger.read(0)
840:         body = record.get("body")
841:         genesis = plan["genesis"]
842:         if (
843:             record.get("k") != genesis["kind"]
844:             or record.get("at") != genesis["at"]
845:             or record.get("observer") != genesis["observer"]
846:             or record.get("origin") != genesis["origin"]
847:             or body != genesis["body"]
848:             or record.get("sig") != genesis["signature"]
849:         ):
850:             raise InitializationConflict("existing genesis differs from initialization intent")
851:         if head.lineage != plan["lineage"]:
852:             raise InitializationConflict(
853:                 "existing ledger lineage differs from initialization intent"
854:             )
855:         return head
856:     finally:
857:         getattr(query, "close", lambda: None)()
858:         getattr(ledger, "close", lambda: None)()

470: def _publish_cache(
471:     plan: DeclarationEditPlan,
472:     *,
473:     intent: Path,
474:     intent_data: dict[str, Any],
475:     failure_hook: Callable[[str], None] | None,
476: ) -> None:
477:     """Detach the verified old cache, then exclusively link a full new file."""
478:     target = plan.target_path
479:     temp = (
480:         Path(intent_data["cache_temp"])
481:         if intent_data.get("cache_temp")
482:         else _unique_sibling(target, "cache")
483:     )
484:     backup = (
485:         Path(intent_data["cache_backup"])
486:         if intent_data.get("cache_backup")
487:         else _unique_sibling(target, "backup")
488:     )
489:     intent_data["cache_temp"] = str(temp)
490:     intent_data["cache_backup"] = str(backup)
491:     _replace_json(intent, intent_data)
492:     try:
493:         proposed = plan.proposed_text.encode("utf-8")
494:         if temp.exists():
495:             _verify_cache_temp(temp, proposed)
496:         else:
497:             _create_cache_temp(temp, proposed)
498:             if failure_hook:
499:                 failure_hook("after-cache-temp")
500:         if target.exists():
501:             current = target.read_bytes()
502:             if current != plan.old_cache_bytes:
503:                 raise DeclarationStale(
504:                     "declaration cache changed after preparation; refusing publication"
505:                 )
506:             if backup.exists():
507:                 raise DeclarationApplyError(
508:                     "a prior cache publication left a backup beside the live declaration"
509:                 )
510:             target.rename(backup)
511:             _fsync_parent(target)
512:         elif not backup.exists():
513:             raise DeclarationApplyError(
514:                 "declaration cache is absent without the verified detached backup"
515:             )
516:         if failure_hook:
517:             failure_hook("after-cache-detach")
518:         if backup.read_bytes() != plan.old_cache_bytes:
519:             raise DeclarationApplyError(
520:                 "detached declaration cache bytes differ from prepared evidence"
521:             )
522:         os.link(temp, target)
523:         temp.unlink()
524:         _fsync_parent(target)
525:         if failure_hook:
526:             failure_hook("after-cache-link")
527:         with suppress(FileNotFoundError):
528:             backup.unlink()
529:         _fsync_parent(backup)
530:     except BaseException:
531:         raise

581:         if not isinstance(basis_captured_data, Mapping):
582:             raise DeclarationApplyError("declaration intent captured basis is malformed")
583:         basis_captured = Head(
584:             lineage=str(basis_captured_data["lineage"]),
585:             ordinal=int(basis_captured_data["ordinal"]),
586:             record_hash=str(basis_captured_data["record_hash"]),
587:         )
588:         projected_data = basis_data.get("projected_through")
589:         projected = None
590:         if projected_data is not None:
591:             if not isinstance(projected_data, Mapping):
592:                 raise DeclarationApplyError(
593:                     "declaration intent projected basis is malformed"
594:                 )
595:             projected = Head(
596:                 lineage=str(projected_data["lineage"]),
597:                 ordinal=int(projected_data["ordinal"]),
598:                 record_hash=str(projected_data["record_hash"]),
599:             )
600:         view_generation = basis_data.get("view_generation")
601:         if view_generation is not None and not isinstance(view_generation, str):
602:             raise DeclarationApplyError(
603:                 "declaration intent basis view generation is malformed"
604:             )
605:         basis = ReadBasis(
606:             lineage=str(basis_data["lineage"]),
607:             captured_head=basis_captured,
608:             projected_through=projected,
609:             view_generation=view_generation,
610:         )
611:         if (
612:             basis.lineage != captured.lineage
613:             or basis.captured_head != captured
614:             or basis.projected_through != captured
615:         ):
616:             raise DeclarationStale(
617:                 "declaration intent basis disagrees with its CURRENT predecessor head"
618:             )
619:     return DeclarationEditPlan(
620:         status="planned",
621:         target_path=Path(data["target"]).resolve(),
622:         descriptor=_descriptor_from(data["descriptor"]),
623:         lineage=str(data["lineage"]),
624:         basis=basis,
625:         captured_head=captured,
626:         before_documents=(),
627:         proposed_documents=(),
628:         changes=(),
629:         authored_at=drafts[0].authored_at if drafts else None,
630:         observer=str(data["observer"]),
631:         drafts=drafts,
632:         fact_ids=tuple(str(value) for value in data["fact_ids"]),
633:         key_introductions=tuple(str(value) for value in data.get("key_introductions", ())),
634:         old_cache_bytes=old_bytes,
635:         old_cache_sha256=str(data["old_cache_sha256"]),
636:         proposed_text=str(data["proposed_text"]),
637:         atomic_limit=None,
638:         exact_drafts=str(data["exact_drafts"]),
639:     )

701: def _signed_with_existing_key(
702:     *,
703:     signer: Callable[[str, str], str | None] | None,
704:     verifier: Callable[[str, str, str], bool],
705:     registry: Any,
706:     author: str,
707:     head: Head,
708:     digest: str,
709:     label: str,

724:             f"{author!r} at the captured Arrival head"

805: def prepare_declaration_edit(
806:     registry: BackendRegistry,
807:     descriptor: StoreDescriptor,
808:     *,
809:     target: Path | str,
810:     proposed_text: str,
811:     observer: str,
812:     credentials: WriteCredentials | None,
813:     fact_verify: Callable[[str, str, str], bool],
814:     arrival_verify: Callable[[str, str, str], bool],
815:     source_cache_bytes: bytes | None = None,
816:     require_cache_basis: bool = False,
817: ) -> DeclarationEditPlan:
818:     """Prepare one exact declaration transition against an attested CURRENT head.
819: 
820:     This function only reads and signs in memory. It creates no intent, does
821:     not append, and does not touch the declaration cache. The registry opener
822:     is expected to return an attested custody handle; its ``scan`` is the
823:     structurally verified genesis-through-head sequence required by the
824:     iterable authorship seam.
825:     """
826:     target_path = Path(target).resolve()
827:     if not isinstance(proposed_text, str) or not proposed_text:
828:         raise _preparation_refused("proposed declaration text is empty")
829:     try:
830:         old_cache_bytes = target_path.read_bytes()
831:     except OSError as exc:
832:         raise _preparation_refused(
833:             f"cannot read declaration cache {target_path}: {exc}"
834:         ) from exc
835:     if source_cache_bytes is not None and old_cache_bytes != source_cache_bytes:
836:         raise _preparation_refused(
837:             "declaration cache changed while preparing the requested splice"
838:         )
839:     try:
840:         ast = parse_vertex(proposed_text, path=target_path)
841:         validate_vertex(ast)
842:     except Exception as exc:
843:         raise _preparation_refused(
844:             f"proposed declaration is not valid Vertex grammar/semantics: {exc}"
845:         ) from exc
846:     validate_arrival_runtime_identity(
847:         ast.name,
848:         ast.loops,
849:         refusal=_preparation_refused,
850:     )
851:     _validate_residence(target_path, ast, descriptor)
852:     proposed_documents = tuple(
853:         document.as_json() for document in vertex_to_documents(ast)
854:     )
855: 
856:     ledger: ArrivalLedger | None = None
857:     query: ArrivalQuery | None = None
858:     snapshot: Any | None = None
859:     atomic_limit: int | None = None
860:     captured_head: Head | None = None
861:     try:
862:         ledger, query = registry.open(descriptor)
863:         report = getattr(ledger, "opened", None)
864:         comparison = getattr(report, "comparison", None)
865:         if isinstance(comparison, PreGenesis):
866:             if comparison.ledger_refusal is not None:
867:                 raise _preparation_refused(
868:                     f"Arrival ledger is not opened: {comparison.ledger_refusal}"
869:                 )
870:             raise _preparation_refused(
871:                 "Arrival ledger has no captured head for declaration editing"
872:             )
873:         if isinstance(comparison, Indeterminate):
874:             raise _preparation_refused(
875:                 f"Arrival head attestation is indeterminate: {comparison.refusal}"
876:             )
877:         if not isinstance(comparison, Compared):
878:             raise _preparation_refused(
879:                 "registry opener did not provide a compared Arrival head"
880:             )
881:         captured_head = comparison.presented
882:         snapshot = query.open_snapshot(
883:             captured_head=captured_head,
884:             requirement=ProjectionRequirement.CURRENT,
885:             continuation=None,
886:         )
887:         validate_arrival_declaration_anchor(
888:             snapshot.declaration_anchor, captured_head
889:         )
890:         facts = snapshot.facts(
891:             FactRequest(
892:                 limit=None,
893:                 kind="_decl",
894:                 include_internal=True,
895:                 order="oldest",
896:             )
897:         ).items
898:         documents = resolve_declaration_documents_from_snapshot(
899:             snapshot.declaration_anchor, facts
900:         )
901:         if documents is None or isinstance(documents, Unhistorized):
902:             raise _preparation_refused(
903:                 "the CURRENT Arrival snapshot has no historized declaration"
904:             )
905:         represented = snapshot.represented
906:         if represented is None:
907:             raise _preparation_refused(
908:                 "the CURRENT declaration snapshot has no matching lineage basis"
909:             )
910:         projected = complete_projection_custody(
911:             ledger,
912:             captured=captured_head,
913:             represented=represented,
914:             lineage_refusal=lambda message: _preparation_refused(message),
915:             conflict_refusal=lambda message: _preparation_refused(message),
916:         )
917:         if projected.ordinal < captured_head.ordinal:
918:             behind = ProjectionBehind(
919:                 "the CURRENT declaration snapshot is behind the captured Arrival head"
920:             )
921:             behind.captured_head = captured_head
922:             behind.projected_head = projected
923:             raise behind
924:         basis = ReadBasis(
925:             lineage=captured_head.lineage,
926:             captured_head=captured_head,
927:             projected_through=projected,
928:             view_generation=getattr(snapshot, "view_generation", None),
929:         )
930:         before_documents = tuple(dict(document) for document in documents)
931:         if require_cache_basis:
932:             try:
933:                 local_ast = parse_vertex(
934:                     old_cache_bytes.decode("utf-8"), path=target_path
935:                 )
936:                 local_documents = tuple(
937:                     document.as_json() for document in vertex_to_documents(local_ast)
938:                 )
939:             except Exception as exc:
940:                 raise _preparation_refused(
941:                     f"current declaration cache is not valid for this splice: {exc}"
942:                 ) from exc
943:             if local_documents != before_documents:
944:                 raise _preparation_refused(
945:                     "declaration cache differs from CURRENT Arrival history; "
946:                     "convenience mutation refused"
947:                 )
948:         changes = tuple(diff_documents(before_documents, proposed_documents))
949:         continuity_ticks = tuple(
950:             snapshot.ticks(TickRequest(since=float("-inf")))
951:         )
952:         verified_params = collect_verified_parameter_rows(
953:             snapshot.declaration_anchor,
954:             facts,
955:             target_documents=proposed_documents,
956:             base_dir=target_path.parent,
957:         )
958:         analyze_boundary_continuity(
959:             snapshot.declaration_anchor,
960:             facts,
961:             continuity_ticks,
962:             target_documents=proposed_documents,
963:             verified_params=verified_params,
964:         )
965:         key_registry, _key_evidence = key_registry_from_records(
966:             ledger.scan(through=captured_head), arrival_verify
967:         )
968:         atomic_limit = ledger.capabilities().max_atomic_records
969:     except DeclarationPreparationError:
970:         raise
971:     except BoundaryContinuityConflict as exc:
972:         raise _preparation_refused(
973:             f"boundary continuity refuses declaration preparation: {exc}",
974:             captured_head=captured_head,
975:         ) from exc
976:     except Exception as exc:
977:         raise _preparation_refused(
978:             f"cannot establish declaration preparation basis: {exc}",
979:             captured_head=captured_head,
980:             projected_head=getattr(exc, "projected_head", None),
981:         ) from exc
982:     finally:
983:         _close_quietly(snapshot)
984:         _close_quietly(query)
985:         _close_quietly(ledger)
986: 
987:     if not changes:
988:         return DeclarationEditPlan(
989:             status="noop",
990:             target_path=target_path,
991:             descriptor=descriptor,
992:             lineage=captured_head.lineage,
993:             basis=basis,
994:             captured_head=captured_head,
995:             before_documents=before_documents,
996:             proposed_documents=proposed_documents,
997:             changes=(),
998:             authored_at=None,
999:             observer=observer,
1000:             drafts=(),
1001:             fact_ids=(),
1002:             key_introductions=(),
1003:             old_cache_bytes=old_cache_bytes,
1004:             old_cache_sha256=hashlib.sha256(old_cache_bytes).hexdigest(),
1005:             proposed_text=proposed_text,
1006:             atomic_limit=atomic_limit,
1007:             exact_drafts=_exact_drafts(()),
1008:         )
1009: 
1010:     if credentials is None:
1011:         raise _preparation_refused(
1012:             "declaration edits require fact and Arrival signers"
1013:         )
1014:     authored_at = time.time()
1015:     rows: list[tuple[Any, ...]] = []
1016:     fact_ids: list[str] = []
1017:     for change in changes:
1018:         fact_id, row = _declaration_row(
1019:             change,
1020:             lineage=captured_head.lineage,
1021:             authored_at=authored_at,
1022:             observer=observer,
1023:             credentials=credentials,
1024:             registry=key_registry,
1025:             captured_head=captured_head,
1026:             fact_verify=fact_verify,
1027:         )
1028:         fact_ids.append(fact_id)
1029:         rows.append(row)
1030:     body = body_of_fact_row(rows[0]) if len(rows) == 1 else body_of_batch(rows)
1031:     envelope_kind = "fact" if len(rows) == 1 else "batch"
1032:     envelope_digest = content_commitment(
1033:         envelope_kind, authored_at, observer, "", body
1034:     )
1035:     outer_signature = _signed_with_existing_key(
1036:         signer=credentials.arrival_signer,
1037:         verifier=arrival_verify,
1038:         registry=key_registry,
1039:         author=observer,
1040:         head=captured_head,
1041:         digest=envelope_digest,
1042:         label="Arrival declaration envelope",
1043:     )
1044:     declaration_draft = RecordDraft(
1045:         kind=envelope_kind,
1046:         authored_at=authored_at,
1047:         observer=observer,
1048:         origin="",
1049:         body=body,
1050:         signature=outer_signature,
1051:     )
1052: 
1053:     proposed_keys: dict[str, str] = {}
1054:     for document in proposed_documents:
1055:         if document["kind"] != DECL_OBSERVER_DEFINED:
1056:             continue
1057:         key = document["payload"].get("key")
1058:         if key is None:
1059:             continue
1060:         if not _key_is_well_formed(key):
1061:             raise _preparation_refused(
1062:                 f"observer {document['subject']!r} carries a malformed public key"
1063:             )
1064:         proposed_keys[str(document["subject"])] = str(key)
1065:     existing_keys = {
1066:         named_observer: {key for key, _ordinal in keys}
1067:         for named_observer, keys in key_registry.introductions.items()
1068:     }
1069:     key_drafts: list[RecordDraft] = []
1070:     for named_observer, key in proposed_keys.items():
1071:         if key in existing_keys.get(named_observer, set()):
1072:             continue
1073:         key_drafts.append(
1074:             _key_draft(
1075:                 observer,
1076:                 named_observer,
1077:                 key,
1078:                 authored_at=authored_at,
1079:                 credentials=credentials,
1080:                 registry=key_registry,
1081:                 captured_head=captured_head,
1082:                 arrival_verify=arrival_verify,
1083:             )
1084:         )
1085: 
1086:     drafts = tuple((*key_drafts, declaration_draft))
1087:     if atomic_limit is not None and len(drafts) > atomic_limit:
1088:         raise AtomicLimitExceeded(
1089:             f"declaration edit needs {len(drafts)} Arrival records, but the "
1090:             f"backend atomic limit is {atomic_limit}; refused before append"
1091:         )
1092:     return DeclarationEditPlan(
1093:         status="planned",
1094:         target_path=target_path,
1095:         descriptor=descriptor,
1096:         lineage=captured_head.lineage,
1097:         basis=basis,
1098:         captured_head=captured_head,
1099:         before_documents=before_documents,
1100:         proposed_documents=proposed_documents,
1101:         changes=changes,
1102:         authored_at=authored_at,
1103:         observer=observer,
1104:         drafts=drafts,
1105:         fact_ids=tuple(fact_ids),
1106:         key_introductions=tuple(draft.body["observer"] for draft in key_drafts),
1107:         old_cache_bytes=old_cache_bytes,
1108:         old_cache_sha256=hashlib.sha256(old_cache_bytes).hexdigest(),
1109:         proposed_text=proposed_text,
1110:         atomic_limit=atomic_limit,
1111:         exact_drafts=_exact_drafts(drafts),
1112:     )

1169: def _apply_declaration_edit(
1170:     registry: BackendRegistry,
1171:     plan: DeclarationEditPlan,
1172:     *,
1173:     failure_hook: Callable[[str], None] | None = None,
1174: ) -> DeclarationEditResult:
1175:     """Append one prepared declaration transition and publish its cache.
1176: 
1177:     The prepared drafts are submitted exactly once under the captured full
1178:     head. Contract refusals are zero-prefix stale refusals; transport and
1179:     witness failures retain the intent and their identity for recovery.
1180:     """
1181:     _validate_plan(plan)
1182:     if plan.status == "noop":
1183:         return _result(
1184:             plan, status="noop", head=plan.captured_head, commit=None, intent=None,
1185:             phase="noop", file_written=False, changes=plan.changes,
1186:         )
1187:     intent = declaration_intent_path(plan.target_path)
1188:     try:
1189:         if plan.target_path.read_bytes() != plan.old_cache_bytes:
1190:             raise DeclarationStale(
1191:                 "declaration cache changed after preparation; refusing append"
1192:             )
1193:     except OSError as exc:
1194:         raise DeclarationApplyError(

1422:     except Exception as exc:

1424:             "declaration custody is committed but cache recovery remains incomplete",

47: def _tick_fields(tick: Any, change: Any) -> tuple[str | None, str | None]:
48:     """Resolve (tick_mark, tick_id) for a receipt whose write fired a boundary.
49: 
50:     The in-memory engine ``Tick`` carries no id — the store assigns one on the
51:     tick row, surfaced as ``TickEvent.tick_id`` in the post-write ``ChangeBatch``.
52:     Reading ``tick.id`` off the Tick object was an AttributeError on every
53:     boundary-firing emission.
54:     """
55:     if tick is None:
56:         return None, None
57:     tick_id: str | None = None
58:     if change is not None and change.ticks:
59:         matching = [ev for ev in change.ticks if ev.name == tick.name]
60:         if matching:
61:             tick_id = matching[-1].tick_id
62:     return tick.name, tick_id

268: def init_vertex(
269:     target: Path | str,
270:     *,
271:     name: str | None = None,
272:     store_type: str = "sqlite",
273:     store_path: str | Path | None = None,
274:     is_root: bool = False,
275:     observer: str | None = None,
276:     strict: bool = False,
277:     overwrite: bool = False,
278:     backend: str | None = None,
279:     location: str | Path | None = None,
280:     documents: list[dict] | None = None,
281:     signer=None,
282:     fact_signer=None,
283:     public_key: str | None = None,
284:     recover: bool = False,
285:     registry: BackendRegistry | None = None,
286: ) -> InitVertexResult:
287:     """Scaffold a new Loops .vertex declaration file.
288: 
289:     Parameters:
290:         target: Target .vertex file path to create.
291:         name: Name of the vertex (defaults to target file stem).
292:         store_type: Backing store format ('sqlite' or 'jsonl').
293:         store_path: Custom store path (defaults to .loops/data/<name>.db or .jsonl).
294:         is_root: If True, scaffolds an aggregate root discovery vertex.
295:         observer: Initial observer identity to register.
296:         strict: If True, declares 'strict true'.
297:         overwrite: If True, overwrites existing file.
298: 
299:     Returns:
300:         InitVertexResult detailing the created vertex file and storage paths.
301:     """
302:     vertex_path = Path(target).resolve()
303: 
304:     # Arrival initialization is an explicit extension of this existing SDK
305:     # operation.  Keeping the legacy arm below preserves callers that ask for
306:     # SQLite/JSONL scaffolding while the clean Arrival cut is adopted; no
307:     # legacy opener is reached by the descriptor arm.
308:     arrival_requested = (
309:         store_type.lower() == "arrival"
310:         or backend is not None
311:         or location is not None
312:         or documents is not None
313:         or recover
314:     )
315:     if arrival_requested and not is_root:
316:         return _init_arrival(
317:             vertex_path,
318:             name=name,
319:             strict=strict,
320:             observer=observer,
321:             backend=backend,
322:             location=location,
323:             store_path=store_path,
324:             documents=documents,
325:             signer=signer,
326:             fact_signer=fact_signer,
327:             public_key=public_key,
328:             recover=recover,
329:             overwrite=overwrite,
330:             registry=registry,
331:         )
332:     if vertex_path.exists() and not overwrite:
333:         raise TargetError(f"vertex file already exists: {vertex_path}")
334: 
335:     v_name = name or vertex_path.stem
336: 
337:     if is_root:
338:         content = (
339:             f'name "{v_name}"\n'
340:             "// Root vertex — discovers all .vertex files under this directory\n"
341:             'discover "./**/*.vertex"\n'
342:         )
343:         resolved_store = None
344:     else:
345:         ext = ".jsonl" if store_type.lower() == "jsonl" else ".db"
346:         default_store = f".loops/data/{v_name}{ext}"
347:         resolved_store = str(store_path) if store_path is not None else default_store
348: 
349:         lines = [f'name "{v_name}"', f'store "{resolved_store}"']
350:         if strict:
351:             lines.append("strict true")
352:         lines.append("")
353: 
354:         if observer:
355:             # Ensure keypair exists for initial observer
356:             from custody import ensure_signing_key
357: 
358:             keypair = ensure_signing_key(vertex_path, observer=observer)
359:             lines.append("observers {")
360:             lines.append(f"  {observer} {{")
361:             lines.append(f'    key "{keypair.public_b64}"')
362:             lines.append("  }")
363:             lines.append("}")
364:             lines.append("")
365: 
366:         lines.append("loops {")
367:         lines.append("  item {")
368:         lines.append("    fold {")
369:         lines.append('      items "collect" 100')
370:         lines.append("    }")
371:         lines.append("  }")
372:         lines.append("}")
373:         lines.append("")
374:         content = "\n".join(lines)
375: 
376:     # Ensure parent directory exists
377:     vertex_path.parent.mkdir(parents=True, exist_ok=True)
378:     vertex_path.write_text(content, encoding="utf-8")
379: 
380:     return InitVertexResult(
381:         target_path=str(vertex_path),
382:         name=v_name,
383:         store_path=resolved_store,
384:         store_type=store_type,
385:         is_root=is_root,
386:         file_written=True,
387:     )

390: def _init_arrival(
391:     vertex_path: Path,
392:     *,
393:     name: str | None,
394:     strict: bool,
395:     observer: str | None,
396:     backend: str | None,
397:     location: str | Path | None,
398:     store_path: str | Path | None,
399:     documents: list[dict] | None,
400:     signer,
401:     fact_signer,
402:     public_key: str | None,
403:     recover: bool,
404:     overwrite: bool,
405:     registry: BackendRegistry | None,
406: ) -> InitVertexResult:
407:     """Compose custody and language inputs for the engine initializer."""
408:     from engine.arrival_contract import Profile, StoreDescriptor
409:     from engine.arrival_initialization import (
410:         arrival_intent_path,
411:         initialize_arrival,
412:         new_lineage,
413:         recover_arrival_initialization,
414:     )
415:     from engine.declaration import validate_arrival_runtime_identity
416:     from lang import parse_vertex, vertex_to_documents
417: 
418:     from .errors import normalize_exception
419: 
420:     if overwrite:
421:         raise TargetError("Arrival initialization never overwrites an existing artifact")
422:     intent_data = None
423:     if recover:
424:         try:
425:             intent_data = json.loads(arrival_intent_path(vertex_path).read_text())
426:             reserved = intent_data["descriptor"]
427:             reserved_observer = str(intent_data["observer"])
428:             if observer is None:
429:                 observer = reserved_observer
430:             elif observer != reserved_observer:
431:                 raise SdkValueError(
432:                     "recovery observer disagrees with the reserved initialization intent"
433:                 )
434:             if backend is not None and backend != reserved["backend"]:
435:                 raise SdkValueError(
436:                     "recovery backend disagrees with the reserved initialization intent"
437:                 )
438:             if public_key is not None and public_key != str(intent_data["public_key"]):
439:                 raise SdkValueError(
440:                     "recovery public key disagrees with the reserved initialization intent"
441:                 )
442:             requested_location = location if location is not None else store_path
443:             if reserved["backend"] == "file" and requested_location is not None:
444:                 requested_location = str(
445:                     (vertex_path.parent / str(requested_location)).resolve()
446:                     if not Path(str(requested_location)).is_absolute()
447:                     else Path(str(requested_location)).resolve()
448:                 )
449:             if (
450:                 requested_location is not None
451:                 and str(requested_location) != str(reserved["location"])
452:             ):
453:                 raise SdkValueError(
454:                     "recovery location disagrees with the reserved initialization intent"
455:                 )
456:         except SdkValueError:
457:             raise
458:         except (OSError, ValueError, KeyError) as exc:
459:             raise TargetError(f"cannot load Arrival initialization intent: {exc}") from exc
460:     if not observer:
461:         raise SdkValueError("Arrival initialization requires observer")
462:     if location is not None and store_path is not None and str(location) != str(store_path):
463:         raise SdkValueError(
464:             "Arrival initialization received conflicting location and store_path"
465:         )
466:     if location is None:
467:         location = store_path
468:     v_name = name or vertex_path.stem
469:     if not recover:
470:         # The SDK scaffold declares item, and the runtime also adds cite.
471:         # Refuse these collisions before the default custody path creates keys.
472:         validate_arrival_runtime_identity(v_name, ("item",), refusal=SdkValueError)
473:     chosen_backend = backend or "file"
474:     if location is None:
475:         relative_location = f".loops/data/{v_name}.arrival"
476:         descriptor_location = str((vertex_path.parent / relative_location).resolve())
477:     elif chosen_backend == "file":
478:         relative_location = str(location)
479:         descriptor_location = str((vertex_path.parent / relative_location).resolve())
480:     else:
481:         # A DSN is opaque to the SDK as well as to the engine registry.
482:         relative_location = str(location)
483:         descriptor_location = relative_location
484: 
485:     # Verification is independent of where signing callables came from.  A
486:     # caller-supplied pair still has to prove both protocol domains against
487:     # the supplied public key before an intent or mint is attempted.
488:     from custody.signing import ARRIVAL_DOMAIN, FACT_DOMAIN
489:     from sign import ed25519
490: 
491:     def _verify(domain: str, key: str, signature: str, digest: str) -> bool:
492:         try:
493:             public = ed25519.public_key_from_b64(key)
494:         except ValueError:
495:             return False
496:         return ed25519.verify(public, signature, digest.encode(), domain=domain)
497: 
498:     def _fact_verify(key: str, signature: str, digest: str) -> bool:
499:         return _verify(FACT_DOMAIN, key, signature, digest)
500: 
501:     def _arrival_verify(key: str, signature: str, digest: str) -> bool:
502:         return _verify(ARRIVAL_DOMAIN, key, signature, digest)
503: 
504:     fact_verify = _fact_verify
505:     arrival_verify = _arrival_verify
506:     if not recover:
507:         # The SDK is the custody owner. An injected signer/key pair is useful
508:         # to headless deployments; absent one, key creation/loading is the
509:         # same explicit custody operation used by the existing init command.
510:         from custody import arrival_signer_for, ensure_signing_key, fact_signer_for
511: 
512:         if signer is None and fact_signer is None and public_key is None:
513:             try:
514:                 keypair = ensure_signing_key(vertex_path, observer=observer)
515:             except ValueError as exc:
516:                 raise SdkValueError(str(exc)) from exc
517:             public_key = keypair.public_b64
518:             signer = arrival_signer_for(vertex_path)
519:             fact_signer = fact_signer_for(vertex_path)
520:         elif (
521:             signer is None
522:             or fact_signer is None
523:             or public_key is None
524:             or not callable(signer)
525:             or not callable(fact_signer)
526:         ):
527:             raise SdkValueError(
528:                 "Arrival initialization custom credentials require arrival signer, "
529:                 "fact signer, and public key"
530:             )
531:         if signer is None or fact_signer is None or public_key is None:
532:             raise SdkValueError("Arrival initialization requires usable custody signers")
533: 
534:     lineage = None
535:     if not recover:
536:         lineage = new_lineage()
537:         lines = [
538:             f"name {_kdl_quote(v_name, field='vertex name')}",
539:             f"store {_kdl_quote(relative_location, field='store location')} "
540:             f"backend={_kdl_quote(chosen_backend, field='backend')} "
541:             f"lineage={_kdl_quote(lineage, field='lineage')} role=\"authority\"",
542:         ]
543:         if strict:
544:             lines.append("strict true")
545:         lines.extend(
546:             [
547:                 "observers {",
548:                 f"  {_kdl_quote(observer, field='observer')} {{",
549:                 f"    key {_kdl_quote(public_key, field='public key')}",
550:                 "  }",
551:                 "}",
552:                 "",
553:                 "loops {",
554:                 "  item {",
555:                 "    fold {",
556:                 '      items "collect" 100',
557:                 "    }",
558:                 "  }",
559:                 "}",
560:                 "",
561:             ]
562:         )
563:         declaration_text = "\n".join(lines)
564:         try:
565:             ast = parse_vertex(declaration_text, path=vertex_path)
566:         except Exception as exc:
567:             raise SdkValueError(f"invalid Arrival declaration text: {exc}") from exc
568:         parsed_documents = [doc.as_json() for doc in vertex_to_documents(ast)]
569:         if documents is None:
570:             documents = parsed_documents
571:         elif documents != parsed_documents:
572:             raise SdkValueError(
573:                 "Arrival declaration text and declaration documents disagree"
574:             )
575:         if (
576:             ast.store_backend is None
577:             or ast.store_backend.name != chosen_backend
578:             or ast.store_backend.role != "authority"
579:             or ast.store_backend.lineage != lineage
580:         ):
581:             raise SdkValueError(
582:                 "Arrival declaration must carry the requested backend, lineage and authority role"
583:             )
584:     else:
585:         # Recovery reads the stable observer and descriptor from the intent;
586:         # the target is not re-rendered and no new lineage is selected.
587:         try:
588:             intent_data = intent_data or json.loads(arrival_intent_path(vertex_path).read_text())
589:             lineage = str(intent_data["lineage"])
590:             declaration_text = str(intent_data["declaration_text"])
591:             if documents is None:
592:                 documents = list(intent_data["documents"])
593:             reserved_descriptor = intent_data["descriptor"]
594:             chosen_backend = str(reserved_descriptor["backend"])
595:             descriptor_location = str(reserved_descriptor["location"])
596:             relative_location = descriptor_location
597:             parsed = parse_vertex(declaration_text, path=vertex_path)
598:             v_name = parsed.name
599:         except (OSError, ValueError, KeyError) as exc:
600:             raise TargetError(f"cannot load Arrival initialization intent: {exc}") from exc
601: 
602:     descriptor = StoreDescriptor(
603:         backend=chosen_backend,
604:         location=descriptor_location,
605:         lineage=lineage,
606:         role=Profile.AUTHORITY,
607:     )
608:     active_registry = (
609:         registry if registry is not None else BackendRegistry.with_builtin_backends()
610:     )
611:     try:
612:         if recover:
613:             result = recover_arrival_initialization(
614:                 active_registry,
615:                 arrival_intent_path(vertex_path),
616:             )
617:         else:
618:             result = initialize_arrival(
619:                 active_registry,
620:                 descriptor,
621:                 target=vertex_path,
622:                 documents=documents or (),
623:                 declaration_text=declaration_text,
624:                 observer=observer,
625:                 public_key=public_key,
626:                 signer=signer,
627:                 fact_signer=fact_signer,
628:                 arrival_signer=signer,
629:                 fact_verify=fact_verify,
630:                 arrival_verify=arrival_verify,
631:                 lineage=lineage,
632:             )
633:     except BaseException as exc:
634:         details = {"intent_path": str(arrival_intent_path(vertex_path))}
635:         context = {"fact_id": lineage} if lineage is not None else None
636:         normalized = normalize_exception(exc, context=context)
637:         if hasattr(normalized, "details"):
638:             normalized.details.update(details)
639:         if normalized is exc:
640:             # Keep SDK exceptions and process-control exceptions exactly as
641:             # raised.  ``raise exc from exc`` would install a self-cause and
642:             # obscure both cancellation and an already-established cause.
643:             raise
644:         raise normalized from exc
645:     return InitVertexResult(
646:         target_path=str(vertex_path),
647:         name=v_name,
648:         read_path="arrival",
649:         store=StoreDescriptorInfo(
650:             backend=chosen_backend,
651:             location=descriptor_location,
652:             lineage=result.lineage,
653:             role="authority",
654:         ),
655:         store_path=relative_location,
656:         store_type="arrival",
657:         is_root=False,
658:         file_written=result.file_written,
659:         lineage=result.lineage,
660:         head={
661:             "lineage": result.head.lineage,
662:             "ordinal": result.head.ordinal,
663:             "record_hash": result.head.record_hash,
664:         },
665:         phase=result.phase,
666:     )

669: def inspect_declaration(
670:     target: Path | str,
671:     *,
672:     registry: BackendRegistry | None = None,
673: ) -> DeclarationInspectionResult:
674:     """Inspect a .vertex declaration without materializing its projection.
675: 
676:     Parameters:
677:         target: Path to the .vertex file.
678:         registry: Optional Arrival backend registry used for descriptor opens.
679: 
680:     Returns:
681:         DeclarationInspectionResult containing AST metadata, admission rules, and syntax health.
682:     """
683:     path = Path(target).resolve()
684:     if not path.exists():
685:         raise TargetNotFound(f"target path does not exist: {path}")
686: 
687:     # A descriptor is residence, not a legacy probe hint. Establish its
688:     # attested bounded snapshot before considering the compatibility branch.
689:     from .read import _arrival_declaration, _open_arrival_read
690:     from .target import _arrival_definition
691: 
692:     definition = _arrival_definition(path, allow_aggregate=True)
693:     if definition is not None and definition[2] is not None:
694:         definition_path, definition_ast, descriptor = definition
695:         arrival = (definition_path, definition_ast, descriptor)
696:         with _open_arrival_read(arrival, registry=registry) as (
697:             locator_ast,
698:             descriptor,
699:             opened,
700:         ):
701:             effective_ast, effective_status, _facts, _own_lineage = _arrival_declaration(
702:                 locator_ast, path, opened, allow_aggregate=True
703:             )
704:             local_fingerprint = _document_fingerprint(locator_ast)
705:             effective_fingerprint = _document_fingerprint(effective_ast)
706:             declared_kinds, declared_observers, cadence_ticks, strict, is_aggregate = (
707:                 _inspection_fields(effective_ast)
708:             )
709:             local_combine, local_discover = _inspection_topology(locator_ast)
710:             effective_combine, effective_discover = _inspection_topology(effective_ast)
711:             return DeclarationInspectionResult(
712:                 read_path="arrival",
713:                 store=StoreDescriptorInfo.from_descriptor(descriptor),
714:                 basis=opened.basis,
715:                 target_path=str(path),
716:                 name=effective_ast.name,
717:                 status=effective_status,
718:                 local_status=(
719:                     "matches-effective"
720:                     if local_fingerprint == effective_fingerprint
721:                     else "drifted"
722:                 ),
723:                 effective_status=effective_status,
724:                 local_fingerprint=local_fingerprint,
725:                 effective_fingerprint=effective_fingerprint,
726:                 store_mode=descriptor.backend,
727:                 store_path=descriptor.location,
728:                 declared_kinds=declared_kinds,
729:                 declared_observers=declared_observers,
730:                 cadence_ticks=cadence_ticks,
731:                 strict=strict,
732:                 is_aggregate=is_aggregate,
733:                 local_combine=local_combine,
734:                 local_discover=local_discover,
735:                 effective_combine=effective_combine,
736:                 effective_discover=effective_discover,
737:                 syntax_valid=True,
738:                 errors=[],
739:             )
740: 
741:     # A valid storeless aggregate has no adopted declaration to consult. Its
742:     # root AST is the exact one just parsed by the target resolver, avoiding a
743:     # second file read before a legacy probe could observe replacement bytes.
744:     if (
745:         definition is not None
746:         and definition[2] is None
747:         and definition[1].store is None
748:         and (definition[1].combine is not None or definition[1].discover is not None)
749:     ):
750:         return _frozen_local_aggregate_inspection(definition[0], definition[1])
751: 
752:     probe = probe_target(path)
753:     if probe.target_type != "vertex":
754:         raise SdkValueError(
755:             f"inspect_declaration requires a .vertex target, got {probe.target_type}"
756:         )
757: 
758:     errors: list[str] = []
759:     syntax_valid = True
760:     file_ast = None
761:     try:
762:         file_ast = parse_vertex_file(path)
763:     except Exception as exc:
764:         syntax_valid = False
765:         errors.append(str(exc))
766: 
767:     decl_status = None
768:     if syntax_valid:
769:         try:
770:             decl_ast, decl_status = load_declaration_status(path)
771:         except Exception as exc:
772:             errors.append(str(exc))
773: 
774:     v_name = getattr(file_ast, "name", path.stem) if file_ast else path.stem
775:     store_mode = probe.canonical_mode
776:     store_path = str(probe.canonical_path) if probe.canonical_path else None
777: 
778:     declared_kinds, declared_observers, cadence_ticks, strict, is_aggregate = _inspection_fields(
779:         file_ast
780:     )
781:     local_combine, local_discover = _inspection_topology(file_ast)
782: 
783:     return DeclarationInspectionResult(
784:         target_path=str(path),
785:         name=v_name,
786:         status=decl_status or "uninitialized",
787:         local_status=decl_status if syntax_valid else "syntax-invalid",
788:         effective_status=decl_status,
789:         store_mode=store_mode,
790:         store_path=store_path,
791:         declared_kinds=declared_kinds,
792:         declared_observers=declared_observers,
793:         cadence_ticks=cadence_ticks,
794:         strict=strict,
795:         is_aggregate=is_aggregate,
796:         local_combine=local_combine,
797:         local_discover=local_discover,
798:         syntax_valid=syntax_valid,
799:         errors=errors,
800:     )

835: def _inspection_fields(ast: Any | None) -> tuple[list[str], list[str], list[str], bool, bool]:
836:     """Extract public declaration fields from one already-chosen AST."""
837:     if ast is None:
838:         return [], [], [], False, False
839:     return (
840:         sorted(ast.loops.keys()) if getattr(ast, "loops", None) else [],
841:         (
842:             sorted(observer.name for observer in ast.observers)
843:             if getattr(ast, "observers", None)
844:             else []
845:         ),
846:         sorted(tick.name for tick in ast.cadence) if getattr(ast, "cadence", None) else [],
847:         getattr(ast, "strict", False),
848:         getattr(ast, "combine", None) is not None or getattr(ast, "discover", None) is not None,
849:     )

852: def _inspection_topology(
853:     ast: Any | None,
854: ) -> tuple[list[dict[str, str | None]] | None, str | None]:
855:     """Serialize only one declaration root's unexpanded aggregate shape."""
856:     if ast is None:
857:         return None, None
858:     combine = getattr(ast, "combine", None)
859:     return (
860:         None
861:         if combine is None
862:         else [{"name": entry.name, "alias": entry.alias} for entry in combine],

867: def _document_fingerprint(ast: Any) -> str:
868:     """Hash semantic declaration documents, deliberately excluding residence."""
869:     from lang import vertex_to_documents
870: 
871:     documents = vertex_to_documents(ast)
872:     canonical = json.dumps(
873:         [document.as_json() for document in documents],
874:         sort_keys=True,
875:         separators=(",", ":"),
876:     )
877:     return "sha256:" + hashlib.sha256(canonical.encode("utf-8")).hexdigest()
