1: # C2 evidence contract — September 6, 2026
2: 
3: Status: design only. This specifies the evidence required before public SDK
4: normalization is widened; it neither changes wire records nor declares a common
5: transaction for custody, projection, cache publication, dispatch, or external
6: collection.
7: 
8: ## What exists now
9: 
10: `normalize_exception` already preserves important public categories:
11: `WriteCommitUnknown`/batch equivalents become an unknown custody outcome,
12: `NotWitnessed` retains its resulting head and an actual `Commit` where the
13: underlying operation supplies one; post-commit projection failures retain their
14: commit. Initialization, declaration recovery, and restore have
15: operation-specific unknown/incomplete wrappers. Source invocation instead
16: returns structured per-tier results, preserving an earlier durable tier while a
17: later tier is uncommitted or unknown.
18: 
19: There are two material gaps. `sync_target` calls `sync_projection` directly and
20: therefore bypasses the existing `ProjectionSyncError ->
21: ProjectionOutcomeUnknown` mapping (`sdk/read.py:sync_target`). Also,
22: `_identity_details` serializes wrapper coordinates but not `exc.cause`, so an
23: in-process maintenance caller can inspect the causal exception while an SDK
24: caller cannot identify its stable type or its evidence. The same concern applies
25: to search-index synchronization. Declaration preparation catches a
26: `ProjectionBehind` in its generic preparation wrapper
27: (`arrival_declarations.py:prepare_declaration_edit`); chaining retains the
28: cause today, but public normalization must not erase it.
29: 
30: The current maintenance wrapper is intentionally conservative. Once
31: `sync_projection` enters its catch-up attempt, it wraps an ordinary
32: `Exception` as
33: `ProjectionSyncError(target, projected_before, observed_after, cause)`.
34: Some adapter checks can fail before changing rows, but the wrapper does not
35: prove that for every implementation. `SearchIndexSyncError` has the analogous
36: shape after a target is selected. Thus a nested `NotAuthority`,
37: `ProjectionBehind`, or backend refusal is not sufficient evidence of a
38: known-unmodified projection. Capture/open failures occur before that wrapper;
39: `BaseException` control flow, including cancellation, escapes it.
40: 
41: A successful sync can report `projected_after > target` when another serialized
42: maintainer legitimately advanced it. This proves custody-resolved coverage of
43: the target, not row-for-row projection provenance; the explicit restore audit
44: is the stronger operation.
45: 
46: ## Proposed public evidence shape
47: 
48: This is a narrow additive schema for the existing maintenance, write and
49: source result/error DTOs. It is not a universal operation framework: each
50: operation exposes only fields it can prove, under its existing names where
51: possible. `phase` below is proposed new evidence, not a claim that every
52: current exception already carries it.
53: 
54: | Field | Meaning |
55: | --- | --- |
56: | `phase` | The operation-local coordinator stage proved reached, such as `capture`, `prepare`, `custody-append`, `derived-sync`, `cache-publication`, or `dispatch`. It is not a global ordering across resources. |
57: | `effects` | Per-resource entries for `custody`, `witness`, `derived`, `cache`/`artifact`, or `dispatch`, each with `attempt` and `state`; see concrete values below. |
58: | `basis` | Captured `H`/`P`/generation where one exists, target/actual projection heads for maintenance, and declaration anchor where interpretation mattered. |
59: | `identities` | Planned fact/tick IDs, item or tier index, observer/kind, and a real `Commit` before/after when known. No invented Commit for a no-op or recovery. |
60: | `cause` | A bounded recursive diagnostic: causal type name, message, and the same safe identity coordinates available on that cause. Keep the Python exception chain in-process; serialize at most a documented short chain, no payload bodies or arbitrary `repr`. |
61: 
62: **Concrete additive SDK shape:** put an optional object at
63: `details["evidence"]`, retaining `loops.sdk/error/v1` and all current top-level
64: error fields:
65: 
66: ```json
67: {"schema":"loops.sdk/evidence/v1", "phase":"derived-sync",
68:  "effects":{"derived":{"attempt":"entered", "state":"unknown"}},
69:  "basis":{"target":{}}, "identities":{},
70:  "cause":{"type":"OSError", "message":"…", "details":{}}}
71: ```
72: 
73: When present, `attempt` is exactly `not-entered` or `entered`; it is omitted
74: when a legacy wrapper has no control-flow proof either way. `state` is exactly
75: `not-attempted`, `known-none`, `committed`, `unknown`, `completed`, or
76: `incomplete`. `not-attempted` means this coordinator did not cross that
77: resource's mutation boundary. `known-none` is a distinct proof: an entered
78: adapter call had an explicit atomic-rejection guarantee of no effect. Neither
79: follows merely from a nested exception type. `phase` is proof, not a progress
80: guess. Cancellation and process-control exceptions are re-raised unchanged,
81: with no replacement wrapper. Structured source results use the identical
82: object at `terminal.details["evidence"]`, preserving the current
83: `SourceTerminalResult.details` DTO shape.
84: 
85: The existing categories can map without flattening evidence:
86: 
87: - An admission/preparation refusal is `phase=prepare`,
88:   `custody=not-attempted` only when its planner has not opened its append
89:   boundary. It may report `known-none` after an entered adapter call only with
90:   an explicit atomic-rejection proof; retain the declared admission details and
91:   its nested cause.
92: - A CAS/refusal before `ledger.append` in the runtime executor is a known
93:   no-custody-append refusal. A generic exception after entering `append` is
94:   `custody=unknown` with planned IDs and captured H (`WriteCommitUnknown`).
95: - `NotWitnessed` proves `custody=committed` and `witness=unknown`, with its
96:   resulting head. Its `commit` is present for append/replicate but is `None`
97:   for mint, so only serialize a Commit receipt when one exists; it must never
98:   be relabeled as a refusal.
99: - An `after_commit` failure is `custody=committed`, with a real Commit and an
100:   independently failed/unknown derived effect. Its result must not claim that
101:   projection was performed.
102: - `ProjectionSyncError` and `SearchIndexSyncError` remain
103:   `derived=unknown` unless their coordinator proves either that the derived
104:   boundary was not entered (`not-attempted`) or that an entered adapter call
105:   atomically had no effect (`known-none`). Include target, before,
106:   observed-after/coverage, spec hash for search, and the causal evidence. Do
107:   not infer custody uncertainty: these operations do not append custody
108:   records.
109: - A source result retains each tier's own basis, IDs, Commit/witness/projection
110:   and dispatch evidence. Collected external effects are not rolled back by a
111:   stale or unknown custody append; `known-uncommitted` custody is not evidence
112:   that recollecting is safe. A durable earlier tier is not downgraded by a
113:   later failure. C8b's proposed coordinator-only
114:   `SourceTierCollectionFailed` terminal carries the current tier basis,
115:   completed siblings, failed-source `(Fact, id)` metadata, cancelled sources,
116:   paired partial output, and cause. It belongs in the existing structured
117:   result, with no fabricated `CollectedTier` or lifecycle ID for an incomplete
118:   attempt. C8b serializes this current source-specific evidence at
119:   `terminal.details["collection"]`; that is deliberately separate from the
120:   prospective shared `terminal.details["evidence"]` object. Dispatch remains
121:   one attempted post-commit action with no at-least-once claim.
122: 
123: ## Bounded implementation worklist
124: 
125: 1. Add optional `phase` plus resource-scoped `effects` evidence to the two
126:    maintenance error records only (`ProjectionSyncError`,
127:    `SearchIndexSyncError`), including `attempt=not-entered` only when their
128:    coordinator can establish it. Do not
129:    inspect nested exception classes to synthesize that proof. Keep existing
130:    constructor compatibility with optional fields.
131: 2. Add one small SDK serializer for safe causal evidence and extend
132:    `_identity_details`; preserve existing `source_type`, error classes and
133:    `as_dict` schemas during the first release. A versioned `evidence` member is
134:    safer than repurposing `outcome`.
135: 3. Route Arrival `sync_target` through normalization and retain search sync's
136:    existing normalization boundary; classify their effects from their wrappers'
137:    phase evidence. Preserve direct engine exceptions only where the SDK already
138:    promises them or introduce a documented SDK compatibility transition.
139: 4. Separately annotate declaration preparation/refusal with explicit
140:    preparation proof and
141:    preserve `ProjectionBehind`'s chained coordinates. Do not turn every nested
142:    `ContractRefusal` into a known-uncommitted public refusal.
143: 5. C8b is implementing serialization of `SourceTierCollectionFailed` terminal
144:    evidence in the current source slice; C2 only fixes the shared object shape
145:    and documents the source tier result as the structured equivalent rather
146:    than forcing it through a scalar error class. Defer broad
147:    ordinary/batch/init/restore reshaping until a concrete mismatched public
148:    classification is found.
149: 
150: **Recommendation:** add optional `details.evidence` now. Existing error DTOs
151: already expose extensible `details` mappings; this preserves their v1 schema,
152: outcome and source type. Reserve a v2 envelope only for a later incompatible
153: change, such as moving evidence out of `details` or changing existing outcome
154: names.
155: 
156: ## Acceptance tests
157: 
158: - Inject a maintainer failure before its first row attempt and one after an
159:   attempted derived write. They must differ only if the maintainer supplies
160:   phase proof; otherwise both serialize derived uncertainty, target/before/
161:   observed-after and causal type.
162: - A later valid projection advance reports actual `P >= target`, preserves its
163:   target, and does not claim a full row audit.
164: - `sync_target` and search sync preserve the same causal/effect evidence as
165:   their direct SDK-normalized counterparts; cancellation identity and cause
166:   chains remain intact.
167: - Declaration preparation with `ProjectionBehind` exposes its preparation
168:   phase and causal coordinates without claiming a custody append.
169: - Unknown append, unwitnessed append, post-commit projection failure and a
170:   no-op respectively retain planned IDs/H, an actual Commit only when supplied,
171:   and only the effects each operation proved. A mint-level `NotWitnessed`
172:   retains its resulting head with `commit=None`.
173: - A two-tier source run keeps the first tier Commit after a second-tier stale,
174:   unknown, collector, or dispatch failure; collected observations and lifecycle

176:   incomplete C8b collection terminal has paired partial `(Fact, id)` evidence
177:   and no invented lifecycle ID.

183:     rebuild: bool = False,
184: ) -> ProjectionSyncResult:
185:     """Advance one projection after normal registry attestation.
186: 
187:     Catch-up is the only supported operation.  Existing inconsistent state is
188:     refused; this coordinator has no path that discards rows or identity
189:     markers.  A projection already at or beyond the target is validated and

214:             )

216:             raise TypeError(
217:                 "first-stage maintenance providers must advertise rebuild=False"
218:             )
219: 
220:         projected_before, before_generation = _snapshot_state(
221:             query, ledger, bound=captured
222:         )
223:         if (
224:             projected_before is not None
225:             and projected_before.lineage == target.lineage
226:             and projected_before.ordinal >= target.ordinal
227:         ):

229:                 None
230:                 if projected_before.ordinal > captured.ordinal
231:                 else before_generation
232:             )
233:             return ProjectionSyncResult(
234:                 captured_head=captured,
235:                 target=target,
236:                 projected_before=projected_before,
237:                 projected_after=projected_before,
238:                 view_generation=generation,
239:                 changed=False,
240:             )
241: 
242:         try:

244:             projected_after = _resolve_head(ledger, advance.after)
245:             if projected_after is None:  # the adapter contract requires one
246:                 raise TypeError("maintenance returned no resulting watermark")

248:                 raise NotAuthority("maintenance returned a foreign projection lineage")

250:                 raise HeadMismatch("maintenance returned a prefix behind its target")

273:                 projected_after = observed_after

277:                 target=target,
278:                 projected_before=projected_before,

290:                 target=target,
291:                 projected_before=projected_before,
292:                 observed_after=observed_after,
293:                 cause=cause,
294:             ) from cause
295:     finally:
296:         if maintenance is not None:
297:             _close_quietly(maintenance)
298:         _close_quietly(query)
299:         _close_quietly(ledger)

145:     *,

147: ) -> SearchIndexSyncResult:
148:     """Build one adapter FTS corpus through an attested exact head.

152:     legacy declaration/store reader on the maintainer's behalf.
153:     """
154:     if descriptor.role not in (Profile.AUTHORITY, Profile.REPLICA):
155:         raise NotAuthority("search maintenance requires an Authority or Replica role")
156:     canonical = SearchFieldSpec.from_fields(
157:         spec.fields_by_kind, normalization_version=spec.normalization_version
158:     )
159:     if canonical != spec:

177:         before = maintenance.coverage()

179:         if build.after.through != target or build.after.fields_hash != spec.fields_hash:
180:             raise HeadMismatch("search maintainer returned coverage other than its target/spec")
181:         return SearchIndexSyncResult(
182:             captured_head=captured,
183:             target=target,
184:             coverage_before=build.before,
185:             coverage_after=build.after,
186:             changed=build.changed,
187:         )
188:     except Exception as cause:
189:         if target is None:
190:             raise
191:         observed_after = None
192:         if maintenance is not None:
193:             with suppress(Exception):
194:                 observed_after = maintenance.coverage()
195:         raise SearchIndexSyncError(
196:             f"search maintenance through ordinal {target.ordinal} failed; "
197:             "inspect coverage evidence",
198:             target=target,
199:             coverage_before=before,
200:             observed_after=observed_after,
201:             fields_hash=spec.fields_hash,
202:             cause=cause,
203:         ) from cause
204:     finally:
205:         _close_quietly(snapshot)
206:         _close_quietly(maintenance)
207:         _close_quietly(query)
208:         _close_quietly(ledger)

238: class NotWitnessed(Exception):
239:     """The mutation COMMITTED, and the journal write for it failed.
240: 
241:     §05's ``committed`` versus ``witnessed`` distinction, and §D.4's rule that
242:     a journal write failure is surfaced rather than swallowed: the append has
243:     already landed, so the store has advanced past its witness and the caller
244:     is told which of the two it got instead of having both collapsed into
245:     "saved".
246: 
247:     **Deliberately NOT an** :class:`~engine.arrival_head_attestation.AttestationRefusal`.
248:     Every member of that family means the operation did not happen. This one
249:     means the opposite — the data is committed and durable — so a caller
250:     catching the refusal root to mean "nothing changed" must not catch this
251:     too. Propagating past those handlers is the never-silent mechanism, and
252:     the type name is the whole message.
253: 
254:     :attr:`head` is where the lineage now stands. :attr:`commit` is the full
255:     transition for the append and replicate paths, and ``None`` for a mint,
256:     which returns a head rather than a commit.
257:     """
258: 
259:     def __init__(
260:         self, message: str, *, head: Head, commit: Commit | None = None
261:     ) -> None:
262:         super().__init__(message)
263:         self.head = head
264:         self.commit = commit
