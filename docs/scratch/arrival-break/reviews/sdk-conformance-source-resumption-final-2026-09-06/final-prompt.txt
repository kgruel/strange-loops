===== libs/sdk/README.md =====
1: # sdk — Loops Apex Composition Library
2: 
3: `sdk` is the headless composition layer uniting `engine`, `custody`, `lang`, `store`, `atoms`, and `sign` into unified, typed operations. It serves as the single foundation for presentation layers (`apps/loops`, TUI, external agents, Python scripts) without leaking presentation logic into the core substrate.
4: 
5: ---
6: 
7: ## Architectural Guarantees
8: 
9: - **Zero Presentation Logic**: Returns pure typed dataclasses; never formats terminal escape codes or parses CLI flags.
10: - **Descriptor-First Arrival Reads**: An explicitly declared backend and instance role select the adapter; store locations remain opaque to the SDK.
11: - **Visible Legacy Boundary**: Bare `.jsonl`/SQLite inputs remain transitional and every read result labels its path as `legacy` with `basis=None`.
12: - **Witness-Axis Honesty**: Fact listing and pagination use append-order cursors (`WitnessPosition`) ensuring deterministic, non-lossy walks.
13: - **Declared Admission & Attestation**: Fact emission enforces declared observer and kind admission policies, signing with operation-fresh custody keys.
14: - **AST-Verified Ceremonies**: Declarative vertex modifications are verified against the language grammar and executed via transactional plan/apply ceremonies.
15: 
16: ---
17: 
18: ## API Reference
19: 
20: ### 1. Target Resolution & Discovery
21: 
22: ```python
23: from sdk import resolve_arrival_target, resolve_target, discover_targets, TargetInfo
24: 
25: # Supported Arrival target: the descriptor carries backend, opaque location,
26: # optional lineage pin, and mandatory instance role.
27: arrival = resolve_arrival_target("path/to/target.vertex")
28: # -> ArrivalTarget(store=StoreDescriptorInfo(backend='file', location='...', role='replica'))
29: 
30: # Single target probe
31: info = resolve_target("path/to/target.vertex")
32: # -> TargetInfo(target_type='vertex', canonical_mode='sqlite', canonical_path=..., index_path=..., exists=True, ...)
33: 
34: # Multi-target workspace discovery
35: targets = discover_targets(".", recursive=True)
36: ```
37: 
38: - **`resolve_target(target: Path | str) -> TargetInfo`**:
39:   Transitional filesystem probe for legacy targets. Raises `TargetNotFound` or `TargetUnsupported`.
40: - **`resolve_arrival_target(target: Path | str) -> ArrivalTarget`**:
41:   Parses an explicit vertex descriptor without probing or normalizing its backend-owned location. It refuses suffix inference and an omitted instance role.
42: - **`discover_targets(root_path=".", *, recursive=True, include_bare=True) -> list[TargetInfo]`**:
43:   Discovers all Loops vertices and bare stores in a directory tree.
44:

47: ### 2. Read Operations
48: 
49: ```python
50: from sdk import (
51:     read_summary,
52:     read_facts,
53:     read_state,
54:     read_ticks,
55:     read_fact_by_id,
56:     search_facts,
57:     resolve_entity,
58:     read_timeline,
59:     sync_target,
60: )
61: 
62: # Target statistical summary & kind inventory
63: summary = read_summary("target.vertex")
64: # -> ReadSummary(read_path='arrival', basis=ReadBasis(...), store=StoreDescriptorInfo(...), ...)
65: 
66: # Bounded, cursor-bearing fact pagination
67: page = read_facts("target.vertex", limit=10, order="newest")
68: # -> FactPageResult(items=[...], next_cursor=..., truncated=True, order='newest')
69: 
70: # Arrival continuations are process-local capabilities. Pass next_cursor back
71: # to read_facts() directly; as_dict() reports has_continuation=True and redacts
72: # the engine value instead of emitting an unprotected wire token.
73: 
74: # Folded vertex state
75: state = read_state("target.vertex", kind="note")
76: # -> FoldStateResult(vertex_name='target', sections={'note': {'count': 10, 'items': [...]}})
77: 
78: # Full-text search across observation payloads
79: search_res = search_facts("target.vertex", query="refactor auth", limit=10)
80: # -> SearchResult(query='refactor auth', matches=[...], total_matches=1)
81: 
82: # Domain entity fold-key resolution
83: fact_id = resolve_entity("target.vertex", kind="task", key="task_id", value="T-100")
84: 
85: # Interleaved chronological timeline (facts + ticks)
86: timeline = read_timeline("target.vertex", limit=50)
87: 
88: # Explicit projection synchronization. Arrival sync first attests custody and
89: # catches a missing or behind projection up through the captured head.
90: sync_res = sync_target("target.vertex")
91: # -> SyncResult(read_path='arrival', captured_head=..., target=...,
92: #               projected_before=..., projected_after=..., changed=True, ...)
93: 
94: # Tick records
95: ticks = read_ticks("target.vertex", name="default")
96: for tick in ticks.items:
97:     print(tick["name"])
98: 
99: # Fact lookup by full ID or prefix
100: lookup = read_fact_by_id("target.vertex", "01M01...")
101: fact = lookup.fact
102: ```
103: 
104: `read_summary`, `read_facts`, `read_state`, `read_ticks`, and
105: `read_fact_by_id` always return typed result models. Descriptor-first results
106: carry the custody head and represented projection prefix in `basis`; legacy
107: results carry `read_path="legacy"` and `basis=None`. Descriptor reads require a
108: current projection and never materialize, repair, or catch it up. Search,
109: entity resolution, and timelines carry the same captured basis. Aggregate
110: state, summary and timeline results retain per-occurrence member bases rather
111: than inventing one shared head. `sync_target` is the
112: explicit maintenance boundary: it may catch up a missing or behind Arrival
113: projection, while inconsistent existing state and rebuild requests refuse.
114: 
115: Arrival read operations, including `resolve_entity`, `read_timeline`, and
116: `inspect_declaration`, accept an optional keyword-only `registry=` for custom
117: `engine.arrival_registry.BackendRegistry` instances. Omission selects the
118: built-in backends. A supplied registry handles every supported root and member
119: Arrival open; unknown backends refuse without fallback, and non-file locations reach
120: the named adapter unchanged. Timeline reuses its captured root when the
121: effective declaration selects aggregation. Entity resolution and declaration
122: inspection retain their current Arrival aggregate restrictions.
123: Legacy targets keep their existing behavior and do not consult the registry.
124: 
125: `export_target("target.vertex", "snapshot.jsonl")` writes an exact captured
126: wire prefix and returns its manifest, selected/captured heads and byte count.
127: It refuses to replace an existing output. A late source failure publishes no
128: partial artifact; a directory-sync failure after publication raises
129: `ExportPublicationError` with `published=True` and the complete artifact's
130: identity. Export requires no current query projection. Import and replication
131: are still pending their explicit initialization/restoration boundary.

135: ### 3. Fact Emission
136: 
137: ```python
138: from sdk import BatchEmitResult, EmitReceipt, emit_batch, emit_fact, preview_emission
139: from atoms import Fact
140: 
141: # Emitting by kind and payload
142: receipt = emit_fact(
143:     "target.vertex",
144:     kind_or_fact="note",
145:     payload={"title": "Meeting Notes", "body": "Discussed SDK API"},
146:     observer="alice",
147: )
148: # Descriptor-first Arrival receipts carry the captured head, durable Commit,
149: # witness state, and post-commit projection status.
150: 
151: # Or preflight dry-run simulation
152: preview = preview_emission("target.vertex", "note", {"title": "Test"}, observer="alice")
153: 
154: # A descriptor-first batch is planned from one snapshot and uses one append.
155: batch = emit_batch(
156:     "target.vertex",
157:     [fact, ("note", {"title": "Batch item"})],
158:     observer="alice",
159: )
160: for receipt in batch.items:
161:     print(receipt.id, receipt.stored)
162: print(batch.commit, batch.atomicity, batch.projection)
163: ```
164: 
165: - **`emit_fact(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, id_override=None, credentials=None, admit_undeclared=False, dry_run=False, registry=None) -> EmitReceipt`**:
166:   Emits a fact (or `Fact` atom) under declared admission rules. Descriptor-first Arrival writes prepare from one CURRENT snapshot, append once against its captured full head, witness the commit, then explicitly synchronize the projection. Bypassing strict kind admission requires `admit_undeclared=True`. Deterministic IDs can be specified with `id_override`. `dry_run=True` simulates emission without storage.
167: - **`preview_emission(target, kind_or_fact, payload=None, *, observer=None, origin="", ts=None, admit_undeclared=False, credentials=None, registry=None) -> EmitPreviewResult`**:
168:   Simulates emission against declared policies, checking fold key requirements without disk side effects. Arrival policy and fold metadata come from the same bounded effective declaration used for planning; a missing projection refuses without materializing it.
169: - **`emit_batch(target, facts, *, observer=None, origin="", credentials=None, admit_undeclared=False, registry=None) -> BatchEmitResult`**:
170:   Normalizes every item before resolving the target. A descriptor-first Arrival batch derives all per-item admission decisions from one current snapshot, appends the packed records under one head comparison, witnesses one shared commit, and explicitly synchronizes the projection. Each mapping item may set its own boolean `admit_undeclared`; duplicate receipts retain `stored=False`. Empty input is an explicit zero-write result. Legacy targets return the same wrapper with `atomic=False`, `atomicity="legacy-sequential"`, and no invented shared commit; `LegacyBatchPartialFailure` retains receipts if that sequential loop stops after an observable prefix.
171: 
172: `CustodyCredentialProvider()` and `CustodyCredentialProvider(key_dir=None)` use
173: the existing custody resolver. A non-`None` `key_dir` now raises
174: `SdkValueError` during construction because directory overrides were previously
175: accepted but ignored. This applies before either Arrival or legacy operations
176: can use the provider. Callers that need another credential source can continue
177: to supply a custom `CredentialProvider`; that interface does not itself create
178: an observer mapping or register public keys.
179: 
180: For an explicit persisted namespace, use `MappedCredentialProvider` with an
181: Arrival target. Prepare the binding separately from initializing the store:
182: 
183: ```python
184: from pathlib import Path
185: from sdk import MappedCredentialProvider, init_vertex, emit_fact
186: 
187: credentials = MappedCredentialProvider(
188:     Path("/absolute/path/to/private-custody"),
189:     namespace="personal",
190:     receipt_observer="alice",  # explicit local receipt-signing selection
191: )
192: binding = credentials.create_binding("alice", token="bootstrap-alice-1")
193: init_vertex(
194:     Path("observations.vertex"), store_type="arrival", observer="alice",
195:     credentials=credentials,
196: )
197: emit_fact(
198:     Path("observations.vertex"), "item", {"value": 1},
199:     observer="alice", credentials=credentials,
200: )
201: ```
202: 
203: Mapped selection uses the exact namespace and observer, independently of the
204: vertex filename or lineage. The engine checks author keys against verified
205: history through captured H, for use after H, and verifies each signature in its
206: own domain. Receipt signing uses the explicitly selected local observer and
207: the effective declaration's current receipt-key policy; the unsigned outer tick
208: still names the physical genesis custodian. Omitting `receipt_observer` permits
209: unsigned ticks before the signed-tick era, and refuses a required signed tick.
210: A missing author binding may remain unsigned where the existing policy allows;
211: a contradictory or unauthorized binding refuses before append.
212: 
213: Mapped initialization only loads a pre-created binding. For another observer,
214: prepare its binding and pass `key=binding.public_key` to `grant_observer` with
215: the existing author's credentials. Mapped `grant_observer(key=None)` refuses
216: before creating keys. Recovery of an existing Arrival initialization intent
217: signs nothing and does not require private custody to remain available.
218: Mapped providers are supported on Arrival targets; legacy writers explicitly
219: refuse them. The default `CustodyCredentialProvider` remains unchanged.
220: 
221: The runnable [two-observer mapped workload](tests/test_arrival_mapped_workload.py)
222: shows the complete public lifecycle: create Alice and Bob bindings under one
223: persisted provider root and exact namespace; initialize with Alice; grant Bob
224: using Bob's pre-created public key; then emit with both authors. For a locator
225: move that keeps the same physical file-backed store, initialize with an
226: **absolute** `location` and move only the `.vertex` file while retaining its
227: store clause, lineage, and role. Recreate `MappedCredentialProvider` with the
228: same provider root, namespace, and receipt observer before continuing work.
229: The absolute store location keeps the same store residence, while
230: mapped key selection comes only from the provider namespace and exact observer
231: label; neither the vertex filename nor its new directory chooses a key.
232: 
233: After relocation, `verify_target(relocated_vertex)` provides a `Full`
234: verification of the captured prefix's grammar, dense ordinals, lineage, and
235: record-hash chain. It does not establish projection agreement, signature
236: authorship, key trust, or the identity of an observer across lineages. The
237: mapped workload exercises public writes with captured authorization; the
238: [mapped signing tests](tests/test_arrival_mapped_credentials.py) separately
239: verify domain-specific signatures and key-history behavior.
240: 
241: `import_legacy(vertex_path, observer, token=...)` explicitly copies a verified
242: legacy key into managed storage without changing the original. It preserves
243: flat/nested ambiguity and alias refusals. After import, locator moves do not
244: change mapped selection. No read, preview, or signer load imports or creates a
245: binding. `bind_existing_ref(observer, key_ref, expected_public_key, token=...)`
246: permits deliberate reuse of a completed managed key in another namespace;
247: equal observer labels alone never select another namespace's key.
248: See [custody binding recovery](../custody/README.md#explicit-mapped-bindings)
249: for interruption handling and filesystem scope.

251: ### Recovering an interrupted mapped declaration edit
252: 
253: An edit can raise `CommittedIncomplete` after its declaration records are
254: durable but before projection synchronization or local cache publication
255: finishes. Its public `details["intent_path"]` identifies the retained recovery
256: intent. Use it before deciding whether to retry the proposal:
257: 
258: ```python
259: from sdk import CommittedIncomplete, edit_declaration, recover_declaration
260: 
261: try:
262:     edit_declaration(vertex, proposal, observer="alice", credentials=credentials)
263: except CommittedIncomplete as outcome:
264:     recovered = recover_declaration(outcome.details["intent_path"])
265: ```
266: 
267: Recovery reconciles the exact retained suffix, synchronizes the projection,
268: and publishes the retained declaration bytes without re-signing or appending
269: the proposal again. A recovery result has no original `Commit`; its basis is
270: the original captured edit basis. Follow it with `inspect_declaration(vertex)`
271: to obtain a fresh effective-declaration/read basis, and use
272: `verify_target(vertex)` when the bounded `Full` hash-chain claim is needed.
273: The [mapped declaration recovery workload](tests/test_arrival_declaration_recovery_workload.py)
274: uses a deterministic injected `after-append` interruption beneath the public
275: SDK edit call; it is not a process-kill or crash-survival test.
276: 
277: Supported Arrival execution reserves the vertex name from its loop names.
278: Every exact name collision refuses, including passive loops, reset/carry loops,
279: and count- or event-triggered boundaries. The runtime also adds an implicit
280: `cite` loop, so a vertex named `cite` cannot execute under this restriction.
281: Runtime capture checks the historized effective declaration and expanded
282: template loop names before hydration and planning; editing only the local cache
283: cannot bypass it. New and proposed declarations check their declared loops and
284: the implicit `cite` loop. The SDK initializer also refuses the name `item`,
285: because its scaffold declares an `item` loop, before creating custody keys.
286: External template sources are expanded and checked at runtime; declaration
287: editing does not load them solely to enforce this rule.
288: 
289: This is an Arrival execution compatibility restriction. Existing histories
290: remain available through evidence reads, declaration inspection and export.
291: A collision-free declaration can be appended to correct an ambiguous current
292: declaration; prior facts and ticks retain their original names and bytes.
293: This does not establish which role an already-recorded ambiguous tick had;
294: historical boundary continuity remains a separate limitation.
295: Legacy runtime behavior and the wire format retain their existing rules.

299: ### 4. Arrival Source Execution
300: 
301: ```python
302: from sdk import run_sources
303: 
304: result = await run_sources("target.vertex", observer="alice", force=False)
305: for tier in result.tiers:
306:     print(tier.outcome, tier.commit, tier.fact_ids, tier.tick_ids)
307: ```
308: 
309: - **`await run_sources(target, *, observer, force=False, credentials=None, registry=None, collector_factory=None, dispatcher=None, evaluated_at=None) -> SourceRunResult`**:
310:   Captures a CURRENT Arrival Authority before collection, fixes cadence and dependency tiers, and commits each collected tier with one exact-head batch append plus explicit projection synchronization. The lifecycle observer is always explicit. Existing custody keys are loaded when present; the operation never creates keys.
311: 
312:   When the invocation finishes without a terminal failure, a source error returns `status="error"` with its yielded observations and error lifecycle fact durable. Interrupted results retain prior commits and distinguish `known_uncommitted` collection from an append whose durability is `unknown`; collectors are not rerun within the invocation. When `dispatcher` is omitted, captured tick run intents remain visible with `dispatch_status="not-requested"` and `attempted=False`. This operation supports explicit single-store Arrival Authority descriptors only and never falls through to legacy source execution.
313: 
314:   Coordinator failures during ID allocation, lifecycle construction, or otherwise successful collector cleanup return an incomplete result with terminal category `collection-failed`. `terminal.details.collection` contains the current tier's basis, `custody="not-attempted"`, completed siblings, and paired partial observations from failed or cancelled siblings. Incomplete attempts have no lifecycle fact; prior tiers keep their commits. These partial observations live in terminal evidence, not `known_uncommitted`, which describes a fully collected tier. Owned iterators and distinct iterable owners receive `aclose()` when available; caller cancellation propagates after sibling cleanup. Closing a collector does not undo its external effects or guarantee subprocess termination.
315: 
316:   Calling `run_sources` again is a fresh, cadence-based invocation with fresh
317:   generated IDs; it is not a resume token for retained collector output. For
318:   example, an upstream source can remain skipped by its persisted successful
319:   cadence while a downstream source retries from its persisted trigger. A
320:   downstream failure before yielding leaves no domain observation from that
321:   collector attempt to repeat; it says nothing about its external effects. If
322:   it yielded before reporting a `SourceError` and that tier has an actual
323:   commit, the observation and error lifecycle are durable. A later fresh
324:   invocation can collect the same logical observation again under a distinct
325:   fact ID. Callers need a source-specific idempotency or reconciliation policy
326:   for external effects and overlapping collected observations. The public
327:   two-tier case is exercised in
328:   [`tests/test_arrival_source_resumption_workload.py`](tests/test_arrival_source_resumption_workload.py).

408: ## Exception Taxonomy
409: 
410: ```mermaid
411: graph TD
412:     SdkError --> TargetError
413:     TargetError --> TargetNotFound
414:     TargetError --> TargetUnsupported
415:     TargetError --> TargetNotWritable
416:     SdkError --> AdmissionFailed
417:     SdkError --> EmissionFailed
418:     SdkError --> SdkValueError
419:     SdkValueError --> InvalidEmissionRequest
420:     EmissionFailed --> InvalidEmissionRequest
421:     EmissionFailed --> CommittedEmissionError
422:     SdkError --> CeremonyFailed
423: ```
424: 
425: - **`SdkError`**: Base class for all high-level SDK exceptions.
426: - **`SdkValueError`**: Base class for SDK parameter and validation errors (inherits from `ValueError`).
427: - **`TargetNotFound`**: Target path does not exist on disk.
428: - **`TargetUnsupported`**: Path exists but is not a recognized Loops artifact.
429: - **`TargetNotWritable`**: Target or derived index cannot be written to.
430: - **`AdmissionFailed`**: Declared admission policy (strict kinds or observer grants) refused the operation.
431: - **`EmissionFailed`**: Fact emission failed prior to committing.
432: - **`InvalidEmissionRequest`**: Invalid emission parameters (missing required observer or invalid shape).
433: - **`CommittedEmissionError`**: Fact was written to storage, but a post-commit task failed (carries `.fact_id`).
434: - **`CeremonyFailed`**: Declaration update AST generation or ceremony apply was refused.
435: 
436: Descriptor-first reads also surface engine contract refusals (for example, a
437: missing or behind projection or an invalid continuation) and declaration
438: resolution errors. These keep the adapter's evidence-bearing refusal intact.
439: 
440: Arrival `sync_target` and `sync_search_index` normalize maintenance failures as
441: `ProjectionOutcomeUnknown`. Their optional `details.evidence` object uses
442: `loops.sdk/evidence/v1`: it records the coordinator phase, resource effects,
443: available head/coverage coordinates, and up to two explicit causal exceptions.
444: Search failures before the build call report derived state as
445: `not-entered`/`not-attempted`; failures after entering build or projection
446: catch-up report `entered`/`unknown`. A nested refusal does not prove that an
447: adapter left derived state unchanged. Existing error outcomes, source types,
448: and operation-specific `details.phase` remain intact. Cause messages are capped
449: at 512 characters; record bodies and implicit exception context are excluded.
450: Declaration preparation refusals carry preparation evidence without claiming a
451: custody append. Cancellation and process-control exceptions propagate unchanged.

360: def _cadence_evidence(
361:     source_index: int,
362:     source: Any,
363:     cadence: Any,
364:     facts: Sequence[Any],
365:     *,
366:     evaluated_at: float,
367:     force: bool,
368: ) -> CadenceEvidence:
369:     last = _latest_success(facts, source.kind)
370:     mode = cadence.mode
371:     trigger_ids: tuple[str, ...] = ()

387:     if force:
388:         qualified = True

390:         source_index=source_index,
391:         kind=source.kind,
392:         mode=mode,
393:         evaluated_at=evaluated_at,
394:         latest_success_id=None if last is None else last.id,
395:         latest_success_ts=None if last is None else last.ts,

411: def _preflight_known_admission(
412:     capture: RuntimeCapture,
413:     sources: Sequence[tuple[Any, Any]],

540: async def _close_owned_streams(
541:     stream: object | None,
542:     iterator: object | None,
543:     *,
544:     primary: BaseException | None,
545: ) -> Exception | None:
546:     """Attempt async close on the iterator and owner before propagating interruption.
547: 
548:     This releases Python iterator resources only. It does not claim that an
549:     underlying collector reversed or terminated any external effect.
550:     """
551:     failures: list[Exception] = []
552:     handles: list[object] = []
553:     deferred_interrupt: BaseException | None = None
554:     primary_is_interrupt = primary is not None and not isinstance(primary, Exception)
555:     for handle in (iterator, stream):
556:         if handle is None or any(handle is existing for existing in handles):
557:             continue
558:         handles.append(handle)
559:         try:
560:             close = getattr(handle, "aclose", None)
561:             if not callable(close):
562:                 continue
563:             await close()
564:         except Exception as exc:
565:             failures.append(exc)
566:         except BaseException as exc:
567:             if not primary_is_interrupt and deferred_interrupt is None:
568:                 deferred_interrupt = exc
569:     if deferred_interrupt is not None:
570:         raise deferred_interrupt
571:     return failures[0] if failures else None

574: async def _collect_one(
575:     invocation: SourceInvocationPlan,
576:     state: _CollectionState,
577:     source: Any,
578:     collector_factory: CollectorFactory | None,
579:     *,
580:     clock: Callable[[], float],
581:     id_factory: Callable[[], str],
582: ) -> CollectedSource:
583:     status: Literal["ok", "error", "invalid"] = "ok"
584:     stderr = ""
585:     returncode: int | None = None
586:     error_type: str | None = None
587:     error_message: str | None = None
588:     invalid: InvalidSourceOutput | None = None
589:     stream: object | None = None
590:     iterator: object | None = None
591:     primary: BaseException | None = None
592:     try:
593:         stream = source.collect() if collector_factory is None else collector_factory(source)
594:         iterator = aiter(stream)
595:         async for value in iterator:
596:             if not isinstance(value, Fact):
597:                 invalid = InvalidSourceOutput(state.source_index, value)
598:                 primary = invalid
599:                 status = "invalid"
600:                 break
601:             try:
602:                 fact_id = id_factory()
603:                 state.pairs.append((value, fact_id))
604:             except Exception as exc:
605:                 failure = _CollectionStepFailed(state, "bookkeeping", exc)
606:                 primary = failure
607:                 raise failure from exc
608:     except _CollectionStepFailed:
609:         raise
610:     except asyncio.CancelledError as exc:
611:         primary = exc
612:         raise
613:     except SourceError as exc:
614:         primary = exc
615:         status = "error"
616:         stderr = exc.stderr
617:         returncode = exc.returncode
618:         error_type = type(exc).__name__
619:         error_message = str(exc)
620:     except Exception as exc:
621:         primary = exc
622:         status = "error"
623:         error_type = type(exc).__name__
624:         error_message = str(exc)
625:     except BaseException as exc:
626:         primary = exc
627:         raise
628:     finally:
629:         cleanup_error = await _close_owned_streams(
630:             stream, iterator, primary=primary
631:         )
632:         if cleanup_error is not None and primary is None:
633:             raise _CollectionStepFailed(state, "cleanup", cleanup_error) from cleanup_error
634: 
635:     try:
636:         payload: dict[str, Any] = {
637:             "command": state.command,
638:             "status": "error" if status != "ok" else "ok",
639:             "count": len(state.pairs),
640:             "invocation_id": invocation.invocation_id,
641:             "source_index": state.source_index,
642:         }
643:         if stderr:
644:             payload["stderr"] = stderr
645:         if returncode is not None:
646:             payload["returncode"] = returncode
647:         if error_type is not None:
648:             payload["error_type"] = error_type
649:         if error_message is not None:
650:             payload["error"] = error_message
651:         if invalid is not None:
652:             payload["error_type"] = type(invalid).__name__
653:             payload["error"] = str(invalid)
654:         lifecycle = Fact(
655:             f"_sync.{state.kind}",
656:             clock(),
657:             payload,
658:             observer=invocation.observer,
659:         )
660:         return CollectedSource(
661:             source_index=state.source_index,
662:             kind=state.kind,
663:             command=state.command,
664:             source_observer=state.source_observer,
665:             facts=tuple(fact for fact, _fact_id in state.pairs),
666:             fact_ids=tuple(fact_id for _fact, fact_id in state.pairs),
667:             lifecycle_fact=lifecycle,
668:             lifecycle_id=invocation.lifecycle_ids[state.source_index],
669:             status=status,
670:             stderr=stderr,
671:             returncode=returncode,
672:             error_type=error_type,
673:             error_message=error_message,
674:             invalid_output=invalid,
675:         )
676:     except Exception as exc:
677:         raise _CollectionStepFailed(state, "bookkeeping", exc) from exc

680: async def collect_source_tier(
681:     invocation: SourceInvocationPlan,
682:     capture: RuntimeCapture,
683:     tier_index: int,
684:     collector_factory: CollectorFactory | None = None,
685:     *,
686:     clock: Callable[[], float] = time.time,
687:     id_factory: Callable[[], str] = _new_id,
688: ) -> CollectedTier:
689:     """Collect one fixed tier concurrently while retaining source-list order."""
690:     indices = invocation.tiers[tier_index]
691:     sources = invocation.initial_capture.sources
692:     states = [
693:         _CollectionState(
694:             source_index=index,
695:             kind=sources[index][0].kind,
696:             command=sources[index][0].command,
697:             source_observer=sources[index][0].observer,
698:             pairs=[],
699:         )
700:         for index in indices
701:     ]
702:     tasks = [
703:         asyncio.create_task(
704:             _collect_one(
705:                 invocation,
706:                 state,
707:                 sources[state.source_index][0],
708:                 collector_factory,
709:                 clock=clock,
710:                 id_factory=id_factory,
711:             )
712:         )
713:         for state in states
714:     ]
715:     try:
716:         collected = tuple(await asyncio.gather(*tasks))
717:     except _CollectionStepFailed as primary:
718:         for task in tasks:
719:             if not task.done():
720:                 task.cancel()
721:         settled = await asyncio.gather(*tasks, return_exceptions=True)
722:         for result in settled:
723:             if isinstance(result, BaseException) and not isinstance(
724:                 result, (_CollectionStepFailed, asyncio.CancelledError)
725:             ):
726:                 # This sibling already owns its chaining evidence. Adding or
727:                 # clearing a cause here would rewrite the control exception.
728:                 raise result  # noqa: B904
729:         completed = tuple(
730:             result for result in settled if isinstance(result, CollectedSource)
731:         )
732:         failed = tuple(
733:             result.state.partial(result.phase, result.cause)
734:             for result in settled
735:             if isinstance(result, _CollectionStepFailed)
736:         )
737:         cancelled = tuple(
738:             state.partial("cancelled")
739:             for state, result in zip(states, settled, strict=True)
740:             if isinstance(result, asyncio.CancelledError)
741:         )
742:         raise SourceTierCollectionFailed(
743:             tier_index=tier_index,
744:             basis=capture.basis,
745:             completed_sources=completed,
746:             failed_sources=failed,
747:             cancelled_sources=cancelled,
748:             cause=primary.cause,
749:         ) from primary.cause
750:     except BaseException:
751:         for task in tasks:
752:             if not task.done():
753:                 task.cancel()
754:         await asyncio.gather(*tasks, return_exceptions=True)
755:         raise
756:     return CollectedTier(
757:         tier_index=tier_index,
758:         basis=capture.basis,
759:         sources=collected,
760:         include_pending_boundaries=tier_index == 0,
761:     )

789:     capture: RuntimeCapture,
790:     collected: CollectedTier,
791:     *,

815:                 BatchFactInput(fact, fact_id=fact_id)
