9: 
10: `normalize_exception` already preserves important public categories:
11: `WriteCommitUnknown`/batch equivalents become an unknown custody outcome,
12: `NotWitnessed` retains its resulting head and an actual `Commit` where the
13: underlying operation supplies one; post-commit projection failures retain their
14: commit. Initialization, declaration recovery, and restore have
15: operation-specific unknown/incomplete wrappers. Source invocation instead
16: returns structured per-tier results, preserving an earlier durable tier while a
17: later tier is uncommitted or unknown.
18: 
19: There are two material gaps. `sync_target` calls `sync_projection` directly and
20: therefore bypasses the existing `ProjectionSyncError ->
21: ProjectionOutcomeUnknown` mapping (`sdk/read.py:sync_target`). Also,

31: `sync_projection` enters its catch-up attempt, it wraps an ordinary
32: `Exception` as

50: operation exposes only fields it can prove, under its existing names where

54: field copied by `_identity_details` from current exceptions.

57: | --- | --- |
58: | `phase` | The operation-local `coordinator_phase` proved reached, such as `capture`, `prepare`, `custody-append`, `derived-sync`, `cache-publication`, or `dispatch`. It is not a global ordering across resources. |
59: | `effects` | Per-resource entries for `custody`, `witness`, `derived`, `cache`/`artifact`, or `dispatch`, each with `attempt` and `state`; see concrete values below. |
60: | `basis` | Captured `H`/`P`/generation where one exists, target/actual projection heads for maintenance, and declaration anchor where interpretation mattered. |
61: | `identities` | Planned fact/tick IDs, item or tier index, observer/kind, and a real `Commit` before/after when known. No invented Commit for a no-op or recovery. |
62: | `cause` | A bounded recursive diagnostic: causal type name, message, and the same safe identity coordinates available on that cause. Its exact source and bound are specified below. |

65: `details["evidence"]`, retaining `loops.sdk/error/v1` and all current top-level
66: error fields:
67:

70:  "effects":{"derived":{"attempt":"entered", "state":"unknown"}},
71:  "basis":{"target":{}}, "identities":{},
72:  "cause":{"type":"OSError", "message":"…", "details":{}}}
73: ```

76: when a legacy wrapper has no control-flow proof either way. `state` is exactly
77: `not-attempted`, `known-none`, `committed`, `unknown`, `completed`, or
78: `incomplete`. `not-attempted` means this coordinator did not cross that
79: resource's mutation boundary. `known-none` is a distinct proof: an entered
80: adapter call had an explicit atomic-rejection guarantee of no effect. Neither
81: follows merely from a nested exception type. Invariant:
82: `attempt=not-entered` requires `state=not-attempted`; other states may omit
83: `attempt` when boundary-entry evidence is unavailable. `phase` is proof, not a

93: characters with `truncated=true` when shortened. Never follow `__context__`,
94: call `repr`, or serialize payload/record bodies.

99:   `custody=not-attempted` only when its planner has not opened its append

188: ) -> ProjectionSyncResult:

192:     refused; this coordinator has no path that discards rows or identity
193:     markers.  A projection already at or beyond the target is validated and

195:     """

197:         raise NotAuthority(

199:         )

205:             raise TypeError("BackendRegistry.open must return an AttestedLedger")

207:         target = _verify_target(
208:             ledger, captured, captured if through is None else through

218:             )

220:             raise TypeError(

222:             )
223: 
224:         projected_before, before_generation = _snapshot_state(
225:             query, ledger, bound=captured
226:         )
227:         if (
228:             projected_before is not None
229:             and projected_before.lineage == target.lineage
230:             and projected_before.ordinal >= target.ordinal
231:         ):
232:             generation = (
233:                 None
234:                 if projected_before.ordinal > captured.ordinal
235:                 else before_generation
236:             )
237:             return ProjectionSyncResult(
238:                 captured_head=captured,
239:                 target=target,
240:                 projected_before=projected_before,
241:                 projected_after=projected_before,
242:                 view_generation=generation,
243:                 changed=False,
244:             )
245: 
246:         try:
247:             advance = maintenance.catch_up(target)
248:             projected_after = _resolve_head(ledger, advance.after)
249:             if projected_after is None:  # the adapter contract requires one
250:                 raise TypeError("maintenance returned no resulting watermark")
251:             if projected_after.lineage != target.lineage:
252:                 raise NotAuthority("maintenance returned a foreign projection lineage")
253:             if projected_after.ordinal < target.ordinal:
254:                 raise HeadMismatch("maintenance returned a prefix behind its target")
255:             if projected_after.ordinal == target.ordinal and projected_after != target:
256:                 raise HeadMismatch(
257:                     "maintenance returned a same-height head different from its target"
258:                 )
259:             projected_before = _resolve_head(ledger, advance.before)
260:             observed_after, generation = _snapshot_state(
261:                 query, ledger, bound=projected_after
262:             )
263:             if (
264:                 observed_after is None
265:                 or observed_after.lineage != projected_after.lineage
266:                 or observed_after.ordinal < projected_after.ordinal
267:             ):
268:                 raise HeadMismatch(
269:                     "query projection does not reach the prefix maintenance returned"
270:                 )
271:             if observed_after != projected_after:
272:                 # Another serialized maintainer advanced after this handle
273:                 # committed. The first snapshot's generation is bounded at
274:                 # our returned prefix, so it cannot identify the newer view.
275:                 # Report the attested actual prefix and leave generation
276:                 # unknown rather than mislabel it or report success as loss.
277:                 projected_after = observed_after
278:                 generation = None
279:             return ProjectionSyncResult(
280:                 captured_head=captured,
281:                 target=target,
282:                 projected_before=projected_before,
283:                 projected_after=projected_after,
284:                 view_generation=generation,
285:                 changed=advance.changed,
286:             )
287:         except Exception as cause:
288:             observed_after = None
289:             with suppress(Exception):
290:                 observed_after, _ = _snapshot_state(query, ledger, bound=captured)
291:             raise ProjectionSyncError(
292:                 f"projection maintenance through ordinal {target.ordinal} failed; "
293:                 "inspect observed_after before retrying",
294:                 target=target,
295:                 projected_before=projected_before,
296:                 observed_after=observed_after,
297:                 cause=cause,
298:                 coordinator_phase="derived-sync",
299:                 effects={
300:                     "derived": {"attempt": "entered", "state": "unknown"}
301:                 },
302:             ) from cause
303:     finally:
304:         if maintenance is not None:
305:             _close_quietly(maintenance)
306:         _close_quietly(query)
307:         _close_quietly(ledger)

### libs/engine/src/engine/arrival_head_seam.py

238: class NotWitnessed(Exception):
239:     """The mutation COMMITTED, and the journal write for it failed.
240: 
241:     §05's ``committed`` versus ``witnessed`` distinction, and §D.4's rule that
242:     a journal write failure is surfaced rather than swallowed: the append has
243:     already landed, so the store has advanced past its witness and the caller
244:     is told which of the two it got instead of having both collapsed into
245:     "saved".
246: 
247:     **Deliberately NOT an** :class:`~engine.arrival_head_attestation.AttestationRefusal`.
248:     Every member of that family means the operation did not happen. This one
249:     means the opposite — the data is committed and durable — so a caller
250:     catching the refusal root to mean "nothing changed" must not catch this
251:     too. Propagating past those handlers is the never-silent mechanism, and
252:     the type name is the whole message.
253: 
254:     :attr:`head` is where the lineage now stands. :attr:`commit` is the full
255:     transition for the append and replicate paths, and ``None`` for a mint,
256:     which returns a head rather than a commit.
257:     """
258: 
259:     def __init__(
260:         self, message: str, *, head: Head, commit: Commit | None = None
261:     ) -> None:
262:         super().__init__(message)
263:         self.head = head
264:         self.commit = commit
