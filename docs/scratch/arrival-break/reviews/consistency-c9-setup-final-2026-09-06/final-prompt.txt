===== apps/loops-min/README.md =====
1: # loops-min
2: 
3: `loops-min` is the transitional JSON process client for the headless `sdk`
4: package. It provides descriptor/read operations, verification, projection and
5: search maintenance, exact export, explicit restore-forward, and a mapped-only
6: Arrival writer surface. Empty-receiver import, admission, a generic replicate
7: command, and legacy writer retirement remain later work.
8: 
9: Writer commands require all of `--credential-root`, `--credential-namespace`,
10: and `--receipt-observer`. They never select locator-derived credentials or fall
11: back to a legacy writer or create keys implicitly. The founding binding must be
12: pre-provisioned for `init`; pre-provision every author and receipt binding used
13: by a signed workflow. Selecting the mapped provider does not make every domain
14: mandatory: an absent optional signer retains the SDK's unsigned behavior under
15: the captured declaration and signed-era rules. Callers should inspect each
16: result's `signed` and `witnessed` evidence.
17: 
18: Credential mutations are explicit SDK-backed commands. Their tokens name one
19: durable operation and should be retained with the JSON result or error:
20: 
21: ```text
22: loops-min credential-create /keys --namespace tenant --observer alice \
23:   --token setup-alice
24: loops-min credential-recover /keys --namespace tenant --observer alice \
25:   --token setup-alice
26: loops-min credential-bind-existing-ref /keys --namespace tenant \
27:   --observer bob --token bind-bob --key-ref KEY_REF \
28:   --expected-public-key PUBLIC_KEY
29: loops-min credential-import-legacy /keys --namespace tenant --observer carol \
30:   --token import-carol --vertex old.vertex
31: ```
32: 
33: `credential-recover` uses the exact namespace, observer, and token of a retained
34: binding intent. An incomplete result is a reconciliation boundary, not an
35: automatic retry instruction. Existing-reference binding and legacy import are
36: explicit selections; the client does not search for keys or serialize custody
37: implementation objects.
38: 
39: `init` always requests an Arrival file target and never uses `init_vertex`'s
40: legacy default. A minimal lifecycle is:
41: 
42: ```text
43: loops-min init app.vertex --name app --location /data/app.arrival \
44:   --observer alice --credential-root /keys --credential-namespace tenant \
45:   --receipt-observer alice --strict
46: loops-min emit app.vertex item --payload-json '{"value":1}' --observer alice \
47:   --credential-root /keys --credential-namespace tenant --receipt-observer alice
48: loops-min emit-batch app.vertex --facts-json '[{"kind":"item","payload":{"value":2},"observer":"alice","id":"item-2"}]' \
49:   --credential-root /keys --credential-namespace tenant --receipt-observer alice
50: ```
51: 
52: `emit` requires a JSON object payload. `emit-batch` requires an array of JSON
53: objects and passes their observer, ID, timestamp, origin, and admission fields
54: to the SDK, retaining its existing defaults and coercion rules. Transport JSON rejects duplicate keys and non-finite
55: numbers before credential resolution. The client does not retry unknown
56: outcomes; stable IDs and the SDK's returned evidence are the reconciliation
57: boundary.
58: 
59: `declaration target.vertex --proposed-file next.vertex --observer alice ...`
60: passes the file's text to the SDK's captured declaration-edit protocol. If an
61: edit reports an intent after a durable interruption,
62: `declaration-recover INTENT` resumes it without resolving credentials again.
63: Likewise, `init-recover TARGET` uses only the target's reserved initialization
64: intent. It does not accept credentials, observer, backend, location, name, or
65: strictness overrides. It does not choose a new lineage or re-sign the reserved
66: bootstrap records.
67: 
68: `loops-min export target.vertex captured.jsonl` publishes a complete captured
69: wire prefix at a new pathname and returns the SDK manifest in its JSON result.
70: It never replaces an existing output. Export publication failures report
71: whether the complete artifact became visible before directory durability failed.
72: 
73: `loops-min restore-forward source.vertex receiver.vertex` restores an existing
74: exact copy through the witnessed source head. It preserves the receiver's
75: role and reports its before/after heads and commit receipt. Ordinary opens
76: continue to refuse older copies. Unknown or incomplete outcomes retain the
77: identity evidence needed to reconcile custody before repeating the operation.
78: 
79: Each successful invocation prints one `{"ok": true, "result": ...}` JSON
80: object. Failures print one JSON error object on stdout and a concise diagnostic
81: on stderr. Result objects are serialized with the SDK model's `as_dict()`;
82: continuation capabilities remain process-local and are reported without a
83: fake cursor token.
84: 
85: Exit status 2 covers argument, transport JSON, local input-file, and SDK
86: invalid-input/configuration errors (including missing founding credentials); 3
87: means a recognized unsupported operation or target; 4 is a target, custody,
88: projection, publication, or contract refusal/outcome; 5 is admission or
89: ceremony refusal; and 6 means ledger custody committed or may have committed,
90: or a credential-binding mutation is incomplete. Status
91: 4 does not by itself prove zero derived or publication effects. Status 6 is
92: not permission to retry: the JSON error retains commit, IDs, intent, and
93: outcome evidence supplied by the SDK. A credential-binding incomplete result
94: has a binding token and phase rather than a ledger Commit or fact IDs; an
95: unknown phase does not prove that a durable binding intent exists.
96: 
97: The executable is deliberately named `loops-min` while the legacy `loops`
98: application remains in the workspace. It has no presentation, storage, or
99: legacy CLI dependency.
100: 
101: The global `--pretty` option may appear before or after a command. Argument
102: errors also use the JSON envelope and exit with status 2. A built-wheel smoke
103: can be run from a clean environment by building `loops-min`, installing it
104: alongside the local SDK dependency wheels, and invoking `loops-min --help` and
105: one temporary Arrival `summary`; the package does not require a repository
106: checkout at runtime.

7: ## Boundary decisions
8: 
9: Initialization recovery is a separate `init-recover TARGET` command. It calls
10: `sdk.init_vertex(target, store_type="arrival", recover=True)` without credentials,
11: backend selection, observer selection, or scaffold parameters. The SDK and engine
12: load the reserved descriptor, observer, declaration, and signatures from the
13: retained initialization intent. Recovery finishes that operation; it does not
14: choose a new lineage or sign a new initialization. Successful recovery removes
15: the intent. A subsequent recovery invocation refuses the missing intent without
16: starting another initialization.
17: 
18: Mapped binding mutation remains a separate local custody operation. SDK-owned
19: results serialize public binding coordinates and mutation outcomes. They carry
20: no Arrival Commit and no private key material. The exact namespace and observer
21: select a local slot; the explicit token identifies the durable operation. Receipt
22: observer selection belongs to subsequent writes and is not a binding mutation
23: argument. Existing read resolution remains read-only and can return no binding.
24: 
25: The process client exposes create, recover, bind-existing-ref, and import-legacy
26: through the corresponding public SDK provider methods. The SDK owns validation,
27: serialization and failure classification. The client performs one invocation and
28: preserves its result or error. It never scans private custody files, manufactures
29: an outcome, or performs an automatic retry. Import copies an explicitly selected
30: legacy key; it does not migrate a store or publish an Arrival descriptor.
31: 
32: ## SDK outcome contract
33: 
34: `MappedCredentialProvider` keeps its four public method signatures and existing
35: result attributes. Those methods now return `CredentialBindingResult`, with
36: schema `loops.sdk/credential-binding/v1`, operation, namespace, observer, token,
37: key_ref, public_key, provenance, binding_created, and key_created. This changes
38: the concrete result type from the custody dataclass; callers inspecting that
39: concrete type must adopt the SDK result. Reusing an existing reference publishes
40: a binding, without implying new key creation or a vertex authorization grant.
41: 
42: SDK lifecycle errors are dedicated `CredentialBindingError` subclasses. They
43: replace exposed custody exceptions for these SDK methods; direct custody callers
44: are unchanged. `CredentialBindingConflict` and `CredentialBindingRecoveryRequired`
45: retain the attempted request coordinates and map to CLI status 4.
46: `CredentialBindingIncomplete` maps to status 6, retaining custody-supplied
47: key_ref/phase when available. Raw custody OSError/ValueError cannot establish
48: that no mutation happened: they use the same incomplete family with phase
49: `unknown`, the source exception type, and the request coordinates. That fallback
50: does not claim an intent exists or supply a guessed key reference. Some failures,
51: such as an absent import source, consequently receive a conservative incomplete
52: outcome even though their current implementation fails before binding publication.
53: Simple invalid SDK argument shapes are rejected before the custody call.
54: 
55: The error's `recovery_action="reconcile"` is not an automatic retry command.
56: Recovery may require the exact retained token; an interrupted legacy import
57: without a published candidate may require repeating that explicit import with
58: the same token and source. A conflicting operation's attempted token is not the
59: token owning another pending intent. Exit status 4 also makes no blanket
60: zero-effects claim. No binding outcome fabricates an Arrival Commit.
61:

312:     @contextmanager

314:         self._root_dir(create=True)

327:     def _read_json(self, path: Path) -> dict[str, object] | None:
328:         if not _regular(path, required=False):
329:             return None
330:         try:
331:             def reject_duplicates(pairs: list[tuple[str, object]]) -> dict[str, object]:
332:                 result: dict[str, object] = {}
333:                 for key, value in pairs:
334:                     if key in result:
335:                         raise ValueError(f"duplicate field {key!r}")
336:                     result[key] = value

339:             loaded = json.loads(path.read_text(encoding="utf-8"), object_pairs_hook=reject_duplicates)
340:         except (OSError, json.JSONDecodeError) as exc:
341:             raise ValueError(f"malformed mapped custody record: {path}") from exc
342:         if not isinstance(loaded, dict):
343:             raise TypeError(f"mapped custody record is not an object: {path}")

346:     def _binding_record(self, namespace: str, observer: str) -> dict[str, object] | None:
347:         parent = self._subdir("bindings-v1", create=False)
348:         if parent is None:
349:             return None
350:         record = self._read_json(parent / f"{self._slot(namespace, observer)}.json")
351:         if record is None:
352:             return None

355:             "namespace": namespace,

359:             raise ValueError("mapped custody binding does not match its slot")
360:         for key in ("key_ref", "algorithm", "public_key", "provenance"):

368:     def _load_keypair(self, key_ref: str, *, require_public_file: bool = False):
369:         keys = self._subdir("keys-v1", create=False)
370:         if keys is None:
371:             raise FileNotFoundError(self.root / "keys-v1")
372:         key_dir = keys / key_ref
373:         mode = _lstat_kind(key_dir)
374:         if mode is None or not S_ISDIR(mode):
375:             raise FileNotFoundError(key_dir)
376:         private_path = key_dir / "ed25519.key"
377:         _regular(private_path)
378:         pair = ed25519.load(key_dir)
379:         public_path = key_dir / "ed25519.pub"
380:         exists = _regular(public_path, required=False)
381:         if require_public_file and not exists:
382:             raise ValueError("mapped custody key is missing its public evidence")

384:             raise ValueError("mapped custody public evidence disagrees with private key")

396:     def _completed_key_reference(self, key_ref: str, expected_public_key: str) -> None:
397:         """Require explicit reuse to name a published, validated binding."""

436:     def resolve(self, request: CredentialRequest) -> ResolvedCredential | None:
437:         """Resolve one credential without locks, mkdirs, repair, or fallback."""
438:         if request.namespace != self.namespace:
439:             raise CredentialBindingRefused("request-mismatch", request=request)
440:         try:
441:             record = self._validated_binding(request.namespace, request.observer)
442:             if record is None:
443:                 pending_dir = self._subdir("pending-v1", create=False)
444:                 pending = (
445:                     None
446:                     if pending_dir is None
447:                     else self._read_json(pending_dir / f"{self._slot(request.namespace, request.observer)}.json")
448:                 )
449:                 if pending is not None:
450:                     raise CredentialBindingRefused("recovery-required", request=request)
451:                 return None

454:         except CredentialBindingRefused:
455:             raise
456:         except (OSError, ValueError) as exc:
457:             raise CredentialBindingRefused("corrupt-binding", request=request) from exc
458:         return ResolvedCredential(
459:             evidence=evidence,
460:             sign_digest=lambda digest: ed25519.sign(
461:                 pair, digest.encode(), domain=_domain_prefix(request.domain)

499:     def _pending_by_token(self, token: str) -> dict[str, object] | None:
500:         """Find a durable token reservation while holding the provider lock."""
501:         pending_dir = self._subdir("pending-v1", create=False)
502:         if pending_dir is None:
503:             return None
504:         found: dict[str, object] | None = None
505:         for path in pending_dir.iterdir():
506:             if path.suffix != ".json":
507:                 continue
508:             record = self._read_json(path)
509:             if record is None or record.get("token") != token:
510:                 continue
511:             namespace = record.get("namespace")
512:             observer = record.get("observer")
513:             if not isinstance(namespace, str) or not isinstance(observer, str):
514:                 raise TypeError("mapped pending intent lacks exact slot identity")
515:             expected_name = f"{self._slot(namespace, observer)}.json"
516:             if path.name != expected_name:
517:                 raise ValueError("mapped pending intent is stored in the wrong slot")
518:             if found is not None:
519:                 raise BindingConflict("mapped binding token owns multiple pending slots")
520:             found = record
521:         return found

524:         """Publish or validate the token index for an already durable intent."""

549:     def _assert_published_intent(
550:         self,
551:         published: dict[str, object],
552:         intent: dict[str, object],
553:         *,
554:         require_token_index: bool = True,
555:     ) -> None:
556:         """Ensure a material-valid slot still names this exact retained intent."""
557:         for name in ("namespace", "observer", "key_ref", "provenance"):
558:             if published.get(name) != intent.get(name):
559:                 raise BindingConflict("published mapped binding contradicts its retained intent")
560:         expected_public = intent.get("expected_public_key")
561:         if expected_public is not None and published.get("public_key") != expected_public:
562:             raise BindingConflict("published mapped binding contradicts its expected public key")
563:         intents = self._subdir("intents-v1", create=False)
564:         if intents is None:
565:             if require_token_index:
566:                 raise BindingConflict("published mapped binding has no token-index evidence")
567:             return
568:         indexed = self._read_json(intents / f"{_digest(str(intent['token']))}.json")
569:         if require_token_index and indexed != intent:
570:             raise BindingConflict("published mapped binding contradicts its token index")
571:         completion = self._read_json(
572:             intents / f"{_digest(str(intent['token']))}.complete.json"
573:         )
574:         if completion is not None:
575:             complete = dict(intent)
576:             complete["stage"] = "complete"
577:             if completion != complete:
578:                 raise BindingConflict("published mapped binding contradicts its completion receipt")

580:     def _intent_for(
581:         self, observer: str, *, token: str, provenance: str, key_ref: str | None = None,
582:         expected_public_key: str | None = None,
583:     ) -> dict[str, object]:
584:         intents = self._subdir("intents-v1", create=False)
585:         token_record = (
586:             None if intents is None else self._read_json(intents / f"{_digest(token)}.json")
587:         )
588:         if token_record is not None and (
589:             token_record.get("namespace") != self.namespace
590:             or token_record.get("observer") != observer
591:         ):
592:             raise BindingConflict("mapped binding token already names another intent")
593:         pending_for_token = self._pending_by_token(token)
594:         if pending_for_token is not None:
595:             if token_record is not None and token_record != pending_for_token:
596:                 raise BindingConflict("mapped binding pending slot contradicts its token index")
597:             if (
598:                 pending_for_token.get("namespace") != self.namespace
599:                 or pending_for_token.get("observer") != observer
600:             ):
601:                 raise BindingConflict("mapped binding token already owns another pending slot")
602:         pending_dir = self._subdir("pending-v1", create=False)
603:         slot_pending = (
604:             None
605:             if pending_dir is None
606:             else self._read_json(
607:                 pending_dir / f"{self._slot(self.namespace, observer)}.json"
608:             )
609:         )
610:         completed = self._validated_binding(self.namespace, observer)
611:         if completed is not None:
612:             indexed_slot: dict[str, object] | None = None
613:             if slot_pending is not None:
614:                 # A caller may legitimately retry an already-completed binding
615:                 # under a fresh operation token. The selected published material
616:                 # must still agree with this slot's original durable intent.
617:                 self._assert_published_intent(
618:                     completed, slot_pending, require_token_index=False
619:                 )
620:                 indexed_slot = (
621:                     None
622:                     if intents is None
623:                     else self._read_json(
624:                         intents / f"{_digest(str(slot_pending['token']))}.json"
625:                     )
626:                 )
627:                 if indexed_slot is not None:
628:                     self._assert_published_intent(completed, slot_pending)
629:             if pending_for_token is not None:
630:                 # The pending marker may be the only durable token evidence
631:                 # after interruption between its publication and token-index
632:                 # publication. Never restore that index until the published
633:                 # slot proves it still names this exact intent.
634:                 self._assert_published_intent(
635:                     completed, pending_for_token, require_token_index=False
636:                 )
637:             if (
638:                 (expected_public_key is not None and completed["public_key"] != expected_public_key)
639:                 or (key_ref is not None and completed["key_ref"] != key_ref)
640:                 or (
641:                     token_record is not None
642:                     and (
643:                         token_record.get("provenance") != provenance
644:                         or token_record.get("key_ref") != completed["key_ref"]
645:                     )
646:                 )
647:             ):
648:                 raise BindingConflict("existing mapped binding has a different public key")
649:             bindings = self._subdir("bindings-v1", create=False)
650:             assert bindings is not None
651:             # These writes all precede a completed result. Their contents have
652:             # been checked above, so a retry can now safely make any link whose
653:             # prior fsync was interrupted durable.
654:             _fsync_directory(bindings)
655:             _fsync_directory(self._key_dir(str(completed["key_ref"])))
656:             if slot_pending is not None:
657:                 assert pending_dir is not None
658:                 _fsync_directory(pending_dir)
659:                 if intents is not None and indexed_slot is not None:
660:                     _fsync_directory(intents)
661:             if pending_for_token is not None:
662:                 # The pending marker may be the only durable token evidence
663:                 # after interruption between its publication and token-index
664:                 # publication. Restore that index only after the published
665:                 # slot has passed the retained-intent check above.
666:                 self._ensure_token_index(pending_for_token)
667:                 self._assert_published_intent(completed, pending_for_token)
668:                 self._publish_completion(pending_for_token)
669:             return {
670:                 "completed": True,
671:                 "key_ref": completed["key_ref"],
672:                 "public_key": completed["public_key"],
673:                 "provenance": completed["provenance"],
674:                 "token": token,
675:             }
676:         pending = slot_pending
677:         if pending is not None:
678:             if pending_for_token is not None and pending_for_token != pending:
679:                 raise BindingConflict("mapped binding slot contradicts its token reservation")
680:             if pending.get("token") != token:
681:                 raise BindingRecoveryRequired(
682:                     "a different durable token owns this mapped binding slot"
683:                 )
684:             if (
685:                 pending.get("namespace") != self.namespace
686:                 or pending.get("observer") != observer
687:                 or pending.get("provenance") != provenance
688:                 or (key_ref is not None and pending.get("key_ref") != key_ref)
689:                 or (
690:                     expected_public_key is not None
691:                     and pending.get("expected_public_key") != expected_public_key
692:                 )
693:             ):
694:                 raise BindingConflict("mapped binding token was reused with different intent")
695:             assert pending_dir is not None
696:             _fsync_directory(pending_dir)
697:             self._ensure_token_index(pending)
698:             return pending
699:         intent = self._new_intent(
700:             observer,
701:             token=token,
702:             provenance=provenance,
703:             key_ref=key_ref,
704:             expected_public_key=expected_public_key,
705:         )
706:         pending_dir = self._subdir("pending-v1", create=True)
707:         assert pending_dir is not None
708:         # The slot marker contains the complete intent. If a process dies before
709:         # the token index is linked, callers which know observer/token can still
710:         # recover coherently; no directory scan or candidate deletion occurs.
711:         if not _publish_no_clobber(
712:             pending_dir / f"{self._slot(self.namespace, observer)}.json", _json_bytes(intent)
713:         ):
714:             return self._intent_for(
715:                 observer,
716:                 token=token,
717:                 provenance=provenance,
718:                 key_ref=key_ref,
719:                 expected_public_key=expected_public_key,
720:             )
721:         self._ensure_token_index(intent)
722:         return intent

724:     def _pending_for_recovery(self, observer: str, token: str) -> dict[str, object]:
725:         pending_dir = self._subdir("pending-v1", create=False)
726:         if pending_dir is None:
727:             raise BindingRecoveryRequired("no durable mapped binding intent exists")
728:         pending = self._read_json(
729:             pending_dir / f"{self._slot(self.namespace, observer)}.json"
730:         )

732:             raise BindingRecoveryRequired("no durable mapped binding intent exists")

735:             or pending.get("namespace") != self.namespace
736:             or pending.get("observer") != observer
737:             or pending.get("token") != token

752:     def _ensure_created_key(self, intent: dict[str, object]):
753:         key_ref = str(intent["key_ref"])
754:         keys = self._subdir("keys-v1", create=True)
755:         assert keys is not None
756:         key_dir = keys / key_ref
757:         _directory(key_dir, create=True)
758:         mode = _lstat_kind(key_dir)
759:         created = False
760:         if mode is None:  # defensive: _directory above must establish it
761:             raise FileNotFoundError(key_dir)
762:         if not S_ISDIR(mode):
763:             raise ValueError("mapped custody candidate key path is not a directory")
764:         private = key_dir / "ed25519.key"
765:         public = key_dir / "ed25519.pub"
766:         if _lstat_kind(private) is None:
767:             # This intent exclusively reserved the candidate ref. It is safe
768:             # to resume a crash before private-key publication completed.
769:             if _lstat_kind(public) is not None:
770:                 raise ValueError("incomplete candidate has public evidence without private key")
771:             pair = ed25519.load_or_generate(key_dir)
772:             _fsync_directory(key_dir)
773:             created = True
774:         else:
775:             pair = self._load_keypair(key_ref)
776:             if _lstat_kind(public) is None:
777:                 # A crash between durable private and public publication is
778:                 # resumable only for this retained, provider-owned intent.
779:                 _publish_no_clobber(public, (pair.public_b64 + "\n").encode(), mode=0o644)
780:                 _fsync_directory(key_dir)
781:             pair = self._load_keypair(key_ref, require_public_file=True)
782:         # A prior attempt may have published both key files and then failed to
783:         # fsync this directory. Validate the pair first, then make the retry
784:         # retain those existing entries before returning success.
785:         _fsync_directory(key_dir)
786:         self._hook("key-published", intent)
787:         return pair, created

+@pytest.fixture(autouse=True)
+def _isolated_process_roots(tmp_path: Path, monkeypatch: pytest.MonkeyPatch) -> None:
+    monkeypatch.setenv("XDG_STATE_HOME", str(tmp_path / "state"))
+    monkeypatch.setenv("XDG_CONFIG_HOME", str(tmp_path / "config"))
+    monkeypatch.setenv("LOOPS_HOME", str(tmp_path / "loops"))

+def _files(root: Path) -> dict[Path, bytes]:
+    return {
+        path.relative_to(root): path.read_bytes()
+        for path in root.rglob("*")
+        if path.is_file()
+    }
+
+
+def _provider(tmp_path: Path) -> MappedCredentialProvider:
+    return MappedCredentialProvider(
+        tmp_path / "bindings", namespace="tenant/a", receipt_observer="alice"
+    )
+

+def test_lifecycle_results_are_serializable_and_resolution_stays_read_only(
+    tmp_path: Path,
+) -> None:
+    provider = _provider(tmp_path)
+    created = provider.create_binding("alice", token="create-alice")
+
+    assert isinstance(created, CredentialBindingResult)
+    assert created.operation == "create"
+    assert created.namespace == "tenant/a"
+    assert created.observer == "alice"
+    assert created.binding_created is True
+    serialized = created.as_dict()
+    assert serialized["schema"] == "loops.sdk/credential-binding/v1"
+    assert serialized["key_ref"] == created.key_ref
+    assert json.loads(json.dumps(serialized, allow_nan=False)) == serialized
+    private = (provider.root / "keys-v1" / created.key_ref / "ed25519.key").read_text()
+    assert private not in json.dumps(serialized)
+    assert "bindings-v1" not in json.dumps(serialized)
+
+    before = _files(provider.root)
+    resolved = provider.resolve(
+        CredentialRequest(
+            provider.namespace,
+            "alice",
+            SigningDomain.FACT,
+            CredentialPurpose.AUTHORSHIP,
+        )
+    )
+    assert resolved is not None and resolved.evidence.key_ref == created.key_ref
+    assert _files(provider.root) == before
+
+    repeated = provider.create_binding("alice", token="create-alice")
+    assert repeated.key_ref == created.key_ref
+    assert repeated.public_key == created.public_key
+    assert repeated.binding_created is False
+    assert repeated.key_created is False
+

+def test_lifecycle_incomplete_retains_reconciliation_evidence(tmp_path: Path) -> None:
+    provider = _provider(tmp_path)
+
+    def interrupt(phase: str, _intent: dict[str, object]) -> None:
+        if phase == "binding-published":
+            raise OSError("injected publication interruption")
+
+    provider._creation_hook = interrupt
+    with pytest.raises(CredentialBindingIncomplete) as raised:
+        provider.create_binding("alice", token="recover-alice")
+
+    error = raised.value
+    assert error.operation == "create"
+    assert error.namespace == provider.namespace
+    assert error.observer == "alice"
+    assert error.token == "recover-alice"
+    assert error.key_ref is not None
+    assert error.phase == "binding-published"
+    assert error.source_type == "BindingMutationIncomplete"
+    assert error.outcome == "incomplete"
+    assert error.recovery_action == "reconcile"
+    assert error.as_dict()["phase"] == "binding-published"
+    assert "commit" not in error.as_dict()
+    assert json.loads(json.dumps(error.as_dict(), allow_nan=False)) == error.as_dict()
+
+    provider._creation_hook = None
+    recovered = provider.recover_binding("alice", token="recover-alice")
+    assert recovered.operation == "recover"
+    assert recovered.key_ref == error.key_ref
+    assert recovered.binding_created is False
+

+def test_lifecycle_conflict_recovery_and_input_errors_are_typed(tmp_path: Path) -> None:
+    provider = _provider(tmp_path)
+    alice = provider.create_binding("alice", token="alice-token")
+
+    pending_provider = MappedCredentialProvider(
+        tmp_path / "pending-bindings", namespace="tenant/a"
+    )
+
+    def interrupt(phase: str, _intent: dict[str, object]) -> None:
+        if phase == "intent-published":
+            raise OSError("leave pending intent")
+
+    pending_provider._creation_hook = interrupt
+    with pytest.raises(CredentialBindingIncomplete):
+        pending_provider.create_binding("alice", token="pending-token")
+    pending_provider._creation_hook = None
+    pending_before = _files(pending_provider.root)
+    with pytest.raises(CredentialBindingRecoveryRequired) as recovery:
+        pending_provider.create_binding("alice", token="different-token")
+    assert recovery.value.as_dict()["operation"] == "create"
+    assert recovery.value.as_dict()["token"] == "different-token"
+    assert recovery.value.as_dict()["outcome"] == "refused"
+    assert _files(pending_provider.root) == pending_before
+
+    before_token_conflict = _files(provider.root)
+    with pytest.raises(CredentialBindingConflict) as conflict:
+        provider.create_binding("bob", token="alice-token")
+    assert conflict.value.as_dict()["observer"] == "bob"
+    assert conflict.value.as_dict()["recovery_action"] == "reconcile"
+    assert _files(provider.root) == before_token_conflict
+
+    before_wrong_key = _files(provider.root)
+    with pytest.raises(CredentialBindingIncomplete) as wrong_key:
+        provider.bind_existing_ref(
+            "carol", alice.key_ref, "not-the-managed-public-key", token="wrong-key"
+        )
+    assert wrong_key.value.source_type == "ValueError"
+    assert _files(provider.root) == before_wrong_key
+    assert provider.resolve(
+        CredentialRequest(
+            provider.namespace,
+            "carol",
+            SigningDomain.FACT,
+            CredentialPurpose.AUTHORSHIP,
+        )
+    ) is None
+
+    shared = provider.bind_existing_ref(
+        "bob", alice.key_ref, alice.public_key, token="share-alice"
+    )
+    assert shared.operation == "bind-existing-ref"
+    assert shared.key_ref == alice.key_ref
+    with pytest.raises(SdkValueError, match="key_ref must be a non-empty string"):
+        provider.bind_existing_ref("carol", None, alice.public_key, token="bad")  # type: ignore[arg-type]
+    with pytest.raises(SdkValueError, match="vertex_path must be a path string or Path"):
+        provider.import_legacy(None, "carol", token="bad")  # type: ignore[arg-type]

+def test_raw_custody_failures_keep_unknown_phase_and_reconcile(
+    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
+) -> None:
+    provider = _provider(tmp_path)
+    original_index = provider._ensure_token_index
+
+    def interrupt_index(_intent: dict[str, object]) -> None:
+        raise OSError("injected token-index failure")
+
+    monkeypatch.setattr(provider, "_ensure_token_index", interrupt_index)
+    with pytest.raises(CredentialBindingIncomplete) as raised:
+        provider.create_binding("alice", token="index-token")

+    assert error.operation == "create"
+    assert error.namespace == provider.namespace
+    assert error.observer == "alice"
+    assert error.token == "index-token"
+    assert error.phase == "unknown"
+    assert error.source_type == "OSError"
+    assert error.key_ref is None
+    pending = json.loads(next((provider.root / "pending-v1").glob("*.json")).read_text())
+    assert pending.pop("key_ref")
+    assert pending == {
+        "expected_public_key": None,
+        "namespace": provider.namespace,
+        "observer": "alice",
+        "provenance": "created",
+        "schema": "loops.custody/binding-intent/v1",
+        "stage": "pending",
+        "token": "index-token",
+    }
+    assert json.loads(json.dumps(error.as_dict(), allow_nan=False)) == error.as_dict()
+
+    monkeypatch.setattr(provider, "_ensure_token_index", original_index)
+    recovered = provider.recover_binding("alice", token="index-token")
+    assert recovered.operation == "recover"
+    assert recovered.observer == "alice"
+
+    binding = next((provider.root / "bindings-v1").glob("*.json"))
+    binding.write_text("{malformed binding record")
+    before_corrupt = _files(provider.root)
+    with pytest.raises(CredentialBindingIncomplete) as corrupt:
+        provider.create_binding("alice", token="fresh-token")
+    assert corrupt.value.phase == "unknown"
+    assert corrupt.value.source_type == "ValueError"
+    assert _files(provider.root) == before_corrupt
