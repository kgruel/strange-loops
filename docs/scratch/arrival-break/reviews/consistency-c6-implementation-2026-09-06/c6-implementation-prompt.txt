1: # C6 — boundary continuity design
2: 
3: Status: accepted by root after two Fable 5.1 **high** design reviews and
4: source/test-backed triage. Implementation is now authorized within this design.
5: The follow-up raw verdict remains REVISE; its sole new blocker was disproved

9: not a claim that current runtime already enforces it. Sol audits engine history
10: and replay, Terra SDK operations, Luna independent failure cases, and root owns
11: the policy and review triage.
12: 
13: ## Decision and scope
14: 
15: A continuing boundary keeps its recorded consumption history. An ordinary
16: declaration edit changes the current interpretation of facts; it does not
17: restart that boundary. The proposed identity for this supported subset remains
18: the exact local vertex name, boundary role, and boundary name. No declaration
19: hash, file path, projection generation, or new wire identifier becomes identity.
20: 
21: The recommended policy is **inherit for in-place edits**. A trigger/count,
22: condition, fold, parse, route, or dispatch edit keeps the existing tick edge.
23: This is an explicit interpretation policy, not a claim that the old tick would
24: have fired under the new rules. A pending fact already consumed by that edge
25: does not become eligible again just because a declaration changed.
26: 
27: Whole-loop retirement followed by same-name recreation needs separate evidence
28: when an old local tick exists. A tick whose loop/vertex role was ambiguous when
29: received also cannot become unambiguous through a later configuration edit.
30: Those cases refuse runtime when the target consumes that ambiguous stream.
31: Removing the consumer is allowed; reintroducing it re-exposes the same conflict.
32: Facts, ticks, and declarations
33: remain available as evidence; no prior row is changed or relabeled.
34: 
35: The user has been offered a choice between inherited in-place trigger/count
36: edits and a stricter interim refusal of those edits. No answer has arrived as
37: this draft is prepared for review; root proceeds with the recommended inherit
38: policy as a stated assumption. Any later answer and the adversarial design
39: review must be reconciled before implementation. Credential requests and persisted bindings (D0/D2), explicit
40: same-name restart/carry ceremonies, and durable vertex IDs are separate work.
41: 
42: ## What the implementation actually does today
43: 
44: `Vertex.hydrate_snapshot` re-folds captured facts under the current declaration
45: in receipt order. It does **not** deserialize an old tick payload as current
46: fold state. A local loop tick invokes `Loop.replay_boundary`: reset to the
47: current initial state when reset is enabled, clear repeating-count bookkeeping,
48: or mark a one-shot boundary exhausted. A local vertex tick restores the vertex
49: period timestamp and does not reset every loop.
50: 
51: `plan_pending_boundaries` selects the greatest event-time/receipt edge per local
52: tick name. Facts at an equal timestamp precede or follow that edge by receipt
53: coordinate. This remains distinct from the tick's fact cursor and from
54: declaration receipt ordering. Count boundaries remain ingress-driven.
55: 
56: The grammar currently exposes `when`, `after`, and `every`; its compiler always
57: sets loop-boundary `reset=True`. The lower-level `Loop` supports carry, but
58: there is no public declaration reset/carry edit to implement in C6. Fold
59: overrides replace initial state and fold code, not declared boundary reset.
60: 
61: Consequently an in-place count edit retains the recorded boundary and replays
62: facts after it. The exact existing count-recovery behavior is:
63: 
64: | Target mode and retained evidence | Hydrated state and next behavior |
65: | --- | --- |
66: | `every M`, with an owned tick and K subsequently routed facts | Count is K, including when K >= M. Hydration does not fire. If K >= M, the next accepted routed ingress fires; otherwise M-K more routed facts are needed. |
67: | `every M`, with no owned tick and K replayed facts | Existing recovery sets count to K modulo M. It creates no missing historical ticks. |
68: | `after M`, with any owned loop tick | Inherits an exhausted one-shot boundary. New ingress does not restart it. |
69: | `after M`, with no owned tick and K replayed facts | Exhausted when K >= M; otherwise count is K. A fresh name can therefore already be exhausted by older facts. |
70: | `after` changed in place to `every M`, with an old owned tick | Current repeating mode resumes from that retained tick and subsequent routed facts, not from the declaration edit. |
71: | Kind-trigger edit with an owned tick | Pending evaluation retains the old event-time/receipt edge; only unconsumed facts are checked against the new trigger/conditions. |
72: 
73: A user wanting a fresh count or first firing is requesting a restart; C6 does
74: not silently provide one. Historical payloads keep their original meaning and
75: bytes even when current replay differs. Count-return values ignored during
76: hydration must not turn into retrospective dispatch or appended ticks.

83: ## Contract matrix
84: 
85: | Situation at the bounded head | Supported result |
86: | --- | --- |
87: | Same continuously present loop, unchanged declaration | Inherit its recorded reset/count/period and pending consumption evidence. |
88: | Same continuously present loop, edited fold/parse/routes/trigger/count/conditions/run or presentation | Inherit the same edge and replay under the new interpretation; no implicit restart. |
89: | No local ticks for a loop; edit, remove/recreate, or introduce a boundary | Allowed, subject to existing checks. Older facts may replay and pending triggers may become eligible; this is not a fresh-facts cutoff. |
90: | Remove a loop that has old ticks | Allowed when it is absent from the proposed runtime. Preserve old ticks as evidence. |
91: | Reintroduce that retired runtime name after it had a local tick | Refuse ordinary declaration preparation/preview and runtime capture. A final-document comparison alone cannot detect this. |
92: | Add a genuinely unused loop name | Allowed. It has a distinct future tick identity, but may still consume older facts selected by current routing. This is not state carry or an explicit restart. |
93: | Vertex boundary list edited in place | Inherit the vertex-name edge. Declaration order remains meaningful; no new vertex identity. |
94: | Historical tick had `origin == name == vertex` while that loop also existed | Refuse when the target has a vertex boundary. A corrected target without that consumer may run, but adding a vertex boundary later refuses. The old row remains ambiguous. |
95: | Historical collision existed but produced no ambiguous local tick | Permit a collision-free append-forward correction. Preserve C5's existing accepted case. |
96: | Foreign or originless tick | Keep as evidence; it does not establish a local edge or a local incarnation conflict. Equal labels in another lineage prove no identity. |
97: | Owned tick predates the own declaration genesis | Refuse if the target consumes its loop name or vertex period: no recorded declaration establishes its role. Removing that consumer can avoid the conflict; a new name is not a historical alias. |
98: | Tick could belong to a generated name whose historical expansion is not recorded | Refuse the affected runtime interpretation as unprovable; current files/environment cannot provide historical evidence. |
99: | Explicit restart, state carry, alias, or same-name incarnation cutover | Deferred new protocol behavior; not inferred from an ordinary edit, projection rebuild, or locator move. |

101: Removing an explicit `cite` declaration still leaves the implicit runtime
102: `cite` loop. That is an in-place interpretation change, not retirement of the
103: runtime name. Likewise, disabling a loop's boundary leaves the loop present;
104: old ticks still reset it under current hydration. The declaration representation
105: and the effective runtime namespace must not be conflated.
106: 
107: ## History and evidence algorithm
108: 
109: The shared validator is pure over one captured declaration anchor, complete
110: self-lineage declaration fact history, bounded ticks, and the target document
111: set (effective current state for runtime, proposed successor for editing).
112: It does not open a store, sign, read keys, consult external source files or the
113: environment, repair projections, or execute any source/dispatch command.
114: 
115: 1. Validate the declaration anchor against the captured full H through the
116:    existing custody/projection contract. Select only the own genesis and
117:    self-lineage declaration overlays. Foreign and unscoped declarations remain
118:    inert, matching the existing resolver. Sort by receipt ordinal and sequence,
119:    never authored time or fact ID.
120: 2. Reconstruct effective runtime names at the genesis and each committed
121:    declaration revision. Preserve retirement evidence across intermediate
122:    revisions; do not compare only genesis/current or before/proposed documents.
123:    Multiple declaration documents in one Arrival batch form one revision:
124:    evaluate the resulting effective set, not transient partial document states
125:    with no observable runtime between them. This grouping is for namespace
126:    continuity; document overlay order remains receipt-sequence order. Wire
127:    batches contain fact rows only; a CAS containing fact and tick drafts gives
128:    those drafts distinct record ordinals. A query reporting an owned tick and
129:    declaration fact at the same ordinal contradicts this shape and refuses
130:    with both actual coordinates. Do not invent an ordering for that adapter
131:    contradiction. This is not a newly legal mixed-row record format.
132: 3. At each owned tick's receipt position, classify its role using that revision.
133:    A vertex-name tick with a simultaneously present loop of that name is
134:    ambiguous. A currently relevant loop-name tick with no provable historical
135:    loop membership is unproven. Tick payload shape, signature, cursor, or
136:    current name validity cannot recover the missing role evidence.
137: 4. For each target runtime name with historical local ticks, require continuous
138:    membership since the relevant tick. A disappearance and later return
139:    conflicts even if its final declaration equals the earlier one. Internal
140:    tracking of membership intervals is evidence analysis, not a newly minted
141:    persistent incarnation ID. Ignore retired names that the target does not
142:    interpret. An ambiguous vertex-name tick matters when the target declares
143:    a vertex boundary; without that consumer the saved period field has no
144:    supported Arrival effect. Later re-enabling that boundary restores the
145:    refusal, not the missing role evidence.
146: 5. Analyze the proposed successor as one additional revision with no fabricated
147:    fact ID, timestamp, ordinal, or Commit. This allows retirement and safe
148:    configuration correction even when the old runtime itself refuses. Run
149:    the check for no-op proposals too; no-op does not certify unsafe execution.
150: 6. Return normally or a deterministic diagnostic naming the reason, boundary,
151:    and actual conflicting tick/declaration receipt where available. Do not
152:    manufacture an epoch/cutoff or report guessed identity as proven.
153: 
154: The custody-bounded query is still an adapter contract: completing a watermark
155: does not independently establish row agreement or prove a projected declaration
156: was authored by the claimed observer. C6 adds continuity analysis, not a second
157: custody audit or new tick-authentication rule.
158: 
159: The evidence read is through captured H even when event timestamps are negative
160: or far in the future. `TickRequest` defaults to `since=0`; the validator must
161: explicitly request the full timestamp range. Existing hydration/pending
162: timestamp selection is a separate policy and must not be widened accidentally.
163: 
164: Use documents as the common target input for all three entrypoints. The result
165: includes the target's provable runtime names and unresolved-generator flag.
166: Apply C5 reservation to provable names, including literal generated loops,
167: during declaration preview and preparation as well as runtime. Runtime also
168: checks names in both directions: every provable target name must be materialized
169: (including implicit `cite`), and every actual compiled name must belong to the
170: proved set or be covered by an explicitly unknown generator. An unexplained
171: extra or missing name refuses before hydration. Thus current parameter-file
172: changes between verification and compilation cannot silently remove a proved
173: consumer. This checks names, not arbitrary fold-code equivalence.
174: 
175: Unchanged wire declaration decoding remains authoritative. Prefer sharing the
176: existing overlay step/ordering code rather than introducing a second subtly
177: different definition of self-lineage history. Unknown declaration kinds retain
178: the resolver's forward-compatible inert treatment; malformed supported
179: namespace evidence refuses rather than yielding a fabricated safe history.

181: ## Generated loop names
182: 
183: Only template sources with a declared `loop` generate runtime loop specs in
184: the current compiler. Bare paths, inline source commands, and templates without
185: such a loop do not create additional loop identities. They must not trigger a
186: blanket source-history refusal.
187: 
188: For a template loop, literal inline parameter rows and the stored loop document
189: can establish generated names without opening the template file. Match the
190: compiler's actual ordering and override semantics: sources sorted by recorded
191: order/subject, parameter rows in order, generated specs overriding explicit
192: specs at equal names. Variables used only by collection commands do not make a
193: literal loop name unprovable.
194: 
195: A `from` parameter file's hash pin commits to historical bytes. If bytes
196: available now verify against the pin recorded for a revision, those bytes can
197: establish that revision's parameter rows. An absent, mismatched, or unpinned
198: file supplies no such evidence. Environment-indirected `kind` remains unknown
199: even in verified rows because the resolved environment value was not recorded.
200: Unknown generators can produce/override any name, including the vertex name.
201: 
202: Keep the classifier pure with explicit `verified_params: hash -> ordered rows`
203: evidence. A shared caller-side collector used by runtime, preparation, and
204: semantic preview obtains candidate bytes from captured historical parameter
205: paths relative to the locator, hashes those exact bytes, and accepts them only
206: for matching recorded pins. Parse the same byte snapshot that was hashed;
207: never verify a path and reopen it to parse potentially changed bytes. Reuse an
208: extracted form of the compiler's parameter-text parser, preserving encoding,
209: header, comments, row ordering, and last-column behavior. Do not implement a
210: second grammar. Cache by verified content hash within this capture only.
211: Unknown/unavailable evidence remains unknown and only blocks a relevant proof;
212: an irrelevant unreadable historical source must not poison a direct loop.
213: No network retrieval or environment resolution supplies historical evidence.
214: 
215: The classifier uses the same whole-value `$NAME` indirection recognition and
216: `$$` leading-dollar escape as the compiler. Partial strings remain literal,
217: matching current behavior. Parameter indirection used only by source commands
218: does not make a literal `kind` unknown. This evidence collector does not replace
219: current runtime pin verification and compilation, which retain their own checks.
220: 
221: That runtime pin gate already exists: `_build_effective_arrival_candidate`
222: calls `effective_declaration_from_documents` with default `verify_pins=True`;
223: the latter calls `verify_source_pins_from_documents`, which checks both source
224: content and `from.params_sha256` before `compile_sources`. Do not add a duplicate
225: gate based on the follow-up review's mistaken claim that it is absent.
226: Continuity here describes the recorded declaration and its pinned expansion,
227: not forensic proof that every past external program obeyed that declaration.
228: Unknown legacy behavior or an origin label is not upgraded into authentication.
229: 
230: Use three-valued membership per name and revision. Direct, implicit, or literal
231: generated membership proves **present** even if another generator has unknown
232: names: an override changes its interpretation but does not remove that name.
233: If the name is not in the provable set and an unresolved generator could emit
234: it, membership is **unknown**. Otherwise it is **absent**.
235: 
236: For every old local loop tick that the target would interpret, membership must
237: be provably present at its receipt and throughout all later revisions through
238: the target. Unknown membership anywhere in that interval refuses: an unknown
239: intervening revision could conceal retirement/recreation without containing a
240: tick itself. Analyze every relevant tick, not just the newest pending edge;
241: hydration also consumes historical reset markers. A tick whose name is absent
242: from the target is not attached to a current loop, so that retired stream alone
243: does not block execution. Unknown target membership for an old tick refuses.
244: 
245: For a vertex-name tick consumed by a target vertex boundary, loop membership
246: at its receipt must be provably absent.
247: Present means a role collision; unknown means its role cannot be established.
248: The vertex identity itself continues while its boundary list is edited or
249: disabled, so only loop-name ambiguity at that tick changes this role proof.
250: Unresolved revisions before all relevant ticks do not, by themselves, create
251: consumption obligations. This is a conservative evidence rule, not proof that
252: unknown expansions actually collided. Literal generated sources and provably
253: continuous direct loops must remain usable. Do not compile old declarations
254: against current external inputs or claim that no document edit proves stability.
255: 
256: ## Integration and effects
257: 
258: - Runtime: invoke the validator in the shared effective-candidate builder
259:   before `hydrate_snapshot`, pending-boundary planning, signer invocation, and source
260:   collection. Ordinary, batch, preview, and source paths inherit that one check.
261:   The lower-level caller-responsible planners remain internal; C6 does not
262:   pretend to validate an arbitrary caller-built `Vertex` against history.
263:   SDK credential providers may already have loaded signer capabilities before
264:   capture; C6 does not claim that loading never occurred or redesign providers.
265:   Raise `BoundaryContinuityRefused(RuntimeWriteRefused)` retaining the actual
266:   `basis`, `captured_head`, effective declaration, and a small immutable issue
267:   DTO. Expose actual `tick_id`, receipt `ordinal`, relevant declaration `fact_id`
268:   and `vertex` through existing C2 scalar evidence fields when known. The local
269:   planning attempt has phase `prepare` and custody append not entered; it does
270:   not erase prior successful source tiers or imply an external witness did not
271:   advance. The diagnostic contains no full source/record payloads.
272: - Declaration preparation: validate the proposed successor at the same CURRENT
273:   basis after history/custody checks and before key-history work that invokes
274:   signers or creates drafts/intents. Use `DeclarationPreparationRefused` with
275:   established prepare/custody-not-entered evidence and captured H. An accepted
276:   registry open may still advance an external witness; custody-not-entered
277:   refers to append, not an assertion of zero effects anywhere. Preserve the
278:   structured conflict as an explicit exception cause (`raise ... from ...`);
279:   C2 already serializes `__cause__`. A general cause parameter on every
280:   preparation refusal factory is unnecessary. Raise that explicit preparation
281:   refusal ahead of the generic basis-error wrapper, preserving a continuity
282:   diagnostic instead of mislabeling it as failure to capture the basis.
283: - SDK semantic preview: use the same bounded history/target validator, with its
284:   existing normalized refusal family and no invented signing/Commit evidence.
285:   A preview must not say applicable for a proposal that the history gate refuses.
286: - Reads/verify/export: do not add this execution gate to evidence reconstruction
287:   or ordinary read APIs. Read-state interpretation remains available and is not
288:   a certification of safe runtime continuity.
289: - Legacy attached `Vertex.replay`/`evaluate_boundaries` and `load_vertex_program`
290:   are outside this supported Arrival capture contract. Their separate origin
291:   and variable-substitution behavior remains legacy-retirement work; C6 must
292:   not claim to have made every historical CLI/runtime path conformant.
293: - Initialization has no old tick history. C5's pre-genesis name check remains;
294:   no pointless history pass or key migration is added.
295: - Existing declaration apply/recovery uses its frozen plan/durable intent.
296:   Runtime capture independently rejects any unsafe history imported or appended
297:   through other mechanisms. No recovery rewrite, automatic retry, or implicit
298:   transition is introduced.
299: 
300: ## Acceptance and staged work
301: 
302: Engine tests must reproduce the old acceptance of a ticked remove/recreate and
303: of a corrected historical loop/vertex collision. Assert the refusal happens
304: before hydration, signing, append, pending planning, or collection as appropriate.
305: Use full bounded receipt histories, including intermediate retirement, batched
306: changes, equal/out-of-order event times, foreign declarations/ticks, a relevant
307: undeclared historical tick, implicit `cite`, and stale local-file disagreement.
308: 
309: Positive engine and real SDK scenarios must demonstrate in-place fold and
310: boundary-count edits retaining edges, `after` inheriting exhaustion, tick-free
311: changes reinterpreting older facts, retirement followed by a fresh-name
312: replacement, unchanged/literal template sources, and tick-free C5 repair.
313: Keep evidence reads/export working for refused histories and verify exact
314: custody prefix preservation through an accepted appended correction.
315: 
316: Negative source scenarios cover missing/mismatched historical parameter pins
317: and env-derived generated names with old ticks even when source documents are
318: unchanged. Positive scenarios prove historical pin-matching rows work in all
319: three entrypoints, direct names stay provably present despite unrelated unknown
320: generators, and a file replacement between read/hash/parse cannot substitute
321: unverified rows. A command-only source edit with provable names remains usable.
322: Test ambiguous-history repair without a vertex consumer, followed by refusal
323: when one is proposed again. Exercise every row of the count-recovery table,
324: including a fresh-name `after` already exhausted by old facts.
325: 
326: Stages: root reconciles this design and agent audits; freeze exact design and
327: supporting source packet; Fable 5.1 high reviews it; root triages all findings
328: and revises/re-reviews material contract changes. Only then assign Sol engine

153: def declaration_document_revisions(
154:     anchor: DeclarationAnchor,
155:     facts: Sequence[Fact],
156:     *,
157:     target_documents: Sequence[Mapping[str, Any]] | None = None,
158: ) -> tuple[DeclarationDocumentRevision, ...]:
159:     """Return genesis, own-overlay groups, and an optional proposed target.
160: 
161:     Foreign declaration rows are intentionally excluded before any caller can
162:     inspect their source paths.  Rows sharing an Arrival ordinal are applied in
163:     sequence and exposed as one observable revision.
164:     """
165:     internal = sorted(
166:         (fact for fact in facts if is_internal_kind(fact.kind)),
167:         key=lambda fact: (fact.arrival_ordinal, fact.arrival_seq),
168:     )
169:     if anchor.own_lineage is None:
170:         if any(fact.kind == DECL_GENESIS for fact in internal):
171:             raise UnadoptedLineage(
172:                 "declaration genesis rows occur without an own-lineage marker"
173:             )
174:         raise DeclarationResolutionError(
175:             "boundary continuity requires a historized own declaration"
176:         )
177:     genesis = anchor.genesis
178:     if (
179:         genesis is None
180:         or genesis.id != anchor.own_lineage
181:         or genesis.kind != DECL_GENESIS
182:     ):
183:         raise DeclarationResolutionError(
184:             "own-lineage declaration marker has no matching genesis"
185:         )
186:     protocol = genesis.payload.get("protocol", 1)
187:     if protocol > DECLARATION_PROTOCOL_VERSION:
188:         raise UnsupportedProtocol(
189:             f"genesis protocol {protocol} exceeds supported "
190:             f"{DECLARATION_PROTOCOL_VERSION}"
191:         )
192: 
193:     mapped = _document_map(genesis.payload.get("documents", ()))
194:     revisions = [
195:         DeclarationDocumentRevision(
196:             arrival_ordinal=genesis.arrival_ordinal,
197:             fact_ids=(genesis.id,),
198:             document_fact_ids=(),
199:             documents=_documents_tuple(mapped),
200:         )
201:     ]
202:     grouped: dict[int, list[Fact]] = {}
203:     for fact in internal:
204:         if fact.kind == DECL_GENESIS:
205:             continue
206:         if fact.arrival_ordinal < genesis.arrival_ordinal:
207:             # A self-scoped overlay cannot establish a runtime definition
208:             # before the declaration genesis that licenses its lineage.
209:             continue
210:         payload = fact.payload
211:         if payload.get("lineage") != anchor.own_lineage:
212:             continue
213:         if fact.kind not in _DEFINED_KINDS and fact.kind not in _TOMBSTONE_TO_DEFINED:
214:             continue
215:         grouped.setdefault(fact.arrival_ordinal, []).append(fact)
216: 
217:     for ordinal in sorted(grouped):
218:         group = grouped[ordinal]
219:         for fact in group:
220:             payload = fact.payload
221:             subject = payload.get("subject")
222:             if fact.kind in _TOMBSTONE_TO_DEFINED:
223:                 mapped.pop((_TOMBSTONE_TO_DEFINED[fact.kind], subject), None)
224:             else:
225:                 mapped[(fact.kind, subject)] = {
226:                     "kind": fact.kind,
227:                     "subject": subject,
228:                     "payload": copy.deepcopy(payload.get("payload", {})),
229:                 }
230:         revisions.append(
231:             DeclarationDocumentRevision(
232:                 arrival_ordinal=ordinal,
233:                 fact_ids=tuple(fact.id for fact in group),
234:                 document_fact_ids=tuple(
235:                     (fact.kind, str(fact.payload.get("subject")), fact.id)
236:                     for fact in group
237:                 ),
238:                 documents=_documents_tuple(mapped),
239:             )
240:         )
241: 
242:     if target_documents is not None:
243:         target = _copy_documents(target_documents)
244:         if not revisions or target != revisions[-1].documents:
245:             revisions.append(
246:                 DeclarationDocumentRevision(
247:                     arrival_ordinal=None,
248:                     fact_ids=(),
249:                     document_fact_ids=(),
250:                     documents=target,
251:                     proposed=True,
252:                 )
253:             )
254:     return tuple(revisions)

257: def collect_verified_parameter_rows(
258:     anchor: DeclarationAnchor,
259:     facts: Sequence[Fact],
260:     *,
261:     target_documents: Sequence[Mapping[str, Any]],
262:     base_dir: Path,
263: ) -> dict[str, tuple[Mapping[str, str], ...]]:
264:     """Read, hash, and parse own historical pinned parameter snapshots.
265: 
266:     Missing, changed, unpinned, or malformed historical inputs remain unknown;
267:     they do not poison an unrelated direct loop.  Current runtime pin checks
268:     remain a separate existing gate.
269:     """
270:     from .compiler import parse_source_params_bytes
271: 
272:     verified: dict[str, tuple[Mapping[str, str], ...]] = {}
273:     revisions = declaration_document_revisions(
274:         anchor, facts, target_documents=target_documents
275:     )
276:     for revision in revisions:
277:         for document in revision.documents:
278:             if document.get("kind") != DECL_SOURCE_DEFINED:
279:                 continue
280:             payload = document.get("payload", {})
281:             if payload.get("form") != "template" or payload.get("loop") is None:
282:                 continue
283:             from_document = payload.get("from")
284:             if not isinstance(from_document, Mapping):
285:                 continue
286:             pin = from_document.get("params_sha256")
287:             path_text = from_document.get("path")
288:             if not isinstance(pin, str) or not isinstance(path_text, str):
289:                 continue
290:             if pin in verified:
291:                 continue
292:             path = Path(path_text)
293:             candidate = path if path.is_absolute() else base_dir / path
294:             try:
295:                 data = candidate.read_bytes()
296:                 if hashlib.sha256(data).hexdigest() != pin:
297:                     continue
298:                 rows = parse_source_params_bytes(data, source=candidate)
299:             except (OSError, UnicodeError, ValueError):
300:                 continue
301:             verified[pin] = tuple(dict(row.values) for row in rows)
302:     return verified

305: def _literal_kind(value: object) -> tuple[str | None, bool]:
306:     if not isinstance(value, str) or not value:
307:         return None, False
308:     if value.startswith("$$"):
309:         return value[1:], False
310:     if _ENV_VALUE.fullmatch(value):
311:         return None, True
312:     return value, False

315: def _namespace(
316:     documents: Sequence[Mapping[str, Any]],
317:     verified_params: Mapping[str, Sequence[Mapping[str, str]]],
318: ) -> _Namespace:
319:     names = {"cite"}
320:     unknown = False
321:     vertex_name: str | None = None
322:     has_vertex_boundary = False
323:     for document in documents:
324:         kind = document.get("kind")
325:         subject = document.get("subject")
326:         payload = document.get("payload", {})
327:         if kind == DECL_VERTEX_DEFINED:
328:             candidate = payload.get("name")
329:             if not isinstance(candidate, str) or not candidate:
330:                 raise DeclarationResolutionError(
331:                     "vertex declaration has no explicit runtime name"
332:                 )
333:             vertex_name = candidate
334:             has_vertex_boundary = bool(payload.get("boundary", ()))
335:         elif kind == DECL_KIND_DEFINED and isinstance(subject, str):
336:             names.add(subject)
337:         elif kind == DECL_SOURCE_DEFINED:
338:             if payload.get("form") != "template" or payload.get("loop") is None:
339:                 continue
340:             rows: list[Mapping[str, str]] = []
341:             for param in payload.get("params", ()):
342:                 if isinstance(param, Mapping) and isinstance(param.get("values"), Mapping):
343:                     rows.append(param["values"])
344:             from_document = payload.get("from")
345:             if isinstance(from_document, Mapping):
346:                 pin = from_document.get("params_sha256")
347:                 if isinstance(pin, str) and pin in verified_params:
348:                     rows.extend(verified_params[pin])
349:                 else:
350:                     unknown = True
351:             for row in rows:
352:                 literal, indirect = _literal_kind(row.get("kind"))
353:                 if literal is not None:
354:                     names.add(literal)
355:                 unknown = unknown or indirect
356:     if vertex_name is None:
357:         raise DeclarationResolutionError(
358:             "declaration documents have no vertex identity"
359:         )
360:     return _Namespace(
361:         names=frozenset(names),
362:         unknown_generator=unknown,
363:         vertex_name=vertex_name,
364:         has_vertex_boundary=has_vertex_boundary,
365:     )

400: def _revision_fact_id(
401:     revision: DeclarationDocumentRevision | None,
402:     loop_name: str | None,
403:     declaration_kind: str | None,
404: ) -> str | None:
405:     if revision is None:
406:         return None
407:     if not revision.document_fact_ids:
408:         # Genesis is the one row that establishes every seed document.
409:         return revision.fact_ids[0] if len(revision.fact_ids) == 1 else None
410:     if declaration_kind is not None:
411:         for kind, _subject, fact_id in reversed(revision.document_fact_ids):
412:             if kind == declaration_kind:
413:                 return fact_id
414:         return None
415:     if loop_name is not None:
416:         loop_kinds = {
417:             DECL_KIND_DEFINED,
418:             DEFINED_TO_TOMBSTONE[DECL_KIND_DEFINED],
419:         }
420:         for kind, subject, fact_id in reversed(revision.document_fact_ids):
421:             if kind in loop_kinds and subject == loop_name:
422:                 return fact_id
423:     return None

365:     data: bytes, *, source: str | Path = "<params>"
366: ) -> list[SourceParams]:
367:     """Parse one exact parameter-file byte snapshot.
368: 
369:     File format:
370:     - Lines starting with # are comments
371:     - Blank lines are skipped
372:     - First content line is the header (whitespace-separated column names)
373:     - Subsequent lines are data rows
374:     - Last column gets remainder (handles URLs with query strings)
375: 
376:     Decode with the same locale encoding ``Path.read_text()`` historically
377:     used.  Accepting bytes lets declaration-history validation hash and parse
378:     one immutable read rather than verify a path and reopen different bytes.
379:     """
380:     import io
381: 
382:     # TextIOWrapper with no explicit encoding/newline is the in-memory sibling
383:     # of Path.open()/Path.read_text() defaults, including Python UTF-8 mode.
384:     with io.TextIOWrapper(io.BytesIO(data)) as stream:
385:         text = stream.read()
386:     lines = text.splitlines()

388:     header: list[str] | None = None
389:     params: list[SourceParams] = []

392:         line = raw.strip()
393:         if not line or line.startswith("#"):
394:             continue
395: 
396:         if header is None:

401:         parts = line.split(None, len(header) - 1)

416: def _resolve_param_indirection(values: dict[str, str]) -> dict[str, str]:
417:     """Resolve environment-indirected param values (SPEC §9.5 secrets-indirection).
418: 
419:     A whole-value ``$NAME`` param resolves from the process environment at
420:     compile time. The declared ``$NAME`` form is what enters declaration
421:     payloads (genesis/edit rows); the resolved value is ingress and never
422:     absorbed. ``$$`` escapes a literal leading ``$``. Partial interpolation
423:     is not supported — compose via separate template params instead.
424:     """
425:     import os
426:     import re
427: 
428:     resolved: dict[str, str] = {}
429:     for key, value in values.items():
430:         if value.startswith("$$"):
431:             resolved[key] = value[1:]
432:         elif re.fullmatch(r"\$[A-Za-z_][A-Za-z0-9_]*", value):
433:             name = value[1:]

435:                 raise ValueError(

437:                     f"(indirected params resolve from the environment at load time)"

+    verified: dict[str, tuple[Mapping[str, str], ...]] = {}
+    revisions = declaration_document_revisions(
+        anchor, facts, target_documents=target_documents

+        for document in revision.documents:

+            if not isinstance(from_document, Mapping):
+                continue

+            if not isinstance(pin, str) or not isinstance(path_text, str):

+def _literal_kind(value: object) -> tuple[str | None, bool]:
+    if not isinstance(value, str) or not value:
+        return None, False
+    if value.startswith("$$"):
+        return value[1:], False
+    if _ENV_VALUE.fullmatch(value):
+        return None, True
+    return value, False

+def _namespace(
+    documents: Sequence[Mapping[str, Any]],
+    verified_params: Mapping[str, Sequence[Mapping[str, str]]],
+) -> _Namespace:
+    names = {"cite"}
+    unknown = False
+    vertex_name: str | None = None
+    has_vertex_boundary = False
+    for document in documents:
+        kind = document.get("kind")
+        subject = document.get("subject")
+        payload = document.get("payload", {})
+        if kind == DECL_VERTEX_DEFINED:
+            candidate = payload.get("name")
+            if not isinstance(candidate, str) or not candidate:
+                raise DeclarationResolutionError(
+                    "vertex declaration has no explicit runtime name"
+                )
+            vertex_name = candidate
+            has_vertex_boundary = bool(payload.get("boundary", ()))
+        elif kind == DECL_KIND_DEFINED and isinstance(subject, str):
+            names.add(subject)
+        elif kind == DECL_SOURCE_DEFINED:
+            if payload.get("form") != "template" or payload.get("loop") is None:
+                continue
+            rows: list[Mapping[str, str]] = []
+            for param in payload.get("params", ()):
+                if isinstance(param, Mapping) and isinstance(param.get("values"), Mapping):
+                    rows.append(param["values"])
+            from_document = payload.get("from")
+            if isinstance(from_document, Mapping):
+                pin = from_document.get("params_sha256")
+                if isinstance(pin, str) and pin in verified_params:
+                    rows.extend(verified_params[pin])
+                else:
+                    unknown = True
+            for row in rows:
+                literal, indirect = _literal_kind(row.get("kind"))
+                if literal is not None:
+                    names.add(literal)
+                unknown = unknown or indirect
+    if vertex_name is None:
+        raise DeclarationResolutionError(
+            "declaration documents have no vertex identity"
+        )
+    return _Namespace(
+        names=frozenset(names),
+        unknown_generator=unknown,
+        vertex_name=vertex_name,
+        has_vertex_boundary=has_vertex_boundary,
+    )

+def _revision_fact_id(
+    revision: DeclarationDocumentRevision | None,
+    loop_name: str | None,
+    declaration_kind: str | None,
+) -> str | None:
+    if revision is None:
+        return None
+    if not revision.document_fact_ids:
+        # Genesis is the one row that establishes every seed document.
+        return revision.fact_ids[0] if len(revision.fact_ids) == 1 else None
+    if declaration_kind is not None:
+        for kind, _subject, fact_id in reversed(revision.document_fact_ids):
+            if kind == declaration_kind:
+                return fact_id
+        return None
+    if loop_name is not None:
+        loop_kinds = {
+            DECL_KIND_DEFINED,
+            DEFINED_TO_TOMBSTONE[DECL_KIND_DEFINED],
+        }
+        for kind, subject, fact_id in reversed(revision.document_fact_ids):
+            if kind in loop_kinds and subject == loop_name:
+                return fact_id
+    return None

+        provable_names=target.names,
+        has_unknown_generators=target.unknown_generator,
+        vertex_name=target.vertex_name,
+        has_vertex_boundary=target.has_vertex_boundary,
+    )
